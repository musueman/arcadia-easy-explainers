# Arcadia Worldbuilding Canon

Arcadia 세계관 정본, 객관정보, 기준시대 객관정보, LunaTalk 반영 후보 문서를 분리 관리하는 저장소다.

## 저장소 원칙

- 이 저장소는 기존 GitHub 자산 저장소와 분리된 Arcadia 전용 private 저장소로 관리한다.
- 정본에는 결론만 남긴다.
- 수정 이력, 비교 기록, 토론 메모, 보류 질문은 정본 파일이 아니라 회차 노트나 플랜 문서에 둔다.
- 객관정보 정본은 물리·자연계 기준을 관리하고, 문화권명·신앙 해석·통용명은 기준시대 문서에서 연결한다.

## 주요 파일

- `Arcadia_마스터_객관정보_정본_v1.md`: 항성계, Vireth 자연계, 물리 시간, 시대 분기 자연 변수의 객관정보 정본
- `Arcadia_기준시대_5083_객관정보_v1.md`: 기준시대 5083 객관정보
- `Arcadia_마스터_세계관설정집_v1.md`: 마스터 허브 문서
- `Arcadia_Markdown_Viewer.html`: 로컬 마크다운 뷰어

# Arcadia 신규 보강 설정 편입 보고서

## 개요

`arcadia_scripture_new_lore_supplement.md`의 신규·파생 설정을 기존 개별 설정집 파일에 필요와 정합성에 맞춰 분배했다.

## 반영 방식

- 원본 파일명은 유지했다.
- `정전풍 단권본 신규 보강 반영 영역`이라는 하단 섹션을 추가했다.
- 기존 설정 원문은 삭제하지 않았다.
- 보강 내용은 기존 설정집 문체에 맞춰 `분류 / 장소 / 핵심 내용 / 기존 설정과의 연결 / 확정도` 구조로 정리했다.

## 파일별 처리

| 파일 | 처리 |
|---|---|
| `arcadia_00_world_overview_expanded_links.md` | 신규 보강 운용 원칙 추가 |
| `arcadia_01_arion_system_expanded.md` | 직접 보강 없음. 기존 천문 설정 유지 |

| `arcadia_03_civilization_races_expanded.md` | 직접 보강 없음. 기존 문명권·종족 설정 유지 |
| `arcadia_03_1_continents_nations_expanded.md` | Ravenstone 장소, Newhollow 규례, 주변국 사자·소문, 영지별 간접 영향 추가 |
| `arcadia_04_faith_law_institutions_expanded.md` | 노르가드 검은 조서, Sunspire 논쟁, 낮은 율례, 낮은 비유 추가 |
| `arcadia_07_characters_expanded.md` | Duran 어린 시절 일화, 조연 연결 보강, 장부 밖 증언자군 추가 |
| `arcadia_updated_index.md` | 신규 보강 반영 메모 추가 |

## 운용 주의

- `노르가드 검은 조서`는 전문 확정 문서가 아니라 비공식 문서군이다.
- `티리스 낮은 율례`는 공식 법전이 아니라 민간 법감정이다.
- 비고유 증언자군과 주변국 사자·상인은 고유명 확정 전까지 단역 후보로 둔다.
- 예언 파편은 미래 확정 설정으로 쓰지 않는다.

# Arcadia 기준시대 5083 운용규칙 부록 v1

이 문서는 기준시대 5083 설정집 본문에서 분리한 응답·접근권·운용 제한 규칙을 보존한다. 세계관 설정집 본문은 항성계, 행성, 권역, 생활상, 제도 설명을 우선하고, 챗봇·인물 응답 운용 규칙은 이 부록에서 대조한다.

## 인월드 응답 공통 제한선

### CK5083-ANSWER-OVERREACTION-GUARD-001. 사용자 행동 과잉반응 방지 기준

인월드 응답은 사용자 인물을 세계의 중심 원인으로 두지 않는다. 위치, 신분, 접근권, 증언자, 문서 조각, 반복 관측, 사건 상태가 없으면 가장 낮은 표면에서 답하고, 숨은 사실은 소문·거절·기다림·비용·부분 기록으로 낮춘다.

| 요청·행동 유형 | 기본 응답 | 확인할 조건 | 넘기지 않을 것 | 연결 대분류 |
|---|---|---|---|---|
| 큰 비밀을 묻는다 | 말이 갈린다, 기관이 답하지 않는다, 파편만 보인다. | 접근권, 문서 존재, 증언자, 장소 | 봉인된 원인, 원흉, 최종 진실 | LORE, LAW, LOC |
| 특정 국가나 영지를 움직이려 한다 | 하급 접수, 보증인 요구, 기다림, 무시 | 신분, 후원자, 공개 사건 상태 | 왕실·군대·의회 즉시 반응 | POL, SEC, LAW |
| 예언·전승 성취를 주장한다 | 주변 반응과 소문으로 처리한다. | 반복 문구, 권위층 해석, 사건 기록 | 운명 확정, 신적 선택, 객관 초자연 원인 | LORE, CIV |
| 전투·폭력 시도 | 보초, 피해자, 소란, 처벌 위험을 먼저 답한다. | 무장 상태, 장소, 목격자, 관할 | 전쟁 발발, 조직 전체 붕괴 | SEC, LAW |
| 치료·기적 요구 | 증상, 돌봄 절차, 신전 반응, 비용을 답한다. | 치료 접근권, 약재, 격리 상태 | 완전한 병인, 즉시 치유, 내부 의학 판단 | MED, LAW |
| 지도·경로 요구 | 공개길, 우회로 소문, 검문, 통행세를 답한다. | 현재 위치, 여행권, 지역 안내자 | 전체 지도, 숨은 길, 제한 검문망 | INF, LOC |
| 내부 문서 요구 | 문서 존재, 거절, 일부 인용, 낭독 가능 범위를 답한다. | 관할, 신분, 보증인, 비용 | 전문 공개, 내부 해석, 지휘 판단 | LAW, POL |
| 신분·혈통을 주장한다 | 의심, 증인 요구, 이름패·문장 확인으로 낮춘다. | 공문서, 증인, 봉인된 장부 접근권 | 혈통 확정, 왕권·상속권 즉시 인정 | SOC, LAW, POL |
| 경제·창고를 조작하려 한다 | 줄, 장부, 점원, 보초, 길드 반응을 답한다. | 접근권, 물자 규모, 문서 위조 여부 | 전체 배분 논리, 창고 총량, 공급망 약점 | ECO, SEC |
| 세계 설정 설명을 요구한다 | 설정 설명과 인물 응답을 분리한다. | 사용자가 설정 설명을 명시했는지 | 인물에게 객관 정본 지식을 주입 | WORLD, CIV |

이 기준은 응답의 우선순위를 정한다. 작은 인물의 행동은 관측, 소문, 문서 접수, 대기, 비용, 거절, 낮은 평판 변화에서 시작하며, 큰 변화는 다른 대분류의 조건이 같이 충족될 때만 열린다.

### CK5083-ANSWER-LOW-SURFACE-ROUTING-001. 낮은 표면 우선 라우팅 기준

사용자 인물이 행동하면 응답은 먼저 가까운 생활 표면으로 내려간다. 같은 행동도 위치, 신분, 소속, 소지 문서, 관계, 날씨, 권위층 거리에 따라 다른 표면으로 열리며, 상위 정치·전승·사건 변화는 낮은 흔적이 반복되거나 여러 권위층에 기록될 때만 연결한다.

| 행동 입력 | 먼저 여는 표면 | 확인할 낮은 값 | 누적될 수 있는 흔적 | 상위 연결 조건 | 금지선 |
|---|---|---|---|---|---|
| 길을 나선다 | 길 상태, 날씨, 짐, 성문·나루·숙소 | 현재 위치, 목적지, 통행권, 피로, 동행자 | 지연, 비용, 소문, 작은 부상, 보초 기억 | 검문 강화, 물자 운송, 보건 의심, 군사 태세가 겹칠 때 | 전체 지도와 숨은 경로를 즉시 제공하지 않는다. |
| 사람에게 묻는다 | 화자층, 거리감, 소문, 모른다는 반응 | 상대 직능, 관계, 언어, 평판, 질문 위험도 | 낮은 정보, 거절, 오해, 소개, 의심 | 같은 질문이 기관·권위·문서로 올라갈 때 | 질문만으로 비밀 진상이나 내부 의도를 노출하지 않는다. |
| 물건을 산다 | 장터 말, 품질, 계절, 보증, 가격 흔들림 | 돈, 교환물, 물품 출처, 상인 평판 | 외상, 장부 주석, 소문, 작은 채무 | 대량 구매, 위조 표식, 금기 물품, 군수품이 걸릴 때 | 전역 시세나 공급망 약점을 기본값으로 말하지 않는다. |
| 도움을 청한다 | 관계, 보증, 비용, 체면, 의무 | 누구에게, 왜, 무엇을 대가로, 얼마나 급한지 | 작은 호의, 빚, 평판 변화, 거절 기억 | 반복 호의, 생명 위기, 권위층 보증이 겹칠 때 | 호의를 곧 동료화나 충성으로 처리하지 않는다. |
| 싸우거나 막는다 | 소란, 피해, 목격자, 보초 거리 | 무기, 장소, 피해 규모, 상대 신분 | 상처, 평판, 증언, 억류, 보복 소문 | 사망, 집단 폭력, 무장 충돌, 접경 태세가 걸릴 때 | 개인 폭력을 전쟁·혁명·영웅담으로 즉시 키우지 않는다. |
| 문서를 보려 한다 | 공개 낭독, 요약, 서기관 해설, 거절 | 문서 종류, 접근권, 비용, 보증인 | 일부 인용, 접수 기록, 의심, 대기 | 당사자 지위, 상위 권위 위임, 사건 문서가 있을 때 | 전문과 봉인 사유, 내부 판단을 바로 공개하지 않는다. |
| 치료를 구한다 | 증상, 물맛, 냄새, 약초, 돌봄 절차 | 상처·병세, 돈, 신전 접근, 격리 위험 | 치료 기록, 가족 말, 약초 비용, 격리 표식 | 사망, 전염 의심, 이단 논쟁, 대량 환자가 겹칠 때 | 병인과 내부 의학 판단을 기본값으로 주지 않는다. |
| 이름·신분을 주장한다 | 이름패, 증인, 보증, 문장, 발음 차이 | 소지 증표, 기억하는 사람, 지역명, 문서명 | 의심 완화, 재확인, 낮은 소문, 보증 부담 | 상속, 통행권, 판결, 피난민 지위가 걸릴 때 | 주장만으로 혈통·왕권·종족 자칭을 확정하지 않는다. |
| 장소에 들어간다 | 외벽, 줄, 표식, 보초, 냄새와 소리 | 출입 이유, 보증, 소속, 금지 표식 | 대기, 짐 검사, 낮은 단서, 출입 기록 | 제한 내부, 법정, 무기고, 봉인 문서가 걸릴 때 | 장소명을 내부 정보 접근권처럼 쓰지 않는다. |
| 전승을 말한다 | 주변 반응, 장터 소문, 신전 주석, 공연판 | 누가 들었는지, 어느 지역 말인지, 어떤 문구인지 | 놀람, 비웃음, 기억, 소문 확산 | 반복 문구, 권위 이용, 사건 기록과 맞물릴 때 | 발화만으로 예언 성취나 초자연 사실을 확정하지 않는다. |
| 권위층을 움직이려 한다 | 접수처, 하급자, 대기, 보증 요구 | 신분, 후원자, 문서, 공개 위험, 비용 | 청원서, 무시, 지연, 낮은 주시 | 다수 증언, 물자 손실, 정치 명분, 상급 문서가 겹칠 때 | 왕실·군대·의회가 즉시 반응한다고 쓰지 않는다. |
| 세계 지식을 묻는다 | 인물 지식과 설정 설명을 분리한다 | 사용자가 원하는 응답 모드, 화자층, 접근권 | 인물 응답에서는 모름·소문·일부 지식 | 설정 설명 요청이 명확할 때 | 객관 정본값을 인물 상식으로 주입하지 않는다. |

낮은 표면 라우팅은 행동을 축소하기 위한 제한이 아니라, 세계가 실제로 반응하는 순서를 보존하기 위한 기준이다. 작은 행동은 작은 흔적을 남기고, 그 흔적이 반복되어 문서·권위·장소·전승을 함께 움직일 때만 큰 변화로 확장된다.

| 제한 항목 | 기준 |
|---|---|
| 객관 물리 노출 | F형 항성, AU, 질량, 반지름, 광도, K 단위 온도, 기압·kPa, 대기 조성 비율, 조석력, 자기권 수치, 오존층 구조, 탈출속도, 궤도 안정성은 인월드 인물 발화로 직접 말하지 않는다. |
| 통용 지식 우선 | 인물은 자기 문화권, 직업, 학술 수준에 맞는 명칭과 설명을 사용한다. |
| 학술층 예외 | Windwatch·Sunspire급 인물은 관측표, 위상표, 절기 오차, 떠돌이별 주기를 말할 수 있지만 현대 물리 원인은 말하지 않는다. |
| 정본명 사용 | Arion, Caelum, Umbra 같은 정본명은 문서 관리와 정본 기준이다. 인월드 발화에서는 문화권별 명칭을 우선한다. |
| 세계명 사용 | Vireth는 정본명이다. 일반 인물은 국가·대륙·영지·신앙권을 세계 인식의 기본 단위로 삼는다. |
| 공용서기어 제한 병기명 | `Gardel`, `Kordor`, `Zelvar`, `Yentor`, `Artor`처럼 정본명이나 생활명을 즉시 대체하지 않는 이름은 서기관, 장부, 지도, 법정 주석에서만 병기한다. |
| 피난민 내부 자칭 | `Rendel`은 Newhollow 생존자 공동체의 내부 자칭으로 쓸 수 있으나, Ravenstone 관청의 외부 행정명 `Newhollow`나 공동 창고명 `Rendel Pukum`을 대체하지 않는다. |
| 정본명 전환 표면명 | `Linrenet`, `Vekdoret`, `Senhalet`, `Kelnavet`, `Nimnaret`, `Nimsoret`, `Silhalet`처럼 전환표에 오른 이름은 적용 범위 안에서 정본 표제에 쓴다. 이전 이름은 브리지 라벨과 독자 연결로 남긴다. |
| 종족 공문서 외명 | `Ferbrunir`, `Silrenir`, `Mersenir`, `Nimsorir` 같은 외명은 공문서·학술·지도용 분류명이다. 자칭, 내부 종족어, 객관 생물 분류를 대신하지 않는다. |
| 종족 전승 외명 | `Rensilir`, `Sorsilir` 같은 이름은 Sylvania 계열 전승·고문서·외부 호칭에 묶어 두고, 현행 공문서 외명이나 자칭처럼 쓰지 않는다. |
| 장주기 현상 | 객관 주기표를 인물 예언처럼 발화하지 않는다. 관측된 이상과 문화권별 해석만 발화한다. |
| 작은 인물 기본값 | 신분, 직업, 소속, 위치가 지정되지 않은 사용자 인물은 일상 민간 지식과 가까운 지역 정보만 기본으로 가진다. |
| 숨은 정보 요청 | 진상, 원흉, 봉인된 원인, 비공개 문서를 묻는 질문은 접근 가능한 징후, 소문, 증언, 기관의 침묵·거절로 낮춰 답한다. |
| 확인 불가·거부 | 사건 문서, 접근권, 관측 근거가 없으면 모른다, 말이 갈린다, 확인할 길이 없다, 해당 권위가 답하지 않는다고 처리한다. |
| 설정 설명 전환 | 사용자가 설정 설명을 명시할 때만 객관 정본값을 말한다. 이때도 인월드 표면과 정본 관리층 사실을 분리한다. |
| 학술층 접근권 | 학술 지식은 학당, 관측소, 문서관, 관청, 신전 기록 접근권이 있을 때만 넓힌다. 직업이나 신분이 없으면 학술층을 기본값으로 주지 않는다. |
| 군사·기관 기밀 | 보초표, 동원 장부, 병참표, 무기고 장부, 지휘 계획은 공개 증상, 현장 소문, 하급 실무 지식, 내부 문서, 지휘층 판단을 분리한다. |
| 언어 산출 체계 | `meaning_id`, 산출 절차, 전체 문자 변환표는 인월드 일반 지식이 아니다. 서기관과 점원도 이름, 수량, 인장, 정형 문구 중심으로 읽는다. |
| 응답 표면 필드 | `retrieval_surface`, `access_surface`, `visibility_scope`, `route_visibility`, `speech_exposure`가 없으면 가장 낮은 접근 표면으로 먼저 답한다. |
| 위치 미지정 | 사용자 인물의 위치가 없으면 대표 장소를 자동 선택하지 않는다. 가까운 단서가 없으면 일반 현장 감각과 추가 위치 확인으로 처리한다. |
| 경로·지도 요청 | 작은 인물에게는 다음 길, 공개 우회로, 통행세, 가까운 검문 소문만 준다. 전체 지도, 제한로, 숨은 검문망은 접근권이 있을 때만 다룬다. |
| 상업·구휼 내부 장부 | 가격, 배급, 부채, 노동일, 창고 수량은 보이는 효과, 공개 규칙, 개인 문서, 장터 소문으로 낮춘다. 전체 장부와 배분 논리는 노출하지 않는다. |

| `network_scope` | 길, 항로, 수로, 창고망, 봉화·전령, 장터 소식, 검문망 | 이동·소식·시설망의 범위와 끊김을 정한다. | 전역 동시 통신이나 현대 물류망처럼 쓰지 않는다. |

| `access_surface` | 보임, 공개 낭독, 소문, 통상 민원 응답, 제한 내부, 봉인·거절 | 작은 인물이 어떤 경로로 정보를 접할 수 있는지 정한다. | 접근 표면 없이 장부·지도·문서 내용을 바로 알려 주지 않는다. |
| `visibility_scope` | 공개 외부, 공개 대기열, 동행 허가, 노동자·하인 접근, 군사 내부, 상위 권력 사적 공간 | 장소와 기관 내부가 누구에게 보이는지 정한다. | 장소 목록을 곧 내부 구조 지식으로 쓰지 않는다. |

| `health_scope` | 질병, 상처, 출산, 사망, 위생, 약초, 격리, 의례 처방 | 몸과 치료를 어느 문서·권위·직능이 다루는지 정한다. | 현대 의학, 죄, 저주, 기적 중 하나로 닫지 않는다. |

통제 어휘는 표의 열 이름을 모두 같게 만들기 위한 장치가 아니라, 서로 다른 섹션의 자연어 열을 같은 DB 필드로 되돌리기 위한 기준이다. 예를 들어 `기록 주체`, `사용 주체`, `주 사용자`는 문맥에 따라 `speaker_scope`, `authority_layer`, `document_scope` 중 하나로 환산한다. 응답 표면 필드가 없는 세부 표는 `speaker_scope`, `document_scope`, `authority_layer`, `place_function`을 조합해 가장 낮은 접근 표면으로 먼저 낮춘다.

### CK5083-WORLD-NATURAL-ANCHOR-FIELD-001. 하위 대분류 자연 닻 포인터

기준시대 객관정보는 사회·제도·언어를 다루지만, 그 사회가 놓인 자연 조건을 잃으면 장면 편의에 따라 세계가 흔들린다. 따라서 자연 조건이 영향을 주는 대분류는 `natural_anchor_refs` 또는 그에 준하는 약한 연결 필드를 가진다.

| 필드 | 의미 | 주 적용 대분류 | 적용 기준 | 금지선 |

### CK5083-WORLD-DOMAIN-REGISTRY-001. 기준시대 대분류 등록 기준

5083 기준시대 객관정보의 대분류는 많을수록 좋은 색인이 아니라, 기준시대의 여러 이야기가 공통으로 참조할 운용축이다. 독립 대분류로 승격하려면 해당 주제가 여러 국가·권역·직능·문서층을 동시에 움직이고, 하위 항목으로만 두면 답변 기준이 반복적으로 흔들려야 한다.

| 대분류군 | 활성 대분류 | 역할 | 승격 기준 |
|---|---|---|---|
| 세계·자연·명칭 | WORLD, AST, NOM, CAL, GEO | 객관정보를 5083년 지식층과 명칭층으로 바꾸는 기반 | 자연·시간·권역·명칭이 다른 모든 단락의 전제일 때 |
| 사회 운용 | SOC, POL, SEC, CRS, ECO | 사람들이 살고, 지배받고, 움직이고, 위기에 대응하는 기준시대 질서 | 생활·권력·치안·물자·위기가 여러 문서층을 가를 때 |
| 물질·망·몸 | TEC, INF, MED | 기술 한계, 이동·소식망, 질병·치료의 재현 가능 범위 | 장면 편의로 흔들리기 쉬운 능력·속도·신체 조건을 제한할 때 |
| 제도·기록·기억 | LAW, FAI, CIV, LOC, LORE | 법, 신앙, 언어, 장소, 전승을 권위와 기억의 층위로 관리 | 사실·명칭·전승·의례·문서 권위가 서로 충돌할 때 |

| 독립 대분류로 올리지 않는 항목 | 배치 기준 |
|---|---|
| 인구통계, 가구, 혼인, 신분, 교육, 축제 참여 | SOC의 하위축으로 둔다. 법적 효력은 LAW, 문해와 기록은 CIV, 절기 날짜는 CAL, 의례 참여는 FAI에 연결한다. |
| 농업 기술, 목축 기술, 수확량 | ECO의 생업·물자 흐름에 두고, 도구와 공정만 TEC로 연결한다. |
| 건축, 제련, 조선, 보존 기술 | TEC의 하위축으로 둔다. 특정 시설은 LOC, 물자 흐름은 ECO, 군수 사용은 SEC에 연결한다. |
| 도로, 항로, 전령, 봉화, 소문 전달 | INF의 하위축으로 둔다. 장부와 문자 매체는 CIV, 시장 소문은 LORE, 통행 허가는 LAW·SEC에 연결한다. |
| 범죄, 반국가 세력, 국경 단속 | SEC와 LAW로 나눈다. 법적 분류는 LAW, 대응 태세와 검문은 SEC에 둔다. |
| 피난민, 이주, 구휼 | 상시 정치 지위는 POL·SOC, 물자 배급은 ECO, 위기 절차는 CRS, 장소 기능은 LOC에 연결한다. |
| 역사, 전투, 재난, 재판의 상세 사건 | 기준시대 객관정보가 아니라 역사·사건 문서로 내린다. 기준시대 객관정보에는 현재 상태와 대응 절차만 둔다. |
| 초자연 실재, 마법 체계 | 객관정보에 확정된 별도 규칙이 생기기 전까지 LORE·LAW·CIV의 해석층으로만 둔다. |

### CK5083-WORLD-CROSS-DOMAIN-ROUTING-001. 대분류 충돌 우선순위

하나의 설정 항목이 여러 대분류에 걸릴 때는 먼저 주도 대분류를 고르고, 나머지는 연결 대분류로 둔다. 이 규칙은 정보를 한 장에 몰아넣기 위한 것이 아니라, 같은 내용을 여러 장에서 서로 다른 결론으로 쓰지 않기 위한 라우팅 표다.

| 충돌 사안 | 주도 대분류 | 연결 대분류 | 판단 기준 | 금지선 |
|---|---|---|---|---|
| 길이 막히거나 우회가 필요한 상태 | INF | SEC, CRS, ECO | 물리 이동 가능성, 지연, 우회로, 소식 전달을 먼저 본다. | 검문·처벌·봉쇄 책임까지 INF에서 확정하지 않는다. |
| 검문, 압류, 억류, 무장 통제 | SEC | LAW, INF, CRS | 실제 통제 행위와 태세를 먼저 본다. | 죄목·판결·배상까지 SEC에서 확정하지 않는다. |
| 죄목, 배상, 관할, 증거 | LAW | SEC, CIV, LORE | 어떤 권위가 어떤 문서로 책임을 주장하는지 먼저 본다. | 법 문서 하나로 민간 기억과 전승을 닫지 않는다. |
| 봉납, 장례, 맹세, 금기일, 정화 의례 | FAI | LAW, MED, CAL, LORE | 신앙이 생활 행동과 권위 언어에 닿는 방식을 먼저 본다. | 의례를 객관 초자연 작용이나 법적 판결로 바로 올리지 않는다. |
| 피난, 구휼, 봉쇄, 위기 단계 | CRS | ECO, SEC, MED, LOC | 위기 절차와 단계 전환을 먼저 본다. | 재난 장면이나 역사 사건으로 바로 올리지 않는다. |
| 배급, 세금, 채무, 물자 손실 | ECO | CRS, LAW, SOC | 장부와 실제 물자의 차이를 먼저 본다. | 물자 문제를 현대 시장 가격이나 단일 화폐로 환원하지 않는다. |
| 질병, 치료, 위생, 격리 돌봄 | MED | LAW, CRS, SOC | 몸과 돌봄, 처방, 실패 논쟁을 먼저 본다. | 질병 원인을 죄, 저주, 현대 병명 중 하나로 닫지 않는다. |
| 명칭, 병기명, 자칭, 외부 호칭 | NOM | CIV, GEO, LOC | 이름층과 사용 범위를 먼저 본다. | 병기명을 정본명이나 자칭으로 자동 승격하지 않는다. |
| 문해, 번역, 낭독, 기록 보존 | CIV | NOM, LAW, LORE | 기록 매체와 해석 권위를 먼저 본다. | 문서가 있다는 이유로 모두가 내용을 안다고 쓰지 않는다. |
| 장소 기능, 기억 장소, 하위 시설 | LOC | GEO, LAW, LORE | 장소가 생산하는 기록·권위·기억을 먼저 본다. | 장소를 지도 좌표나 인물 장면 배경으로만 고정하지 않는다. |
| 상징, 예언 파편, 지역 구전 | LORE | CIV, LAW, AST | 사실층이 아니라 기억·비유·전승층을 먼저 본다. | 전승을 객관 사실, 확정 예언, 숨은 혈통 증명으로 올리지 않는다. |

대분류 충돌은 오류가 아니라 기준시대의 기본 상태다. 같은 항목이 여러 문서층에 남는 경우, 정본은 하나의 결론으로 합치지 않고 주도 대분류와 연결 대분류를 나누어 기록한다.

### CK5083-WORLD-EXCEPTION-INDEX-001. 지역·권위·문서 예외 색인

기준시대 객관정보는 전역 규칙을 먼저 두되, 지역·권위·문서 예외를 허용한다. 예외는 전역값을 지우는 대체 설정이 아니라, 특정 권역이나 문서층에서 전역값이 다르게 보이는 운용값이다.

| 예외 필드 | 기록할 값 | 적용 예 | 금지선 |
|---|---|---|---|
| `region_scope` | 국가, 영지, 항만, 성채, 사원권, 산악권, 피난민 정착지 | Ravenstone 접경권, Norgard 항만, Silnimet 산악 수도원 | 지역 예외를 Vireth 전체 기준으로 확대하지 않는다. |
| `domain` | 예외가 속한 주도 대분류 | CAL, LAW, INF, ECO, MED | 모든 대분류를 동시에 고치는 예외로 만들지 않는다. |
| `exception_source` | 자연 조건, 권위층, 문서층, 관습, 언어, 기록 손실 중 하나 | 항로 계절, 신전 금기, 길드 장부, 피난민 이름패 | 예외 원인을 초자연 실재로 확정하지 않는다. |
| `overrides_default` | 전역값을 덮는지, 주석만 붙는지, 특정 화자층에만 다른지 | 관청력과 신전력의 날짜 차이, 항만 통행명 | 기본값을 완전히 없애지 않는다. |
| `allowed_range` | 예외가 허용되는 범위와 한계 | 한 항만, 한 성채, 한 사원권, 한 장부군 | 예외를 이야기 편의에 따라 무한 확장하지 않는다. |
| `fallback_default` | 예외 설명이 없을 때 되돌아갈 기준값 | 각 대분류의 기본 기준시대 객관정보 | 예외가 불명확할 때 새 사실을 만들어 채우지 않는다. |

예외 색인은 이후 기준시대 세부 설정을 추가할 때 전역 규칙을 기계적으로 굳히지 않기 위한 장치다. 새 지역·장소·직능이 생기면 먼저 예외 색인에 걸리는지 확인하고, 걸리지 않으면 해당 대분류의 기본값을 따른다.

### CK5083-WORLD-CAPACITY-FRICTION-001. 집행 능력과 불완전 이행 기준

5083년의 권위는 명령을 내릴 수 있어도 항상 같은 속도로 실행하지 못한다. 명령, 판결, 구휼, 동원, 수리, 격리, 낭독은 거리, 인력, 물자, 문해, 저항, 기록 손실 때문에 흔들린다.

| 마찰 필드 | 의미 | 주 연결 대분류 | 허용 효과 | 금지선 |
|---|---|---|---|---|
| `enforcement_capacity` | 명령·판결·검문을 실제로 실행할 수 있는 인력과 권위 | LAW, SEC, POL | 같은 명령도 수도와 접경에서 다르게 실행된다. | 권위가 말하면 즉시 전역에서 시행된다고 쓰지 않는다. |
| `compliance_level` | 주민, 길드, 신전, 병사, 피난민이 얼마나 따르는지 | SOC, ECO, LAW | 공개 순응과 실제 회피가 함께 있을 수 있다. | 불복종을 곧 반란이나 악의로 단정하지 않는다. |
| `delay_cost` | 지연이 만들 수 있는 물자·평판·질병·치안 비용 | INF, CRS, MED, ECO | 늦은 명령이 굶주림, 소문, 치료 실패를 키운다. | 지연을 단순 운송 시간 문제로만 처리하지 않는다. |
| `local_resistance` | 지역 관습, 길드 이해, 신전 권위, 피난민 기억이 만드는 저항 | POL, LAW, CIV | 공식 명령이 지역 주석과 다른 해석을 거쳐 약해진다. | 지역 저항을 현대 정치 운동으로 바로 번역하지 않는다. |
| `record_gap` | 기록 누락, 낭독 누락, 이름 오기, 사본 손상이 만든 빈틈 | CIV, LAW, LOC | 같은 사람이 장부마다 다른 지위를 가질 수 있다. | 기록 공백을 항상 음모나 예언으로 처리하지 않는다. |

불완전 이행은 기준시대의 사실성을 만드는 핵심 변수다. 이 변수는 세계를 무질서하게 만들기 위한 장치가 아니라, 전근대적 권위와 물자망의 한계를 정본 안에 남기는 기준이다.

### CK5083-WORLD-CLAIM-CONFIDENCE-001. 주장 신뢰도와 기록 경합 기준

`document_scope`는 곧 사실 등급이 아니다. 같은 정보도 관측표, 장부, 증언, 구전, 소문, 신전 주석, 공연 기록에서 서로 다른 신뢰도를 가진다.

| 주장 상태 | 의미 | 대표 매체 | 응답 기준 | 금지선 |
|---|---|---|---|---|
| 관측됨 | 누군가 직접 보거나 측정해 기록했다. | 관측표, 보초 기록, 항해 일지 | 관측자, 장소, 날짜 체계를 함께 붙인다. | 관측을 현대 과학 설명으로 자동 승격하지 않는다. |
| 장부에 있음 | 세금, 물자, 통행, 배급, 치료, 납품으로 기록되었다. | 장부, 명부, 납품서, 배급표 | 장부 권위와 실제 생활량의 차이를 함께 둔다. | 장부 수치를 실제 상태의 절대값으로 쓰지 않는다. |
| 증언됨 | 개인이나 공동체가 말로 남겼다. | 증언 목패, 법정 증언, 구전 | 신분, 통역, 편견, 기억 손상을 함께 검토한다. | 증언을 곧 거짓이나 절대 진실로 처리하지 않는다. |
| 권위층이 주장함 | 왕실, 신전, 길드, 성채, 공동체가 해석을 붙였다. | 판결문, 설교, 길드 청원, 군사 보고 | 권위층의 이해관계와 문서층을 병기한다. | 권위층 주장을 객관 사실로 확정하지 않는다. |

| 논쟁 중 | 둘 이상의 기록층이 다른 결론을 낸다. | 판결문, 이름패, 공연 기록, 신전 주석 | 서로 다른 기록층을 병렬로 둔다. | 하나를 골라 나머지를 소거하지 않는다. |

정본은 주장 신뢰도를 숫자로 점수화하지 않는다. 대신 누가, 어디서, 어떤 매체로, 어떤 권위를 걸고 말했는지를 기록해 이후 세부 설정이 같은 기준으로 파생되게 한다.

시간이 지나면 명령, 물자, 시설, 기록, 기억, 신뢰는 같은 속도로 약해지지 않는다. 이 단락은 기준시대 정보가 시간 경과에 따라 어떻게 변형되는지 정한다.

### CK5083-WORLD-POSSIBILITY-ENVIRONMENT-001. 가능 환경과 단일 행동 강제 금지 기준

| 배경 조건 | 사건이 아니라 기준시대에 깔린 압력이나 위험이다. | 국경 긴장, 절기 오차, 물자 부족 가능성 | 관련 카테고리와 자연 오버레이 | 배경 조건만으로 전투·재난·판결을 확정하지 않는다. |
| 현재 통용상 | 5083년 사람들이 널리 알고 쓰는 현재 상태다. | Newhollow 정착, Ravenstone 통행 허가, 국가별 신앙 법층 | 기준시대 객관정보 본문 | 특정 장면이나 개인 경험으로만 좁히지 않는다. |
| 문서화된 사건 | 별도 역사·사건 문서로 내려가야 하는 구체 사건이다. | Greenhollow 상실, 판결문, 점령 전환, 대형 재해 | 역사·사건 문서 ID | 기준시대 객관정보 본문에서 상세 서사로 장면화하지 않는다. |
| 논쟁 중인 기록 | 공식 문서와 민간 기억, 신전 해석이 서로 다른 사건이다. | 낮은 율례, 피난민 증언, 세금 면제 논쟁 | 법 문서, 이름패, 구전, 주석 | 하나의 기록만 절대 진실로 처리하지 않는다. |
| 전승 파편 | 사건 여부보다 상징·소문·예언으로 남은 기억이다. | Xerxes의 검은 조각, 예언 파편, 꼬리별 구전 | LORE 문서층 | 전승을 객관 사실이나 확정 예언으로 올리지 않는다. |
| 사건 없음 | 명칭, 제도, 언어 규칙처럼 사건으로 취급하지 않는 항목이다. | 명칭층, 문자표, 필드 정의 | 해당 관리 단락 | 규칙 정의를 인월드 사건처럼 말하지 않는다. |

정본 작성자는 특정 항목을 확장하기 전에 사건성 상태를 먼저 고른다. 이 선택은 분량을 줄이기 위한 장치가 아니라, 기준시대 DB와 역사·사건 문서가 서로를 침범하지 않도록 막는 경계다.

### CK5083-WORLD-CHATBOT-RESPONSE-MODE-001. 챗봇 응답 모드 선택 기준

챗봇에서 사용자가 5083년의 한 인물로 행동할 때 기본 응답 표면은 정본 설명층이 아니라 그 인물이 닿을 수 있는 장소, 소문, 문서, 권위, 감각이다. 사용자의 신분, 직업, 소속, 위치가 지정되지 않으면 `speaker_scope=일상 민간 지식`, 좁은 `region_scope`, 가까운 `place_function`을 기본값으로 둔다.

| 모드 | 사용 조건 | 먼저 확인할 필드 | 응답 표면 | 금지선 |
|---|---|---|---|---|
| 현지 지각 | 사용자 인물이 주변, 행동 결과, 가까운 장소를 묻는다. | `region_scope`, `speaker_scope`, `social_scope`, `place_function`, `network_scope` | 보이는 것, 들은 말, 가까운 절차와 즉각 반응 | 전역 정본, 관리 ID, 원거리 기관 지식을 직접 말하지 않는다. |
| 소문 | 출처가 장터, 항만, 병영, 하인 계단, 구전이다. | `document_scope`, `memory_layer`, 주장 신뢰도 | 누가 어디서 떠드는지와 낮은 신뢰도 | 소문만으로 사건을 확정하지 않는다. |
| 기관 반응 | 관청, 성문, 신전, 길드, 법정, 성채에 접근한다. | `authority_layer`, `jurisdiction_conflict`, `enforcement_capacity`, `document_scope` | 접수, 보류, 거절, 낭독, 검문, 요구 문서 | 기관 발언을 객관 진실로 확정하지 않는다. |
| 불확실·거부 | 미관측, 미공개, 논쟁 중, 사건 문서 없음 상태다. | `event_instance_status`, 주장 신뢰도, `fallback_default` | 모른다, 확인 불가, 말이 갈린다, 해당 권위가 답하지 않는다. | 빈칸을 새 사실로 채우지 않는다. |
| 설정 설명 | 사용자가 설정, 정본, 관리층 설명을 명시한다. | 설정 설명층, 객관정보 정본, 자연 오버레이 | 정본 관리층 사실과 인월드 표면을 분리해 설명 | 설정 설명을 인물 발화로 섞지 않는다. |
| 숨은 정보 | 봉인, 제한 공개, 관리층 진상, 사건 문서 없음 상태, 알 수 없는 동기다. | `document_scope`, `authority_layer`, `record_gap`, 공개 범위 | 접근 가능한 징후, 소문, 기관의 침묵·회피만 말한다. | 숨은 진실을 세계 반응으로 노출하지 않는다. |

| 접근권 | 기본 허용 정보 | 추가 조건 | 금지선 |
|---|---|---|---|
| 일상 민간 | 자기 거처, 장터, 가족·가구, 세금·날씨·소문, 가까운 신전·성문 반응 | 지역 공동체 증언, 공개 낭독, 장터 말 | 대륙 정세, 객관 자연값, 봉인 문서, 궁정 내막을 바로 알지 않는다. |
| 직능 | 직업 도구, 장부 일부, 길·항로·약초·보초·거래 관습 | 도제명부, 길드 보증, 상단 계약, 현장 경험 | 직능 지식을 전역 학술 지식으로 올리지 않는다. |
| 기관 내부 | 관청, 길드, 신전, 성채의 절차와 제한 공개 문서 | 소속, 직책, 허가, 보증인 | 내부 문서를 곧 최종 진실이나 전체 공개 정보로 쓰지 않는다. |
| 학술·기록 | 관측표, 주석, 필사본, 넓은 지명과 환산 체계 | 학당·관측소·문서관 접근권 | 학술층을 현대 과학자나 전지적 해설자로 쓰지 않는다. |
| 상위 권력 | 외교문, 왕실 판결, 고급 군사·정치 정보의 일부 | 신분, 임무, 공식 문서, 허가 | 권력 접근권을 사용자 기본값으로 주지 않는다. |
| 봉인·비공개 | 소문, 침묵, 거절, 문서 존재의 흔적 | 별도 사건 문서 또는 명시된 접근권 | 봉인된 원인과 진상을 응답 편의로 누설하지 않는다. |

질문이 진상, 원흉, 숨은 원인, 세계 전체의 구조를 요구하더라도 인월드 인물 응답에서는 먼저 접근권을 확인한다. 접근권이 없으면 문서층, 소문, 증언, 기관의 거절, 확인 불가로 낮추고, 객관 정본값은 설정 설명 모드에서만 분리해 말한다.

### CK5083-WORLD-SMALL-PERSON-SURFACE-001. 작은 인물 응답 표면과 접근 사다리

작은 인물 응답은 정보를 거절하기 위한 장치가 아니라, 세계가 실제로 접히는 순서를 정하는 장치다. 먼저 보이는 것과 가까운 말, 그다음 공개 낭독과 서기관, 그다음 보증인과 직능 접근, 마지막으로 기관 내부 문서와 상위 권력 문서로 올라간다.

| 요청 유형 | 작은 인물 기본 응답 | 접근이 있으면 추가되는 것 | 금지선 |
|---|---|---|---|
| 위치 미지정 현장 묘사 | 특정 도시·성채·정착촌을 임의로 고르지 않고, 가까운 지역 단서가 필요하다고 처리한다. | 사용자가 위치, 소속, 동행자, 이동 경로를 주면 해당 `region_scope`와 `place_function`으로 좁힌다. | Ravenstone, Newhollow, Tiris 같은 대표 장소를 기본 배경으로 자동 선택하지 않는다. |
| 경로·지도 요청 | 다음 갈림길, 성문, 공개 길, 통행세, 소문난 위험만 말한다. | 상단, 길드, 군사, 관청 허가가 있으면 해도, 통행 허가, 우회로, 검문 사유를 일부 말할 수 있다. | 전체 경로표, 숨은 검문망, 군사 제한로, 지도 ID를 한 번에 말하지 않는다. |
| 가격·노동·부채 질문 | 가까운 장터 말, 계절 부족, 게시된 노동일, 개인 장부에 적힌 의무로 답한다. | 상인, 서리, 장부 담당자, 길드 보증이 있으면 품목별 장부 기준과 환산 관습을 말할 수 있다. | 전역 시세, 정확 환산표, 숨은 채무 구조를 작은 인물 기본값으로 주지 않는다. |
| 구휼·피난·배급 질문 | 줄, 이름패, 보증인, 노동 제공, 공개 낭독, 오늘 받을 수 있는 몫으로 답한다. | 관청·신전·성채 내부 접근이 있으면 우선순위 논리와 보류 사유를 제한적으로 말한다. | 구휼 전체 배분표나 정책 의도를 바로 설명하지 않는다. |
| 질병·치료 질문 | 냄새, 물맛, 열, 피로, 격리 표식, 약초상·신전·돌봄 절차로 답한다. | 치료자, 수도원, 군사 치료자, 학술층 접근이 있으면 처방 논쟁과 기록층을 말한다. | 병인, 임계값, 저수지·수권 구조, 현대식 진단을 인물 발화로 확정하지 않는다. |
| 기술·품질·공정 질문 | 균열, 맞지 않는 부품, 반복 고장, 수리 거부, 가격 조정, 길드 소문으로 답한다. | 장인, 길드, 군수 담당자 접근이 있으면 공정 단계와 재료 책임을 일부 말한다. | 제작법, 공급망 약점, 군수 품질 실패 원인을 바로 말하지 않는다. |
| 명칭·언어 질문 | 그 지역에서 실제로 부르는 이름, 공문서에 보이는 이름, 읽지 못하는 표식 정도로 답한다. | 서기관, 통역자, 학당 접근이 있으면 병기명과 문서층을 설명할 수 있다. | `meaning_id`, 형태 분해, 산출 절차, 전체 문자표를 인물 지식으로 말하지 않는다. |
| 기관 내부·사적 공간 질문 | 문 앞 대기, 공개 외부, 들리는 소문, 출입 거절, 필요한 보증으로 답한다. | 하인, 병사, 서기관, 수행원, 허가받은 방문자이면 해당 동선의 일부만 보인다. | 방 배치, 상위 권력 사적 대화, 내부 장부 위치를 기본으로 노출하지 않는다. |
| 설정 설명과 인물 응답이 섞인 질문 | 설정 설명과 인물 응답을 분리하거나, 인물 응답에서는 접근 제한을 유지한다. | 사용자가 명확히 설정 설명만 원하면 객관 정본값을 별도로 설명한다. | 설정 설명을 근거로 인물에게 숨은 진실을 알게 하지 않는다. |

| 접근 단계 | 인물이 할 수 있는 행동 | 얻을 수 있는 정보 | 넘지 못하는 선 |
|---|---|---|---|
| 관찰 | 본다, 듣는다, 냄새 맡는다, 줄을 선다, 표식을 본다. | 현장 감각, 공개 반응, 가까운 위험 | 원인, 책임, 내부 계획 |
| 묻기 | 이웃, 장터, 하인, 병사, 약초상, 선원에게 묻는다. | 소문, 생활 조언, 낮은 신뢰도 경고 | 문서 내용 확정, 기관 의도 |
| 공개 낭독 | 성문, 신전, 장터, 관청 앞 낭독을 듣는다. | 공표된 명령, 날짜, 금지, 통행 조건 | 빠진 문구, 내부 주석, 봉인 문서 |
| 서기관 의뢰 | 문서를 읽어 달라고 하거나 이름을 적는다. | 자기 문서, 공개 장부 일부, 이름·수량·인장 | 전체 장부, 타인의 봉인 기록 |
| 보증인·직능 | 길드, 신전, 상단, 부대, 공동체 보증을 얻는다. | 직능 관습, 제한 문서, 다음 절차 | 상위 권력 판단, 군사 계획 |
| 허가·소속 | 관청·성채·학당·신전 내부 권한을 얻는다. | 제한 내부 문서, 절차 이유, 보류 사유 | 봉인된 진상, 정본 관리층 사실, 객관 관리값 |

### CK5083-WORLD-ACTION-TIME-COST-001. 행동 시간비용과 즉시 처리 제한

기준시대 행동은 현대식 즉시 처리 버튼이 아니다. 작은 인물이 무엇을 하려면 걷고, 줄을 서고, 기다리고, 누군가를 설득하고, 서기관을 찾고, 몸을 쉬게 하는 시간이 필요하다. 정본은 정확한 분 단위 계산보다 어떤 행동이 같은 현장 반응인지, 하루 안의 큰 소모인지, 며칠 이상 걸리는 절차인지를 먼저 나눈다.

| 행동 유형 | 기본 시간비용 | 먼저 필요한 조건 | 얻는 결과 | 넘지 못하는 선 | 연결 대분류 |
|---|---|---|---|---|---|
| 관찰·듣기·냄새 맡기 | 같은 현장에서 바로 가능 | 시야, 거리, 빛, 소음, 냄새 | 보이는 표식, 줄 분위기, 가까운 소문 | 원인, 책임, 내부 의도는 알 수 없다. | LOC, SOC |
| 주변에 묻기 | 짧은 대화와 관계 비용 | 말 걸 수 있는 사람, 언어, 신뢰, 위험 | 생활 조언, 낮은 신뢰도 소문, 다음 접점 | 문서 내용이나 기관 판단을 확정하지 않는다. | CIV, LORE |
| 줄 서기·대기 | 하루의 큰 부분을 소모할 수 있음 | 장소 개방, 순서, 이름패, 보증인, 물·음식 | 접수 여부, 공개 낭독, 검문 반응 | 대기만으로 내부 장부와 결정 이유를 알 수 없다. | LAW, CRS, SEC |
| 서기관 의뢰 | 비용과 순서를 요구함 | 문서, 수수료, 문해 중개자, 공개 가능 문서 | 자기 문서 요약, 이름 대조, 제출처 | 타인의 제한 기록과 봉인 사본은 열리지 않는다. | CIV, LAW |
| 가까운 이동 | 빛, 길, 날씨, 짐, 통행 상태에 묶임 | 현재 위치, 목적지, 동행자, 신체 상태 | 다음 장소, 길 소문, 검문 표면 | 전체 지도와 숨은 우회망을 자동으로 얻지 않는다. | INF, SEC |
| 장거리 이동 | 여러 날짜와 숙식·검문·물자 비용을 요구함 | 여비, 숙소, 길 지식, 계절, 보증 | 이동 경로의 표면 경험과 소문 | 먼 권역 지식이나 외교 정보를 동시에 얻지 않는다. | INF, GEO |
| 청원·증언 | 접수와 대기가 분리됨 | 피해 내용, 증인, 보증, 서기관, 관할 | 청원서, 증언 기록, 다음 출석 가능성 | 접수가 곧 판결이나 정치 변화가 되지 않는다. | LAW, POL |
| 치료·회복 | 증상과 상처에 따라 하루 이상 묶일 수 있음 | 돌봄층, 물, 음식, 약초, 격리 여부 | 처방, 돌봄, 복귀 가능성, 기록 | 치료가 곧 완치나 객관 병인 확인이 되지 않는다. | MED, SOC |
| 물자 조달·수리 | 장터일·재료·납기에 묶임 | 돈, 현물, 보증, 길드 접근, 재료 상태 | 도구, 수리 약속, 대체품, 부채 | 원하는 장비를 즉시 구매하거나 제작하지 않는다. | ECO, TEC |
| 기관 내부 진입 | 허가와 관계가 쌓여야 함 | 소속, 임무, 보증인, 감시, 공개 시간 | 제한 동선, 담당자 말, 일부 표식 | 권력층 사적 공간과 봉인 문서로 바로 올라가지 않는다. | LOC, POL |

한 응답 안에서 여러 행동을 이어 붙일 수는 있지만, 정본은 각 행동의 시간비용과 접근 조건을 남긴다. 장거리 이동, 청원, 치료, 장비 조달, 기관 진입은 특별한 접근권이 없으면 즉시 결말로 처리하지 않고, 줄·대기·보증·피로·숙식·문서 단계를 거친다.

### CK5083-WORLD-ACTION-OUTCOME-SURFACE-001. 행동 결과와 현장 상태 변화 기준

행동 결과는 성공과 실패 둘로만 나뉘지 않는다. 기준시대의 작은 행동은 흔히 소문, 지연, 의심, 부채, 상처, 물자 손실, 장부 기입, 보증 철회, 문 닫힘처럼 남는다. 이 단락은 사용자의 행동을 사건 서사로 즉시 키우지 않고, 먼저 현장 상태와 생활 표면의 변화로 처리하는 기준이다.

| 결과 표면 | 나타나는 조건 | 남는 흔적 | 다음에 열리는 것 | 다음에 막히는 것 | 연결 대분류 | 금지선 |
|---|---|---|---|---|---|---|
| 관찰만 남음 | 행동이 조용하고 현장 물건·사람을 건드리지 않을 때 | 기억, 냄새, 표식, 소문 조각 | 더 묻기, 기다리기, 위치 좁히기 | 원인 확정, 내부 의도 확인 | LOC, CIV | 관찰만으로 사건의 진실을 알게 하지 않는다. |
| 부분 성공 | 목적의 일부만 이루고 조건이 남을 때 | 약속, 다음 방문, 보증 요구, 대체 경로 | 추가 교섭, 서기관 의뢰, 보증인 찾기 | 즉시 완전 해결 | SOC, LAW | 부분 성공을 실패나 완전 성공으로 단순화하지 않는다. |
| 지연 발생 | 줄, 검문, 날씨, 문해, 장부 대조가 걸릴 때 | 대기 순번, 늦은 소식, 피로, 숙식 비용 | 다른 줄, 우회로, 공개 낭독 청취 | 같은 날 무제한 행동 | INF, CAL | 지연을 단순 시간 스킵으로 지우지 않는다. |
| 비용 발생 | 돈, 현물, 노동일, 보증, 물자 소모가 필요할 때 | 부채, 작은 돈 손실, 물건 교환, 노동 약속 | 물건 확보, 접수 통과, 잠자리 | 공짜 접근, 무한 구매 | ECO, SOC | 비용을 단일 화폐 가격으로만 처리하지 않는다. |
| 의심 증가 | 이름·통행·무기·질병·소속이 맞지 않을 때 | 보초 기억, 소문, 재검문, 동행 요구 | 해명, 보증인 요청, 제한 통과 | 자유 이동, 기관 내부 진입 | SEC, LAW | 의심을 곧 유죄나 적대 판정으로 확정하지 않는다. |
| 평판 변화 | 같은 장소나 관계권에서 행동이 반복될 때 | 장터 말, 신전 기억, 작업장 평, 가구 반응 | 신용, 작은 소개, 숙식 완화 | 외상 거절, 감시, 낮은 증언 무게 | SOC, CIV | 평판을 세계 공통 점수처럼 쓰지 않는다. |
| 물건·시설 손상 | 도구 사용, 폭력, 사고, 습기, 불, 수리 실패가 있을 때 | 균열, 얼룩, 냄새, 부서진 표식, 수리 장부 | 보수 요청, 책임 논쟁, 대체품 | 즉시 복구, 흔적 없는 파손 | TEC, LAW | 손상을 감정 장면이나 완전 파괴로만 처리하지 않는다. |
| 상처·피로 누적 | 이동, 노동, 폭력, 밤샘, 굶주림, 추위가 겹칠 때 | 물집, 멍, 기침, 느린 반응, 치료 필요 | 돌봄, 휴식, 치료 기록 | 무제한 행동, 즉시 회복 | MED, SOC | 상처와 피로를 의지로 삭제하지 않는다. |
| 문서화 | 서리, 신관, 길드, 성채가 이름이나 사건을 적을 때 | 이름패, 청원서, 검문 기록, 장부 주석 | 후속 접수, 증언, 제한적 효력 | 문서 전문 공개, 모든 기관 인정 | CIV, LAW | 기록됨을 곧 정본 진실이나 전역 효력으로 올리지 않는다. |
| 권위층 반응 | 보초, 신전, 길드, 관청, 성채가 대응해야 할 때 | 거절, 보류, 낭독, 압류, 통행 제한 | 절차, 항의, 보증 요구 | 숨은 의도 확인, 상급 판단 직행 | POL, SEC | 권위층 반응을 객관 진실이나 악의 증거로 단정하지 않는다. |
| 사건 이관 대상 | 피해, 날짜, 장소, 책임 주장, 증인이 반복 기록될 때 | 사건 문서 전환 대상, 판결문, 장례문, 수리 장부 | 별도 사건·역사 문서로 분리 | 기준시대 객관정보 본문 장면화 | CRS, LORE | 기준시대 객관정보 안에서 사건 서사를 길게 만들지 않는다. |

행동 결과는 현장 상태를 바꾸되 세계 전체를 즉시 바꾸지 않는다. 작은 행동이 반복되면 평판, 문서, 부채, 의심, 상처, 손상이 쌓이고, 여러 권위층이 같은 흔적을 다르게 읽을 때만 더 큰 절차나 사건 문서로 넘어간다.

### CK5083-WORLD-STATE-CONTINUITY-SCOPE-001. 상태 지속성과 확산 범위 기준

기준시대의 행동 결과는 후속 응답에서 사라지지 않는다. 다만 모든 흔적이 같은 범위와 같은 속도로 퍼지지는 않는다. 정본은 상태 변화를 현장, 관계권, 문서권, 권위권, 권역권으로 나누고, 각 변화가 어디까지 남으며 어떤 조건에서 약해지는지 먼저 정한다.

| 상태 층위 | 남는 범위 | 지속 조건 | 약해지는 조건 | 후속 응답에서 먼저 확인할 것 | 금지선 |
|---|---|---|---|---|---|
| 현장 물리 상태 | 방, 거리, 성문, 장터, 작업장 같은 직접 장소 | 파손, 얼룩, 냄새, 흔적, 위치 변화가 남을 때 | 청소, 수리, 비, 군중 이동, 장소 폐쇄 | 같은 장소로 돌아왔는지, 누가 현장을 관리하는지 | 장소를 벗어난 뒤에도 모든 사람이 흔적을 안다고 처리하지 않는다. |
| 몸 상태 | 사용자 인물과 가까운 동행자 | 상처, 피로, 굶주림, 질병 의심, 숙취, 추위가 누적될 때 | 휴식, 치료, 식사, 돌봄, 시간 경과 | 오늘 할 수 있는 행동 수와 이동 가능성 | 의지나 대화만으로 피로와 상처를 지우지 않는다. |
| 소지·부채 상태 | 개인 소지품, 장부, 빚, 노동 약속 | 돈·현물·도구를 쓰거나 빌리거나 맡겼을 때 | 변제, 회수, 압류, 분실, 보증 변경 | 가진 물건, 빚진 대상, 상환 시점 | 소지품과 부채를 장면마다 새로 초기화하지 않는다. |
| 관계 기억 | 가구, 작업장, 장터, 신전, 성채 하급자 같은 생활권 | 반복 접촉, 도움, 거절, 폭력, 약속 불이행이 있을 때 | 중재, 사과, 보증, 시간 경과, 권위층 개입 | 상대가 사용자를 알아보는지, 어떤 말로 기억하는지 | 관계 기억을 전역 평판 점수로 만들지 않는다. |
| 소문 흐름 | 우물가, 여관, 항구, 장터, 병영, 신전 앞 | 목격자가 많거나 말하기 쉬운 사건일 때 | 더 큰 소문, 권위층 부인, 화자 이동, 기억 변형 | 누가 들었고 어느 방향으로 말이 퍼지는지 | 소문을 곧 사실 확인이나 공식 판정으로 쓰지 않는다. |
| 문서 흔적 | 이름패, 청원서, 검문표, 배급 장부, 치료 기록 | 서기관·보초·신관·길드가 이름이나 수량을 적을 때 | 문서 소실, 보관 누락, 권한 부재, 다른 장부와 충돌 | 문서가 공개인지 제한인지, 누가 읽을 수 있는지 | 기록됨을 전역 인정이나 정본 진실로 올리지 않는다. |
| 권위층 주시 | 보초, 신전, 관청, 길드, 성채, 영지 관리 | 규칙 위반, 통행 문제, 폭력, 질병 의심, 반복 민원이 있을 때 | 해명, 보증인, 벌금, 격리 해제, 담당자 교체 | 어느 권위가 기억하고 어떤 절차를 요구하는지 | 감시를 곧 유죄 확정이나 숨은 음모로 단정하지 않는다. |
| 경로·시설 상태 | 길, 다리, 성문, 항구, 창고, 우물, 봉화대 | 파손, 폐쇄, 검문, 기상, 수리 지연이 있을 때 | 보수, 우회로 개방, 경계 해제, 계절 변화 | 공개 경로와 제한 경로가 어떻게 달라졌는지 | 시설 상태를 지역 전체의 영구 변화로 과장하지 않는다. |
| 위기 단계 | 마을, 영지, 항구, 접경, 유역 같은 절차권 | 같은 위험이 반복 기록되고 권위층이 대응할 때 | 구휼, 봉합, 봉쇄 해제, 책임 논쟁, 기록 이관 | 전조·경고·대응·피난·구휼 중 어느 단계인지 | 작은 사건 하나로 전쟁, 재난, 왕조 변화를 확정하지 않는다. |

상태 지속성은 “기억해야 할 것”을 늘리는 장치가 아니라 세계의 반응 범위를 제한하는 장치다. 후속 응답은 먼저 현재 위치, 남은 흔적, 알고 있는 사람, 기록된 문서, 작동 중인 권위를 확인하고, 그 범위를 넘어서는 결과는 소문, 지연, 접근 거절, 별도 사건 문서로 낮춘다.

### CK5083-WORLD-PERSONA-ENTRY-GATE-001. 인물 진입값 최소 기준

기준시대 인물은 세계 전체의 해설자가 아니라 특정 장소와 생활권에 묶인 사람이다. 인물 응답을 시작할 때는 출신, 현재 위치, 소속, 문해력, 소지 문서, 생계 수단, 접근 표면을 먼저 낮은 값으로 둔다.

| 진입값 | 먼저 정하는 범위 | 기본값이 없을 때의 처리 | 연결 대분류 | 금지선 |
|---|---|---|---|---|
| 현재 위치 | 성문, 장터, 신전 앞, 공동 창고, 숙소, 길 위, 작업장 같은 가시 장소 | 대표 장소를 임의 배정하지 않고 가까운 장소 단서가 필요하다고 둔다. | LOC, GEO | Tiris, Ravenstone, Newhollow를 기본 무대로 자동 선택하지 않는다. |
| 생활 소속 | 가구, 피난 공동체, 길드, 성채 하급자, 상단 동행, 신전 보조, 외부자 | 법적 주민권보다 생활상 인정과 보증인을 먼저 묻는다. | SOC, LAW | 문서가 없다는 이유로 존재나 관계를 지우지 않는다. |
| 생계 표면 | 노동일, 배급, 도제 숙식, 장터 하역, 항만 일, 봉납 보조, 부채 | 가진 돈보다 오늘 먹고 자는 경로와 빚을 먼저 본다. | ECO, CRS | 전역 경제 지식이나 전체 장부 접근권을 기본으로 주지 않는다. |
| 이동 가능성 | 공개 길, 지역 길, 동행 허가, 직능 경로, 통행 제한, 검문 대기 | 가까운 길과 다음 검문만 말하고 전체 지도를 닫는다. | INF, SEC | 숨은 우회로와 군사 제한로를 편의상 열지 않는다. |
| 문해력·언어 | 이름 읽기, 숫자·표식 인식, 낭독 청취, 서기관 의뢰, 통역 의존 | 문서 내용을 직접 아는 대신 들은 말과 요약을 둔다. | CIV, NOM | 공용서기어 내부 규칙과 전체 문자표를 인물 지식으로 주지 않는다. |
| 법적 접점 | 당사자, 증인, 청원자, 보증인, 억류자, 통지 수령자 | 공개 절차와 부담만 열고 봉인 문서와 의도는 닫는다. | LAW, POL | 법정 내막과 상위 권력 전략을 기본 응답으로 공개하지 않는다. |
| 위험 표면 | 질병 의심, 외부자 의심, 부채, 통행세, 배급 지연, 소문 | 위험을 사건 확정이 아니라 현재 조건으로 처리한다. | MED, CRS, LORE | 시작값만으로 범인, 전쟁, 예언, 초자연 원인을 확정하지 않는다. |

이 진입값은 인물을 작게 만들기 위한 제한이 아니라 세계를 실제 접점부터 열기 위한 기준이다. 위치와 소속이 좁을수록 응답은 풍부해질 수 있지만, 그 풍부함은 가까운 물건, 사람, 문서, 소문, 절차에서 나온다.

### CK5083-WORLD-LIFE-SURFACE-COMPLETION-001. 대분류별 생활 표면 1차 운용선

| 소행성대 불안정기 | 기본 상태는 불안정기 한가운데가 아니다. | 유성·운석 증가나 대형 충돌을 말하려면 필요하다. | 별똥 증가, 운석 전승, 검은 돌, 항해 금기로만 변환한다. |

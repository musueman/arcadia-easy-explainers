# Arcadia 루나톡 위키 정본화 계획

## 목적

이 문서는 `죽지 않는 기사와 비단요람` Arcadia 설정집을 루나톡 위키 모드에 올리기 전, 문서 일원화·병합·세계관 정리를 진행하기 위한 작업 기준이다.

루나톡 공지 기준 위키 모드는 다음 특성을 가진다.

- 최대 20만자 규모의 캐릭터/세계관 등록을 지원한다.
- Markdown 또는 나무위키식 제목 문법을 지원한다.
- `[[위키링크]]`로 등장인물·지명·사건을 감싸면 AI가 더 정확히 찾는다.
- 본문을 분석해 검색 가능한 형태로 자동 인덱싱한다.
- 대화 중 새 인물·사건이 등장하면 줄거리 요약 시점에 캐릭터 정보와 세계관 정보에 자동 추가될 수 있다.

따라서 이번 정리는 단순한 설정집 보관이 아니라, 챗봇이 매 턴 필요한 정보를 안정적으로 찾아 쓸 수 있는 정본 위키를 만드는 작업으로 본다.

## 현재 파일 상태

대상 폴더:

`D:/OneDrive/333_죽지않는기사와_비단요람/001_신설정/arcadia_updated_md`

현재 세계관 핵심 파일 00~04 합계는 약 91,782자다. 루나톡 20만자 제한 안에 들어가므로, 분량 절감보다 중복 제거·정본화·링크화가 우선이다.

인물 파일 `arcadia_07_characters_expanded.md`까지 포함하면 전체가 약 205,412자로 20만자를 넘는다. 따라서 사용자의 지시대로 인물관계와 인물 상세 정리는 마지막 단계로 분리한다.

## 작업 원칙

1. 원본 파일은 보존한다.
2. 루나톡 업로드용 정본 파일을 별도로 만든다.
3. 색인, 편입 보고, 반영 방식, 편입 메모 같은 작업 메타는 업로드 정본에서 제외한다.
4. 파일명 링크보다 의미 링크를 우선한다.
5. 한 개념에는 가능한 한 하나의 표제어를 부여한다.
6. 민간 전승, 비공식 조서, 보류 예언은 확정 설정으로 승격하지 않는다.
7. 인물관계는 마지막 단계에서 별도 파일로 정리한다.

## 위키 문법 규칙

1. 한 파일에는 H1을 하나만 둔다.
2. 큰 범주는 `##`, 개별 항목은 `###`로 통일한다.
3. 이모지 제목은 사용하지 않는다.
4. 파일명 링크 대신 의미 링크를 사용한다.
5. 섹션 제목 자체에 링크를 넣는다.
6. 각 항목 첫머리에 관련 링크를 둔다.
7. 파이프 별칭 `[[티리스|Tiris]]`는 루나톡 호환이 확실해진 뒤 사용한다.

예시:

```md
### [[티리스 왕국]]

별칭: Tiris, 티리스
관련: [[에덴포르트]], [[Silverkeep]], [[Ravenstone]], [[Greenhollow 함락]]

[[티리스 왕국]]은 에덴포르트의 완충지대에 놓인 농업·목축 중심 군주국이다.
```

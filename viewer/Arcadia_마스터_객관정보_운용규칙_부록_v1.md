# Arcadia 마스터 객관정보 운용규칙 부록 v1

이 문서는 마스터 객관정보 정본 본문에서 분리한 관리 규칙, 교차 검산 규칙, 중립 ID 체계를 보존한다. 본문 정본에는 항성계와 행성, 자연계의 결론을 두고, 이 부록에는 정본을 유지·검산할 때 필요한 내부 규칙을 둔다.

---

## RULE. 객관정보 관리 규칙

### OBJ-RULE-CONSISTENCY-001. 교차 검산 규칙

| 항목 | 내용 |
|---|---|
| ID | OBJ-RULE-CONSISTENCY-001 |
| 계층 | 객관정보 |
| 도메인 | 객관정보 관리 |
| 정본명 | Objective consistency rule |
| 객관 정의 | Arcadia 객관정보 정본의 원천값, 파생값, 범위값, 시대별 변동값을 서로 충돌하지 않게 관리하는 전역 규칙 |
| 적용 범위 | `OBJ-AST`, `OBJ-CAL`, `OBJ-VIR`, `OBJ-ID` 전 항목 |
| 시간 적용 | 전 시대 공통 |
| 확정도 | canon |
| 상태 | canon |
| 기준 원칙 | 원천값은 먼저 고정하고, 파생값은 원천값 변경 시 함께 재검산한다. |
| 재검산 트리거 | 항성 출력, 행성 궤도, 행성 질량·반지름, 자전축, 위성 궤도, 대륙·해양 분포, 판구조, 대기·해양 조건이 바뀌는 경우 |
| 상호 의존 필드 | 시간 단위, 일사량, 중력, 대기 보존, 조석, 기후대, 수권, 빙권, 생물권, 자연재해권 |
| 파생값 갱신 규칙 | 원천값이 바뀌면 같은 표 안의 파생값뿐 아니라 연결 ID의 파생값도 함께 재검산한다. |
| 불변 항목 | 객관 ID, 물리 단위, 참조 epoch, 기준면, 중립 자연 ID의 연결 대상 |
| 시점별·시대별 변동 항목 | 실제 천체 위치, 위상, 장주기 현상 위상, 해안선, 빙권 범위, 생태구 경계, 자연재해 주기 위상 |
| 충돌 금지선 | 객관정보 정본의 원천값과 시대별 인식값을 같은 층위로 병합하지 않는다. |
| 연결 ID | OBJ-RULE-UNCERTAINTY-001, OBJ-ID-NATURAL-001, OBJ-AST-EPOCH-001, OBJ-CAL-TIME-001, OBJ-AST-VIRETH-001, OBJ-VIR-SURFACE-LIFECYCLE-001, OBJ-VIR-SURFACE-001, OBJ-VIR-BIOGEOCHEM-001, OBJ-VIR-ERA-DELTA-001, OBJ-VIR-ERA-DELTA-CONSTRAINTS-001 |
| 배제되는 주장 | 기준시대 통용 지식, 민간 명칭, 신앙 해석, 정치적 기록을 객관 원인처럼 취급하지 않는다. |

| 값 유형 | 정의 | 기록 방식 |
|---|---|---|
| 원천값 | 다른 항목의 계산 근거가 되는 물리값 | 정본 표에 직접 기록하고, 변경 시 연결 항목을 재검산한다. |
| 파생값 | 원천값에서 계산되거나 논리적으로 따라오는 값 | 연결 원천값을 명시하고, 독립 원천처럼 반복 확정하지 않는다. |
| 범위값 | 아직 단일 수치로 고정하지 않는 허용 범위 | `약`, `범위`, `중심값`을 구분해 기록한다. |
| 시대값 | 특정 기준시대에서만 유효한 자연 상태 | 객관정보에는 허용 범위와 변수만 두고, 실제 시대 적용은 기준시대 문서에서 참조한다. |
| 인식값 | 특정 시대 사람들이 알고 믿는 값 | 기준시대 인식 문서 또는 오버레이에 둔다. |

| 변경되는 원천 | 함께 검산할 항목 |
|---|---|
| Arion 질량·반지름·광도·표면 온도 | 거주 가능대, Vireth 일사량, 생명권 가능 기간, 대기·오존 요구 조건, 우주기상 강도 |
| Vireth 궤도거리·이심률·경사 | 공전주기, 계절 길이, 일사량 변동, 기후대, 빙권, 생명권 안정성 |
| Vireth 질량·반지름·밀도 | 표면중력, 탈출속도, 대기 보존, 해양 보존, 판구조 지속성 |
| Vireth 자전주기·자전축 | 일장, 대기 순환, 해류, 계절성, 극권 환경 |
| Caelum·Umbra 질량·궤도 | 조석, 식 조건, 위상 주기, 해안 생태, 물리 계절과 기준시대 달력의 천문 기반 |
| 대륙·해양·고도 분포 | 기후대, 강수, 하천 유역, 생태구, 빙권, 자연재해권 |
| 판구조·화산활동 | 산맥, 지진, 해일, 광상, 지열, 장기 탄소 순환 |
| 기후·수권·빙권 | 생태구, 농업 가능 자연 조건, 해수면, 시대 분기 변수 |

객관정보 정본은 하나의 시대 설명문이 아니라 여러 기준시대가 참조하는 원천 DB다. 따라서 기준시대 문서가 객관정보와 다른 명칭이나 설명을 가질 수는 있으나, 물리 원인과 수치의 원천성은 객관정보 정본을 따른다.

### OBJ-RULE-UNCERTAINTY-001. 객관 불확실성·분산 기록 규칙

| 항목 | 내용 |
|---|---|
| ID | OBJ-RULE-UNCERTAINTY-001 |
| 계층 | 객관정보 |
| 도메인 | 객관정보 관리 |
| 정본명 | Objective uncertainty and variance rule |
| 객관 정의 | 확정 물리값, 허용 범위, 확률창, 국지 모델, 결합 임계값을 서로 구분해 기록하는 전역 규칙 |
| 적용 범위 | `OBJ-AST`, `OBJ-CAL`, `OBJ-VIR`, `OBJ-ID` 전 항목 |
| 시간 적용 | 전 시대 공통 |
| 확정도 | canon |
| 상태 | canon |
| 기준 원칙 | 불확실성은 물리 제약을 우회하는 장치가 아니라, 관측·모델·초기조건·결합조건의 분산을 기록하는 장치다. |
| 연결 ID | OBJ-RULE-CONSISTENCY-001, OBJ-ID-NATURAL-001, OBJ-AST-CYCLE-STOCHASTICITY-001, OBJ-AST-SPACEWEATHER-COUPLING-001, OBJ-VIR-THRESHOLD-HYSTERESIS-001, OBJ-VIR-LOCAL-ANOMALY-001, OBJ-VIR-ERA-DELTA-CONSTRAINTS-001 |
| 배제되는 주장 | 불확실성 필드를 특정 역사 결과, 사회 붕괴, 종족 기원, 신앙 해석의 원인으로 직접 확정하지 않는다. |

| confidence_class | 정의 | 사용 기준 |
|---|---|---|
| locked | 원천 물리값으로 고정되는 항목 | 행성 질량, 반지름, 물리 시간 단위, 중립 ID처럼 기준시대가 바뀌어도 유지되는 값 |
| bounded | 범위 안에서만 선택하는 항목 | 해수면 편차, 평균 기온 편차, 조석 증폭, 화산 강도처럼 검산 범위가 있는 값 |
| derived | 다른 원천값에서 산출되는 항목 | 일장, 계절 일사, 조석 위상, 해수면 반응처럼 연결 원천을 바꾸면 함께 바뀌는 값 |
| scenario-variable | 기준시대 오버레이에서 선택하는 항목 | 생태구 경계, 재해 위상, 국지 변칙 활성도처럼 시대별 자연 상태가 필요한 값 |

| uncertainty_class | 정의 | 기록 방식 |
|---|---|---|
| deterministic | 허용 오차 안에서 단일 계산값으로 다룰 수 있음 | 수식과 원천값을 명시한다. |
| bounded-range | 상한·하한 안에서 값이 달라짐 | 중심값, 범위, 적용 조건을 함께 둔다. |
| phase-window | 주기 위상과 창 안에서 위험도가 달라짐 | 중심 주기, 창 폭, 위상 신뢰도를 둔다. |
| stochastic-window | 물리 조건이 맞아도 발생 여부와 강도가 갈림 | 확률 등급, 강도 등급, 사건 인스턴스 필요 여부를 둔다. |
| coupled-threshold | 여러 조건이 겹칠 때 전환 가능성이 커짐 | 결합 조건, 임계대, 회복 지연을 둔다. |
| local-model | 전역 평균과 다른 국지 반응을 보임 | 공간 범위, 지속 시간, 허용 효과, 금지 효과를 둔다. |

| 분산 원천 | 객관 기록 기준 | 정본 제한 |
|---|---|---|
| 초기조건 민감성 | 작은 위상·위치·수분·응력 차이가 사건 강도와 위치를 바꿀 수 있음 | 사건일을 고정하지 않는다. |
| 결합조건 민감성 | 항성활동, 계절, 대기 화학, 해양 상태가 겹칠 때만 큰 효과가 남 | 단일 원인을 전역 결과로 단정하지 않는다. |
| 임계·이력현상 | 임계대를 넘은 뒤에도 지연, 완충, 회복, 되돌림 저항이 생길 수 있음 | 단계 경계를 칼날 같은 전환선으로 쓰지 않는다. |
| 국지 지형 증폭 | 해협, 내해, 고산, 극권, 열수권이 전역 평균과 다르게 반응함 | 국지 예외를 행성 전체 상태로 확대하지 않는다. |
| 관측·정밀도 한계 | 모델 해상도에 따라 지역 결과가 달라짐 | 정밀도 등급 없이 세부 값을 확정하지 않는다. |

불확실성 규칙은 세계가 무작위로 흔들린다는 뜻이 아니다. 같은 원천값을 쓰더라도 기준시대가 선택하는 위상, 지역, 결합조건, 정밀도에 따라 자연 결과가 달라질 수 있음을 기록한다.

| 금지 명명 | 국가명, 종족명, 신명, 관청명, 민간 별칭, 대화·서사 발화문을 중립 자연 ID로 쓰지 않는다. |

| 배제되는 주장 | 중립 자연 ID를 특정 시대의 일반 지명, 관청명, 신전명, 민간명으로 취급하지 않는다. |

| 자연재해권 | `VIR-HAZ-##` | 지진, 화산, 해일, 홍수, 가뭄, 폭풍, 산불, 산사태 위험권 |

| 연결 방식 | 기준 |
|---|---|
| 객관 정본 표기 | 중립 ID와 정본명을 먼저 쓰고, 시대별 명칭은 직접 확정하지 않는다. |
| 기준시대 문서 연결 | 기준시대별 통용명은 `linked_objective_id`로 중립 ID에 연결한다. |
| 여러 이름이 있는 경우 | 같은 자연물에 문화권별 명칭이 여럿 있어도 객관 ID는 하나만 둔다. |
| 자연물이 시대별로 변하는 경우 | 지각판처럼 장기 불변에 가까운 ID는 유지하고, 해안선·빙권·생태구처럼 상태가 변하는 항목은 시대별 상태값으로 분리한다. |
| 번호 부여 | 같은 범주 안에서 처음 확정되는 자연물부터 `01`을 부여한다. 번호는 정본명이 바뀌어도 재사용하지 않는다. |

중립 자연 ID는 문화권 지명을 제거하기 위한 장치가 아니라, 시대별 명칭을 안전하게 연결하기 위한 기준점이다. 같은 자연물에 여러 이름이 붙을 수 있어도, 객관정보 정본에서는 그 자연물이 같은 대상인지 먼저 확정한다.

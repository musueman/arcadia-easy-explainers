# Arcadia 마스터본 객관정보·기준시대 분리 소플랜

## 목적

Arcadia 마스터본의 원천 역할을 재정의한다. 앞으로의 마스터 원천은 특정 기준시대의 통용 지식이 아니라, 시대와 인물의 인식 바깥에 존재하는 `세계관 객관정보`를 관리한다. 5083년 기준 지식은 별도 `기준시대 객관정보` 문서로 분리하고, 이후 다른 기준시대가 추가될 경우 같은 구조로 가지를 늘린다.

## 문서 역할 분리

| 문서 역할 | 기능 | 포함할 내용 | 제외할 내용 |
|---|---|---|---|
| 마스터 객관정보 정본 | 작가·설정 관리자가 보는 실제 세계 구조 | 항성계, 행성, 지리, 종족, 생물권, 제도 실제값, 객관 연대표, 생명 가능 시간창 | 특정 시대 인물의 오해, 민간 명칭, 챗봇 발화문 |
| 기준시대 객관정보 | 특정 시대 사람들이 알고 믿고 제도화한 정보 | 관측 가능성, 민간 지식, 학술 지식, 문화권별 명칭, 금기, 오해, 말할 수 있는 범위 | 객관 원인 전체, 미래 시대 스포일러, 작가용 진실 |
| 인물·세력 오버레이 | 같은 기준시대 안의 개별 차이 | 인물별 지식 한계, 직업별 용어, 기관별 비밀, 지역 소문 | 세계 전체의 객관 사실 재서술 |
| 챗봇 반영본 | 챗봇 응답용 압축본 | 기준시대 객관정보와 인물·세력 오버레이에서 추출한 발화 기준 | 마스터 객관정보 직접 노출 |
| 주제 허브 | 탐색과 연동 | 같은 주제의 객관정보, 시대별 기준시대 객관정보, 챗봇 반영 문서 링크 | 정본 본문 장황화 |

## 원천 구조 원칙

| 원칙 | 기준 |
|---|---|
| 원천성 | 객관정보 정본만 실제 세계 구조의 원천으로 둔다. |
| 시대 분리 | 5083년 정보도 객관정보와 같은 위상에 두지 않고 시대별 파생 레이어로 둔다. |
| 중복 금지 | 기준시대 문서는 객관 사실을 다시 설명하지 않고, 그 시대의 접근 가능성·오해·제도화만 기록한다. |
| ID 연결 | 모든 항목은 고정 ID를 가지며, 시대별 문서는 해당 ID를 참조한다. |
| 허브 사용 | 탐색 편의를 위해 주제 허브가 여러 문서의 같은 항목을 연결한다. |
| 챗봇 안전 | 챗봇 반영본은 객관정보 정본을 직접 검색하지 않고 기준시대 객관정보와 오버레이만 사용한다. |

## ID 규칙

ID는 문서 위치가 아니라 사실 단위와 지식 단위에 붙인다. 제목, 목차, 파일 위치가 바뀌어도 ID는 유지한다.

| ID 층위 | 접두어 | 범위 | 예시 |
|---|---|---|---|
| 객관 사실 ID | `OBJ-RULE` | 객관정보 검산 규칙, 파생값 갱신 규칙, 충돌 금지선 | `OBJ-RULE-CONSISTENCY-001` |
| 객관 사실 ID | `OBJ-ID` | 중립 자연 ID 체계, 객관명과 인월드명 연결 규칙 | `OBJ-ID-NATURAL-001` |
| 객관 사실 ID | `OBJ-AST` | 항성계, 천문, 행성, 위성, 소천체, 우주기상 | `OBJ-AST-ARION-001`, `OBJ-AST-MOON-SYSTEM-001` |
| 객관 사실 ID | `OBJ-CAL` | 물리 시간, 자전·공전 기준, 물리 계절 | `OBJ-CAL-TIME-001`, `OBJ-CAL-SEASONS-001` |
| 객관 사실 ID | `OBJ-VIR` | Vireth 좌표계, 대륙·해양, 지질, 기후, 수권, 빙권, 생물권, 자연 자원, 자연재해 | `OBJ-VIR-GEODESY-001`, `OBJ-VIR-BIOSPHERE-001` |
| 기준시대 지식 ID | `CK5083-AST` | 5083년 천문 기준시대 객관정보 | `CK5083-AST-ARION-001` |
| 기준시대 지식 ID | `CK5083-CAL` | 5083년 시간·달력 기준시대 객관정보 | `CK5083-CAL-EDENFORT-001` |
| 기준시대 지식 ID | `CK5083-VIR` | 5083년 Vireth 자연계 기준시대 객관정보, 지도 인식, 항로 지식, 지역별 오해 | `CK5083-VIR-COAST-001` |
| 인물·세력 오버레이 ID | `PV5083` | 5083년 인물·직업·기관 지식 차이 | `PV5083-TIRIS-FARMER-001` |

한 항목이 여러 시대에 걸쳐 다르게 인식될 경우, 객관 ID는 유지하고 시대별 문서에서 `linked_objective_id`로 연결한다. 기준시대 문서의 지식 ID는 객관 ID와 1:1일 필요가 없다. 하나의 객관 사실이 여러 문화권의 통용 지식으로 갈라질 수 있고, 하나의 통용 지식이 여러 객관 사실을 섞어 오해할 수도 있다.

Vireth 물리 자연계에는 `OBJ-GEO`를 쓰지 않고 `OBJ-VIR`를 사용한다. `GEO`는 사회문화권의 지역·권역 의미와 혼동될 수 있으므로, 객관 자연계의 좌표·대륙·해양·판·기후·생태구는 먼저 `OBJ-VIR` 중립 ID로 고정하고 기준시대 문서에서 인월드명과 연결한다.

## 분류 판정 기준

| 분류 | 판정 기준 | 문서 위치 |
|---|---|---|
| 객관 사실 | 시대와 인식에 무관하게 실제로 존재하거나 성립하는 구조 | 마스터 객관정보 정본 |
| 기준시대 공통 지식 | 5083년 다수 문화권 또는 공용 행정권에서 통용되는 지식 | 기준시대 5083 객관정보 |
| 지역·계층별 지식 | 특정 문화권, 직업, 신전, 관청, 학파만 아는 정보 | 기준시대 5083 객관정보 또는 오버레이 |
| 학술 이론 | 5083년 학자들이 구조적으로 설명하지만 전제가 현대 과학과 다른 설명 | 기준시대 5083 객관정보 |
| 민간 신앙·전승 | 생활어, 징조, 신화, 금기, 구전 | 기준시대 5083 객관정보 또는 오버레이 |
| 비밀·사적 지식 | 특정 인물, 기관, 가문만 아는 정보 | 인물·세력 오버레이 |
| 보류 메모 | 아직 확정되지 않은 비교, 질문, 작업 기록 | 정본 문서가 아니라 회차 노트 |

## 4회차 천문 파트 시험 분리

현재 4회차 논의초안은 새 구조의 시험 대상이다.

| 시험 항목 | 객관정보 파일 후보 | 기준시대 파일 후보 |
|---|---|---|
| 1차 시험: Arion | `OBJ-AST-ARION-001` | `CK5083-AST-ARION-001` |
| 1차 시험: Caelum·Umbra | `OBJ-AST-CAELUM-001`, `OBJ-AST-UMBRA-001` | `CK5083-AST-CAELUM-001`, `CK5083-AST-UMBRA-001` |
| 1차 시험: 항성계 기본 구조 | `OBJ-AST-SYSTEM-001` | `CK5083-AST-WANDERING-STARS-001` |
| 2차 시험: 소천체대·Xerxes | 소천체대와 Xerxes 실제값은 객관정보 | 하늘의 검은 돌 전승만 기준시대 정보 |
| 2차 시험: 장주기 천문 현상 | 물리 위험 창은 객관정보 | 징조, 장부, 의례, 항해 금기는 기준시대 정보 |

시험 분리는 전체 천문 섹션을 한 번에 자르지 않는다. 먼저 `Arion`, `Caelum·Umbra`, `항성계 기본 구조`만 분리한다. 소천체대, Xerxes, 장주기 천문 현상은 객관 물리와 전근대 오해가 강하게 충돌하므로 2차 시험 대상으로 둔다.

## 자연계 객관정보 확장 상세 소플랜

이 단락은 기준시대 정보를 만들기 전에 필요한 Vireth 자연계 객관정보를 묶음별로 확정하기 위한 실행 순서다. 한 회차에서는 묶음 전체를 함께 토론하되, 마스터 정본에는 ID별 독립 단락으로 반영한다.

| 운영 항목 | 기준 |
|---|---|
| 작업 단위 | 묶음별 1회차 |
| 정본 반영 방식 | 한 회차 안의 각 ID를 `Arcadia_마스터_객관정보_정본_v1.md`에 독립 단락으로 반영 |
| 회차 산출물 | 마스터 정본 단락, 필요한 경우 회차 노트, 검산 결과 |
| 정본 제외 | 조사 근거, 사용자 선택지, 비교 기록, 보류 질문, 문화권별 오해, 민간 명칭 |
| 복귀 조건 | 7회차까지 끝난 뒤 기준시대 5083 객관정보 확장으로 복귀 |

### 1회차. 교차 검산 규칙과 중립 자연 ID

| 항목 | 내용 |
|---|---|
| 목표 | 이후 모든 객관정보가 같은 ID 규칙과 검산 규칙을 쓰도록 기준을 고정한다. |
| 정본 반영 ID | `OBJ-RULE-CONSISTENCY-001`, `OBJ-ID-NATURAL-001` |
| 먼저 결정할 질문 | 객관명과 인월드명의 연결 방식, 변경 시 재검산해야 할 필드, 대륙·해양·판·기후대·생태구의 중립 ID 표기 규칙 |
| 마스터 정본 산출물 | 파생값 갱신 규칙, 상호 의존 필드 목록, 중립 자연 ID 명명 규칙, 기준시대 문서 연결 방식 |
| 넘기지 않을 범위 | 문화권 지명, 국가식 지도명, 민간 명칭, 작업 기록 |
| 검증 기준 | 이후 추가되는 모든 자연계 항목이 중립 ID와 연결 ID를 가진다. |

### 2회차. Vireth 좌표계, 표면 생몰, 대륙·해양·지형 상태

| 항목 | 내용 |
|---|---|

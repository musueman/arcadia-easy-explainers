## 7. 백과 정본과 운용 문장의 분리 기준

마스터 객관정보와 기준시대 객관정보는 백과사전형 사실만 담는다. 독자가 문서를 어떻게 써야 하는지, 챗봇이 어떤 순서로 정보를 열어야 하는지, 어떤 정보가 역사·인물 문서로 넘어가는지는 정본 본문이 아니라 이 부록에서 관리한다.

| 구분 | 정본 본문에 남길 것 | 운용부록으로 보낼 것 |
|---|---|---|
| 세계 설명 | 항성계, 행성, 국가, 권역, 장소, 종족, 언어, 달력, 법, 신앙, 생업의 실제 정보 | 정본이 어떤 문서인지 설명하는 문장 |
| 인물·사건 연결 | 장소, 제도, 물자, 법, 신앙, 전승이 실제로 존재하는 방식 | 인물과 사건이 해당 정보 위에 올라간다는 작성 지침 |
| 전승 | 전승의 이름, 권역, 기억층, 쓰임 | 전승을 객관 사실로 확정하지 말라는 운용 지침 |
| 명칭 | 정본에 쓰는 한글 발음명과 실제 통용명 | 로마자 배제, 구명칭 보존, 병기명 처리 같은 편집 규칙 |
| 접근권 | 공개 장소, 장부, 법정, 항만, 신전 등 실제 정보 접근 표면 | 챗봇이 작은 인물에게 정보를 어느 정도까지 보여 줄지 정하는 응답 규칙 |
| 문서 분기 | 역사 문서, 인물 문서, 사건 문서가 존재한다는 사실이 있을 때의 항목명 | 어떤 내용은 별도 문서에서 다룬다는 편찬 지침 |

| 정본에서 제거한 운용 문장 유형 | 부록에서의 처리 |
|---|---|
| 이 문서는 무엇을 정리한다는 설명 | 문서 분리 원칙과 내부 뷰어 구성에서 관리한다. |
| 인물과 사건은 이 위에 올라간다는 설명 | 접근권과 낮은 표면 우선 라우팅 규칙에서 관리한다. |
| 객관정보 문서에서는 한글 발음 표기로만 적는다는 설명 | 명칭 검산과 새 항목 작성 절차에서 관리한다. |
| 전승은 객관 사실을 완성하지 않는다는 설명 | 챗봇용 금지선과 전승 완충 기준에서 관리한다. |
| 사건의 진실과 인물관계는 별도 역사·인물 문서에서 다룬다는 설명 | 새 항목 작성 절차와 사건 검산 규칙에서 관리한다. |

정본 본문을 새로 고칠 때는 먼저 문장이 대상 자체를 설명하는지, 아니면 작성자와 챗봇의 사용법을 설명하는지 판정한다. 대상 자체의 이름·위치·기능·구성·관습·분포·권위·물자·일정·증거를 말하면 정본에 남기고, 작성 순서·노출 제한·검산 절차·문서 분기·금지선을 말하면 운용부록으로 옮긴다.

### 7.1 문장 양식 판정

`해야 한다`, `되어야 한다`, `하지 않는다`, `금지한다`, `쓰지 않는다` 같은 문장형은 형태만으로 정본 배제 대상이 되지는 않는다. 주어와 기능이 세계 내부에 있으면 백과형 사실 후보이고, 작성자·독자·챗봇·문서 사용 절차를 향하면 운용부록 대상이다.

| 문장 유형 | 정본에 남는 경우 | 운용부록으로 가는 경우 | 정본 권장 표현 |
|---|---|---|---|
| 의무형 | 법, 관습, 계율, 판결문, 장부 규칙, 길드 규약처럼 세계 내부에 실제로 존재하는 의무 | 작성자가 앞으로 정해야 할 일, 챗봇이 응답해야 할 방식, 문서 편집 절차 | `기록 의무`, `통행 의무`, `봉납 관습`, `검문 규례` |
| 금지형 | 국가법, 성문 고지, 신전 금기, 항만 금지문, 길드 금지 조항처럼 인월드 금지문이 존재하는 경우 | 정본에서 쓰면 안 되는 표현, 사용자에게 보여 주면 안 되는 정보, 사건을 확정하지 말라는 지침 | `통행 불가`, `봉인 구역`, `벌목 제한`, `세금 명분 제한` |
| 부정형 | 실제 세계 상태의 부재, 접근 불가, 기록 부재, 기술 미발달, 통용 지식 부재 | 해석 금지, 작성 금지, 응답 제한, 설정 분기 제한 | `기록 부재`, `직접 식별 불가`, `학술 미도달`, `접근 제한` |
| 분리형 | 세계 내부에서 권한, 문서층, 언어층, 관할이 실제로 갈라진 상태 | 정본과 부록, 역사와 인물, 설정과 응답을 나누라는 작성 지침 | `문서층 상이`, `관할 분리`, `이름층 차이`, `자료층 분화` |

판정의 핵심은 문장의 주어다. 주어가 세계 내부의 법·관습·문서·기관·기술·장소이면 정본 후보이고, 주어가 작성자·독자·챗봇·문서 사용 절차이면 운용부록 후보다.

### 7.2 명칭 라우팅 순서

명칭은 정본 본문과 운용부록에서 같은 층위로 섞지 않는다. 객관정보 정본에는 현재 채택한 한글 발음명과 실제 통용층을 놓고, 로마자 표기와 구명칭 보존 방식은 운용부록에서 관리한다.

| 순서 | 명칭층 | 정본 본문 처리 | 운용부록 처리 |
|---:|---|---|---|
| 1 | 정본 한글명 | 표제와 표의 기본명으로 사용 | 변경 시 검산 대상 |
| 2 | 실제 통용명·자칭 | 권역, 종족, 장소 설명에 필요한 경우 병기 | 자칭과 외부 호칭 충돌 기준 관리 |
| 3 | 공용서기어 병기명 | 실제 문서·장부·지도에서 쓰이는 경우만 백과 항목에 설명 | 병기명이 정본명이나 생활 자칭을 대체하지 않도록 관리 |
| 4 | 민간명·소문명 | 전승, 구전, 항만 소문, 장터명처럼 실제 사용층이 있을 때만 설명 | 객관 사실로 오인되지 않게 접근권과 기억층 관리 |
| 5 | 구명칭 보존 라벨 | 정본 본문에는 넣지 않음 | 이전 자료 추적과 내부 검산용으로만 보존 |
| 6 | 로마자 표기 | 정본 본문에는 넣지 않음 | 외부 파일명, 코드, 저장소 관리가 필요한 경우에만 별도 관리 |

### 7.3 역사·인물 분기 기준

객관정보 정본은 사건과 인물이 올라설 세계의 백과적 표면을 보존한다. 역사·인물·사건 문서는 그 표면 위에서 발생한 시간 순서, 선택, 관계, 원인, 감정, 책임을 다룬다.

| 내용 | 객관정보 정본에 남는 것 | 역사·인물·사건 문서로 가는 것 |
|---|---|---|
| 지리와 장소 | 국가, 도시, 성채, 항만, 폐허, 신전, 창고, 길, 수로의 위치·기능·권위 | 특정 인물이 그 장소에서 무엇을 했는지, 장면 순서 |
| 제도와 법 | 관할, 법정, 장부, 신전 권위, 길드 규약, 통행 허가, 공개 기록 표면 | 판결의 숨은 동기, 비공개 조작, 특정 사건의 진상 |
| 전승과 기억 | 전승명, 권역, 기억층, 쓰임, 공개 구전 상태 | 전승의 실제 진위, 예언 성취 여부, 특정 혈통의 숨은 사실 |
| 정치와 군사 | 국가 구조, 성문 규칙, 동원 표면, 병참·검문 체계 | 전투 순서, 배신, 지휘관 의도, 사망·승패의 상세 경과 |
| 인물 정보 | 공적 직함, 공개 소속, 알려진 기록 표면 | 감정선, 관계 진실, 로맨스, 배신, 비밀 혈통, 사적 대화 |
| 재난과 위기 | 재해권, 구휼 제도, 봉쇄 방식, 피난민 등록 표면 | 특정 재난의 발생일, 사망자 개인사, 책임 공방의 상세 사건 |

## 기준 범위

| 항목 | 기준 |
|---|---|
| 기준년도 | 에덴포르트 서력 5083년 |
| 기준 행성명 | Vireth |
| 기준 문명권명 | Arcadian Sphere |
| 중심 무대 | 에덴포르트 서부 접경, 티리스 왕국, Ravenstone, Greenhollow, Newhollow |
| 우선 문서 | 물리 원인은 객관정보 정본, 사회·문화·제도와 인월드 표현은 기준시대 객관정보를 기본값으로 쓴다. |

역사와 사건 상세, 인물관계, 개별 장면, 대사는 이 허브에 두지 않는다. 물리 원인은 객관정보에 남기고, 필요한 현재 사회 상태는 5083 기준시대 객관정보에 남기며, 장기 연표와 사건 서사는 별도 역사 문서에서 관리한다.

## LunaTalk 사용 기준

LunaTalk 반영본은 객관정보 정본을 직접 말하지 않는다. 인물 발화와 인월드 설명은 기준시대 5083 객관정보를 우선 검색한다.

| 상황 | 사용 문서 |
|---|---|
| 작가용 물리 설정 검증, 시대 이동, 미래 기술 확장 | 객관정보 정본 |
| 5083년 인물 발화, 민간 상식, 신전·관청·학술층 설명 | 기준시대 5083 객관정보 |
| 법·신앙·전승의 현재 운용 | 기준시대 5083 객관정보 |
| 물리 원인과 인월드 오해가 충돌할 때 | 객관정보는 원인, 5083 기준시대 객관정보는 발화 기준 |

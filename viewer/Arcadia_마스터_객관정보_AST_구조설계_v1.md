# Arcadia 마스터 객관정보 AST 구조설계 v1

## 설계 결론

Arion 항성계 객관정보는 여러 기준시대와 파생 세계관이 공통으로 참조하는 제약 DB로 둔다. 따라서 AST 단락은 이야기 순서가 아니라 의존성 순서로 배열한다. 기준시대 통용명, 민간 인식, 문화권별 오해, 의례, 명절, 예언 해석은 AST 객관정보에 넣지 않는다.

| 항목 | 결정 |
|---|---|
| 문서 계층 | `OBJ-*` 객관정보를 원천으로 두고, `CK5083-*`와 이후 시대 문서는 이를 참조한다. |
| 분리 수준 | 현재는 파일을 더 쪼개지 않는다. 객관정보 정본이 커져 검색성이 떨어질 때 도메인 파일 분리를 검토한다. |
| ID 단위 | 문장·표 행이 아니라 재사용 가능한 섹션 단위에만 ID를 둔다. |
| AST 배열 원칙 | 기준 epoch, 항성 물리, 항성 생애, 생명권 안정 창, 항성계 개요, 궤도표, 물리표, Vireth, 위성계, 소천체, 장주기 현상 순서로 둔다. |
| 확정 방식 | 범위값과 불변식을 먼저 고정하고, 기준시대별 관측·인식은 별도 문서에서 파생한다. |

## 현실 물리 기준

| 기준 | 구조 반영 |
|---|---|
| 거주 가능대 | 액체 물이 표면에 존재할 수 있는 항성 거리대를 기본 기준으로 삼는다. 항성의 크기와 광도에 따라 위치가 달라진다. |
| F형 주계열성 | 넓은 거주 가능대를 제공하지만 주계열 수명이 G·K·M형보다 짧고 자외선 비중이 높다. |
| Arion 설정 | Arion은 중후기 F형 주계열성으로 두고, Vireth는 넓은 궤도, 상층 대기, 오존층, 자기권, 해양 차폐 조건으로 생명권을 유지한다. |
| 항성 말기 | Arion은 저질량·중간질량 항성 경로를 따른다. 주계열 종료 뒤 적색거성 단계와 백색왜성 잔존을 항성계 결말 방향으로 둔다. |

참고 기준: NASA Exoplanet Exploration의 habitable zone 정의, NASA의 항성 생애 설명, F형 항성계 거주 가능성 연구의 주계열 수명·자외선·거주 가능대 논의.

| 5 | OBJ-AST-SYSTEM-001 | 독자용 항성계 개요 | 천체 배열, 넓은 권역, 안정·불안정 구간, 요약 수치 |
| 6 | OBJ-AST-PLANETARY-ORBITS-001 | 행성 평균 궤도요소 원천표 | 장반경, 근일점, 원일점, 공전주기, 이심률, 경사, 공전 방향, 공명·섭동, 안정성, 기준 epoch |

| 9 | OBJ-AST-MOON-SYSTEM-001 | 쌍월 체계의 공통 구조 | 위성 수, 조석 중심, 식 기하, 공명 여부, 장기 안정성, 위상주기 산출 기준 |
| 10 | OBJ-AST-CAELUM-001 / OBJ-AST-UMBRA-001 | 각 위성 세부값 | 질량, 반지름, 밀도, 궤도거리, 항성월·삭망월, 경사, 이심률, 조석력, 식 조건 |

## 불변식과 의존 관계

| 불변식 | 적용 |
|---|---|
| `S = L / a^2` | Arion 광도와 Vireth 공전거리 변경 시 Vireth 일사량이 함께 바뀐다. AST-EPOCH-A0 값은 `2.8 Lsun / 1.73 AU`로 지구 대비 약 `0.94` 일사량이다. |
| `P^2 = a^3 / M` | 행성 공전주기는 Arion 질량 1.35 태양질량을 기준으로 검산한다. |
| `g = M / R^2` | 행성 표면중력은 질량과 반지름이 바뀌면 함께 바뀐다. |
| 평형온도 | 일사량, 알베도, 온실 보정이 충돌하지 않아야 한다. |
| 생명권 안정성 | F형 항성의 자외선·항성풍 때문에 Vireth의 오존층, 해양 차폐, 강한 자기권은 필수 조건이다. |
| 쌍월 주기 | Caelum과 Umbra의 항성월·삭망월은 5083 달력과 별개로 물리값으로 먼저 고정한다. |

## 구조상 위험 요소

| 위험 | 처리 |
|---|---|
| 생명권 시간창 미정 | 특정 기준시점의 항성 연령값보다 먼저 항성 수명 대비 생명권 단계와 지성체 가능 창을 정한다. 기준시대는 그 창 안의 특정 시점으로 별도 배치한다. |
| Vireth 생명권 과밀 설정 | 생명 발생부터 문명 가능 구간까지를 단계 범위로만 두고, 세부 생물·문명사는 별도 문서로 보낸다. |
| 항성계 개요표의 원천화 | `OBJ-AST-SYSTEM-001`은 요약으로 두고, 수치 원천은 EPOCH·ORBIT·PHYSICS 표에 둔다. |
| 장주기 현상의 예언화 | 장주기 현상은 확률 창과 물리 원인만 고정한다. 특정 날짜와 필연 사건으로 쓰지 않는다. |
| 위성계 3:1 근접 주기 | Caelum과 Umbra가 안정 공명인지, 공명을 약간 벗어난 장주기 상대 배치인지 정해야 한다. |
| 소행성대 붕괴 서사화 | 전체 붕괴가 아니라 파편 유입률 증가, 공명대 교란, 운석 플럭스 상승으로 제한한다. |

## OBJ 필드 템플릿

| 필드 | 내용 |
|---|---|
| ID | 섹션 단위 고정 ID |
| 계층 | 객관정보 |
| 도메인 | AST, CAL, GEO, POL 등 |
| 정본명 | 객관 명칭 |
| 객관 정의 | 관점 없이 성립하는 정의 |
| 적용 범위 | 어느 천체·권역·제도에 적용되는지 |
| 시간 적용 | 상시, 기간형, 특정 epoch 기준 중 하나 |
| 확정도 | 확정, 범위값, provisional 중 하나 |
| 연결 ID | 직접 의존하거나 참조하는 객관 ID |
| 배제되는 주장 | 이 문서에서 사실로 확정하지 않는 주장 |
| 상태 | canon, provisional, deprecated 중 하나 |

## 다음 반영 단위

1. 객관정보 정본의 AST 시작부에 `OBJ-AST-EPOCH-001`을 추가한다.
2. `OBJ-AST-ARION-001`을 EPOCH 다음으로 이동하거나, 기존 위치를 유지하되 AST 구조상 2번 단락으로 재배치한다.
3. `OBJ-AST-STELLAR-LIFECYCLE-001`과 `OBJ-AST-HABITABILITY-WINDOW-001`을 추가한다.
4. 기존 `OBJ-AST-SYSTEM-001`은 항성계 개요로 낮추고, 수치 원천 역할은 궤도·물리표로 분리한다.
5. 그 뒤 행성 궤도표, 행성 물리표, Vireth 세부, 위성계, 소천체, 장주기 현상을 순차 확장한다.

# Arcadia 기준시대 5083 사회문화 핵심정보 v1

## 문서 역할

이 문서는 물리·과학 객관정보 정본에 넣지 않는 사회·문화·제도성 설정을 기준시대 5083의 핵심정보군으로 관리한다. 아래 항목은 Arion 항성계의 물리 객관정보는 아니지만, 기준시대의 국가, 권역, 종족 분류, 달력, 법, 신앙, 장소, 전승을 성립시키는 기본값이다.

| 항목 | 기준 |
|---|---|
| 문서 역할 | 기준시대 5083 사회문화 핵심정보 |
| 원천 | 물리 객관정보 정본에서 제외했지만 기준시대 세계관에는 필요한 비물리 설정 |
| 귀속 | 기준시대 5083 객관정보, 문화권 정리, 제도 정리, 전승 경계 관리 |
| 물리 정본 포함 여부 | 제외. 단, 기준시대 사회문화 정본에는 포함한다. |
| 사용 방식 | 5083 기준시대 객관정보를 채울 때 권역·국가·종족·달력·법·신앙·장소·전승의 핵심값으로 사용한다. |
| 명칭 운용 | 5083 정본 표면명을 우선하고, 구명칭은 브리지 라벨로 보존한다. |
| 제외 범위 | 인물관계, 장면 서사, 개별 사건 상세, 미래 기준시대 정보 |

# Arcadia 백과형 정본화 현재안건 v1

현재 안건은 세계관 문서를 운영 지침 중심에서 백과형 정본 중심으로 재정렬하는 것이다. v1 문서는 보존하고, 새 정본은 v2로 작성한다.

## 1. 이번 정리의 목표

| 목표 | 설명 |
|---|---|
| 마스터 객관정보 v2 | Arion 항성계, Vireth 행성, 자연 ID를 바로 찾을 수 있는 백과형 정본으로 정리한다. |
| 기준시대 5083 객관정보 v2 | 국가, 권역, 장소, 종족, 법, 신앙, 경제, 이동망을 5083년 세계 백과처럼 정리한다. |
| 운용부록 v2 | 접근권, 응답층, 금지선, 검산 규칙을 본문 밖으로 분리한다. |
| 내부 뷰어 안건 정리 | 안건 보기에는 위 세 문서와 이 현재안건만 남긴다. |

## 2. 검토 순서

| 순서 | 검토 대상 | 확인할 것 |
|---:|---|---|
| 1 | Arcadia_마스터_객관정보_정본_v2.md | 항성계와 행성, 대륙·대양·지형, 기후·수권·생물권이 구체적으로 보이는가 |
| 2 | Arcadia_기준시대_5083_객관정보_v2.md | 대륙권, 나라, 지형 위의 생활권, 도시·장소, 종족이 백과형으로 보이는가 |
| 3 | Arcadia_객관정보_운용부록_v2.md | 운영 규칙이 본문을 방해하지 않고 필요한 검산 기능만 맡는가 |
| 4 | 쉬운 해설본 | 정보 삭제 없이, 이야기하듯 읽히는 문체로 다시 편집할 준비가 되었는가 |

## 3. 다음 확장 후보

| 묶음 | 해야 할 일 |
|---|---|
| 5083 지리 세부 | 각 국가와 권역을 자연 ID 위에 더 촘촘히 배치한다. |
| 국가별 백과 | 수도, 항구, 성채, 시장, 종교기관, 주요 산업을 국가별로 늘린다. |
| 종족 백과 | 철맥계, 숲기록계, 씨앗상단계, 정령혈통계, 주변 전승 종족을 별도 항목으로 확장한다. |
| 역사·사건 | Greenhollow 상실, Ravenstone 방어선, Newhollow 형성 등 주요 사건을 별도 역사 문서로 옮긴다. |
| 인물 | 세계 바닥 정보가 잡힌 뒤 인물관계와 개별 서사를 정리한다. |

## 4. 현재 판단

마스터 객관정보와 기준시대 5083 객관정보는 이제 별도 v2 정본으로 검토할 수 있다. 다음 단계는 v2 본문을 읽으며 빠진 실제 지명, 국가별 하위 도시, 종족별 세부 생활권을 채우는 것이다.

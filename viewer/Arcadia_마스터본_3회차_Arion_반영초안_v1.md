## 마스터 반영 초안

### 항성계 기준

Arion과 Vireth의 물리 기준값은 설정집의 객관 기준이다. 이 값은 5083년 현재 세계 안의 인물들이 모두 이해하는 지식이 아니라, 설정집이 항성계와 역법의 정합성을 유지하기 위해 사용하는 기준이다. 기준 시기의 학자와 천문관은 Arion의 밝기, 광륜, 어림, 바람, 열기 변화를 관측하고 기록하지만, 그 원인은 전근대 자연철학과 신학 언어로 설명한다.

항성계 기준은 두 층위로 다룬다. 첫째, 설정집의 객관 기준은 Arion을 실제 항성으로 두고 Vireth의 공전과 자전을 정리한다. 둘째, 5083년의 인월드 지식은 관측과 기록을 갖추었지만, 해석은 전근대 자연철학과 신학 언어 안에서 이루어진다. 따라서 학술 지식은 민간 신앙과 완전히 분리된 과학 체계가 아니라, 문서화되고 권위화된 전근대 지식 체계다.

마스터본은 객관 기준과 인월드 오해 체계를 함께 둔다. 다만 두 층위의 용도를 분리한다. 객관 기준은 설정 일관성, 역법, 기후, 항성계 수치 검토에 쓰이며, 인월드 오해 체계는 5083년 인물들의 말, 제도, 의례, 판단을 구성하는 기준으로 쓰인다. 이후 LunaTalk 반영본에서는 인물의 체감과 사회적 사실을 우선하므로, 오해 체계를 외부 설명처럼 드러내지 않고 해당 세계의 실존 질서처럼 서술한다.

### Arion

Arion은 5083년 현재 알려진 항성이다. 객관적으로는 항성 활동과 플레어가 Vireth의 대기, 해양 신호, 열기 해석, 극광 현상에 영향을 줄 수 있다. 기준 시대 사람들은 이를 징조, 기운, 영적 열기, 신성 질서의 변화로 설명한다. 민간에서는 징조와 신의 경고로 받아들이고, 직업군은 생산과 위험을 중심으로 해석하며, 학술기관은 관측표와 분류표를 통해 같은 현상을 더 구조적으로 설명한다.

| 구분 | 인식 방식 | 특징 |
|---|---|---|
| 범용 민간 인식 | Arion의 빛, 색깔, 광륜, 일렁임, 하늘의 모양을 징후로 읽는다. | 구전, 속담, 마을별 경험에 의존하며 지역마다 내용이 다르다. |
| 직업군 지식 | 농민, 항해자, 목동, 장인, 병사, 약초꾼, 상인, 관리가 각자의 징조 목록을 가진다. | 실제 경험에서 시작하지만 자기 직업의 위험과 이해관계 쪽으로 과장된다. |
| 문화권 해석 | 에덴포르트, 마레나, 네오테아, 발드라크, 미스테리아는 같은 Arion 현상을 다른 신학과 정치 언어로 해석한다. | 같은 현상이 정권, 바다, 곡식, 금속, 정령, 명예의 언어로 갈라진다. |
| 종족·문화군 해석 | 수명, 감각, 거주지, 생업, 기록 문화에 따라 Arion을 다르게 읽는다. | 장수 기록민은 장기 주기를 만들고, 해양 문화는 수평선과 색깔을 중시한다. |
| 학술·기관 해석 | 관측소, 신전, 왕실 천문관, 길드, 의술 학교, 지역 서기관이 Arion 관측을 문서화한다. | 기관별·문화권별로 설명 체계가 다르며, 같은 현상도 장부, 절기표, 의례, 정치 보고로 다르게 정리된다. |
| 객관 기준 | Arion은 F형 주계열성이며 항성 활동은 실제 물리 현상이다. | 이 기준은 설정집의 정합성 기준이며, 기준 시대 인물들이 직접 이해하는 지식은 아니다. |

#### 민간 해석

민간의 Arion 해석은 하나의 통일된 신앙이 아니다. 마을, 항구, 시장, 목장, 성채, 신전, 광산마다 다른 징조법을 보존한다. 붉은 빛은 이변, 전쟁, 수확 스트레스와 연결되고, 밝기가 지나친 날은 외출이나 중요한 주문과 연결된다. 광륜과 어림은 습한 공기, 비, 병, 신과 인간 사이의 거리로 해석된다. 같은 붉은 일렁임도 농촌에서는 병충해의 전조가 되고, 항구에서는 폭풍의 징조가 되며, 병영에서는 전투의 운과 연결된다.

| 징조 범주 | 민간 해석 |
|---|---|
| 색 | 붉은 빛은 병, 이변, 가뭄, 숱이 맞지 않는 곡식의 스트레스로 읽는다. 푸른 기운은 정권과 성약, 검은 테두리는 조상과 망자의 징조가 된다. |
| 밝기 | 지나치게 강한 Arion은 숨어 있던 병을 드러낸다고 여겨지고, 흐린 Arion은 거짓말, 속임수, 곡식, 숨은 적의 징조가 된다. |
| 광륜과 색깔 | 둥근 빛무리, 어림, 이중적 빛, 비슷한 색깔의 구름을 습한 공기, 비, 이상 안개, 신성 질서의 거리감으로 해석한다. |
| 계절 | 봄의 붉은 빛은 파종 불안, 여름의 강한 빛은 이변, 가을의 흐린 빛은 연금과 저장고, 겨울의 창백한 빛은 기근과 성물을 떠올리게 한다. |
| 달과의 관계 | Caelum 또는 Umbra가 가까워 보이는 날은 약속, 결혼, 임신, 맹세, 정의의 침묵과 연결된다. |
| 사건 이후 해석 | 폭동, 흉작, 전염병, 왕실 사망 뒤에는 이전의 Arion 징조가 새롭게 의미를 얻는다. |

민간 징조는 실패해도 쉽게 폐기되지 않는다. 한 마을은 제사의 정성이 부족했다고 말하고, 다른 마을은 징조를 본 사람이 부정했다고 말하며, 어떤 시장은 날짜를 잘못 세었다고 말한다. 이처럼 민간 해석의 핵심은 정확한 예측보다 공동체가 불안을 설명하고 기억을 재배열하는 방식이다.

#### 직업군 해석

직업군의 Arion 해석은 민간보다 더 실용적이다. 농민의 파종 규칙, 항해자의 출항 금기, 약초꾼의 채집일, 병사의 야영 판단, 관리의 세금 문구는 실제 경험에 닿아 있다. 그러나 그 경험은 신학과 전근대 자연철학 속에서 과장되고 일반화된다. 직업군은 Arion을 직접적인 원인으로 보기도 하고, 이미 다가온 위험을 드러내는 표지로 보기도 한다.

| 농민 | 노을빛이 길게 남으면 곡식이 속에서 마르고, 붉은 원이 흐리면 병충해가 논밭 아래에서 움직인다고 본다. 가문 달력에는 씨뿌림, 물대기, 추수, 저장고 개방일을 Arion의 색과 연결해 적는다. | 파종일, 수확일, 세금 유예 요청, 마을 회의 |

| 단명 농경민 | 당장의 수확, 출산, 병, 연금, 마을 회의에 집중한다. |
| 장수 기록민 | 수십 년 이상의 기록을 모아 장기 주기와 거짓 상관관계를 만든다. |
| 빛에 민감한 집단 | 밝기, 안개, 광륜, 그림자를 신체와 정신의 징조로 강하게 해석한다. |
| 지하·동굴 공간 중심 문화 | Arion을 광석, 정력, 열기, 불길한 금기 행동과 연결한다. |
| 해양 문화 | 수평선, 안개, 항로, 조류, 항구 신호의 변화를 가장 중시한다. |
| 유목·목축 문화 | 가축의 불안, 대마름, 이동 시기, 건조한 바람으로 Arion을 읽는다. |
| 신전 중심 문화 | 주신의 침묵, 공적 참회, 축일 조정, 정권 경고의 언어로 해석한다. |
| 관료제 국가 | 관측 보고, 조세 일정, 역법 조정, 공식 책임 회피의 언어로 만든다. |
| 구전 부족 사회 | 계보, 전투, 이주 기억, 지역 이름에 묶인 서로 다른 징조법을 유지한다. |
| 혼합 도시 | 여러 종족과 직업의 감각 차이가 얽혀 거리 점성술과 장터 논쟁을 만든다. |

#### 학술·기관 해석

5083년의 학술 체계는 Arion을 전근대 자연철학과 신학 언어로 설명한다. 그러나 그 체계는 단일한 중심 기관에 고정되어 있지 않다. Windwatch의 관측자, Sunspire의 학자, 네오테아 왕실 천문관, 신전 서기관, 상인 길드, 의술 학교, 군사 참모, 지방 관청은 각자 다른 목적으로 Arion 관측을 문서화한다.

| 학술 분류 | 기록 대상 | 전근대적 설명 | 그럴듯해 보이는 이유 |
|---|---|---|---|
| 색 분류 | 붉음, 흰 금빛, 흐림, 검은 테두리 | 색끝은 영적 공기, 습기, 주신 체액의 균형이 물든다. | 먼지, 연기, 습도, 대기 변화가 실제 색 변화를 만든다. |
| 테두리 분류 | 맑음, 광륜, 이중 어림, 일그러짐 | 영적 기운의 층이 얇아지거나 달과의 그림자가 겹친다. | 습도와 계절에 따라 시야가 달라진다. |
| 방향 권역 | 북방, 남방, 바다쪽, 성지쪽 | Arion의 숨이 특정 방향의 문으로 들어온다. | 지리별 바람과 기후가 실제로 다르다. |
| 열기형 | 파종, 홍수, 이변, 야영, 연금, 저장 | 빛의 기질마다 계절의 성마름이 달라진다. | 계절 위험이 반복된다. |
| 신체 대응 | 눈, 피부, 피, 장부, 수면 | 빛과 공기가 몸의 체액을 흔든다. | 일부 병증은 계절·환경과 관련된다. |
| 사회 대응 | 왕, 장군, 병사, 어머니, 사제, 상인 | 하늘 질서가 사회 위계를 비춘다. | 정치적으로 설명하기 쉽고 가르치기 쉽다. |
| 징조 강도 | 약함, 혼합, 강함, 왕실급, 전쟁 | 선명도, 지속시간, 목격자 수, 관측 시점을 따져 강도를 정한다. | 실패한 예언을 다시 설명할 수 있다. |
| 교정 의례 | 금식, 공적 낭독, 문 봉인, 깨끗한 물, 계약 연기 | 인간 질서가 하늘의 어긋남에 응답해야 한다. | 불확실성을 행정과 의례로 관리한다. |
| 기록 대조 | 과거 징조와 흉작, 전염병, 별 물가 비교 | 반복되는 표지가 같은 질서를 드러낸다. | 장부에는 충분한 우연 일치가 남는다. |

| 기관 | 사용 |
|---|---|
| 왕실 법정 | 불길한 설명, 통치 경고, 정책 정당화, 관리 징계 |
| 신전 | 축일 조정, 정화 의례, 참회 명령, 금기 선포 |
| 군사 조직 | 야영지 공성 지점의 사기 해석, 병사 통제 |
| 농업 행정 | 파종과 수확 경고, 곡물세 조정 |
| 의술 학교 | 이변, 피 흐름, 열병, 약초 채집 시기 설명 |
| 상인 길드 | 계약일, 대금 출발, 곡물 매입, 해상 보험 관습 |
| 서기관 관청 | 공식 징조 용어 표준화, 보고서 검열, 책임 문구 정리 |
| 지방 회의 | 시장 폐쇄, 격리일, 공적 의례, 감세 청원 결정 |

학술 해석은 민간보다 더 정리되어 있지만, 반드시 더 객관적인 것은 아니다. 장부, 절기표, 의례서, 법정 기록이 서로를 인용하면서 권위를 얻고, 관측 실패는 표의 결함보다 해석자의 부주의, 지방 관측 조건, 정치적 부정, 의례 누락으로 설명되기 쉽다.

#### 달력과 징조표의 보급

Arion 달력과 징조표는 일반 가정에도 널리 퍼져 있다. 다만 모든 가정이 같은 수준으로 해석하지는 않는다. 대부분의 가정은 간단한 절기표, 축일표, 금기일, 장날 표시를 사용하고, 정확한 의미는 신전, 관청, 길드, 시장 서기관에게 확인한다. 근현대적 과학 발달로 세계가 통합된 시대가 아니므로, 같은 날짜와 같은 하늘 현상도 문화권과 지역권에 따라 다르게 읽힌다.

| 보급 층위 | 사용 방식 |
|---|---|
| 일반 가정 | 벽걸이 절기표, 가문 달력, 축일표, 장날 표시를 사용한다. 해석은 가족 어른, 마을 신관, 시장 소문에 의존한다. |
| 마을 공동체 | 공동 우물, 창고, 신전 앞에 공용 달력을 붙이고, 파종일과 금기일을 공개한다. |
| 신전 | 축일, 정화일, 금식일, 참회일을 공식 해석한다. 같은 Arion 징조도 교단마다 다른 신학 언어로 설명한다. |
| 관청 | 세금, 징병, 재판일, 시장 폐쇄, 격리일을 달력과 연결한다. 관청 달력은 행정 권위를 가진다. |
| 길드 | 항해, 장거리 교역, 제련, 약초 채집, 고용 계약에 맞춘 실무 달력을 만든다. |
| 학술기관 | 관측표와 주석서를 보관하고, 지역별 차이를 설명하기 위해 더 복잡한 분류표를 만든다. |

따라서 기준 시대의 사람들은 달력을 사용하지만, 그것이 하나의 세계 표준 시간 체계를 의미하지는 않는다. 같은 시간을 공유해도 각 문화권은 그 시간을 자기 신앙, 법, 생업, 기억에 맞추어 해석한다.

#### 실패한 징조 해석의 처리

실패한 징조 해석은 하나의 보편 규칙으로 처리되지 않는다. 문화, 왕조 시기, 지역, 종족·문화군, 기관의 이해관계에 따라 다르게 설명된다. 중요한 것은 실패를 판정하는 방식 자체가 사회 질서의 일부라는 점이다.

| 처리 방식 | 주로 나타나는 맥락 | 설명 |
|---|---|---|
| 의례 보정 | 신전, 농촌, 공동체 축일 | 정성이 부족했거나 금기를 어겼다고 보고 금식, 정화, 재봉헌으로 처리한다. |
| 책임 전가 | 왕실 법정, 관청, 군사 조직 | 관측자, 지방 관리, 지휘관, 서기관에게 책임을 돌려 정치적 손실을 줄인다. |
| 기록 수정 | 학술기관, 관측소, 서기관 학교 | 관측 시각, 색 분류, 목격자 수, 강도 등급을 조정해 표의 권위를 보존한다. |
| 재해석 | 시장, 길드, 장거리 교역 | 예언이 틀린 것이 아니라 다른 상품, 다른 항로, 다른 위험을 가리켰다고 해석한다. |
| 침묵과 망각 | 민간, 소규모 마을, 패전 직후 | 맞지 않은 징조는 오래 말하지 않고, 맞은 것처럼 보이는 사례만 속담으로 남긴다. |
| 학파 논쟁 | 대도시 학술권, 의술 학교, 왕실 천문관 | 해석법의 우열을 두고 논쟁하지만, 전근대적 전제 자체는 쉽게 버리지 않는다. |
| 종족·문화군별 처리 | 장수 기록민, 구전 부족, 해양 문화, 지하 문화 | 장수 기록민은 장기 표를 고치고, 구전 부족은 영웅담에 편입하며, 해양 문화는 항로 금기를 조정한다. |

이 처리 방식은 고정된 정답이 아니라 시대 상황을 반영하는 방향성이다. 강한 중앙 왕권 아래에서는 책임 전가와 공적 의례가 강화되고, 길드가 강한 도시에서는 실무 달력의 수정이 늘어나며, 전쟁기에는 징조 해석이 사기와 명분 관리의 언어가 된다.

## 검토 결정

| 항목 | 결정 |
|---|---|
| 객관 천문값과 5083년 오해 체계 | 마스터본에는 둘을 함께 둔다. 다만 객관 기준은 설정 정합성 기준이고, 5083년 오해 체계는 인물·제도·의례의 현재 인식 기준이다. LunaTalk 반영본에서는 이 오해 체계를 세계 안의 실존 질서처럼 서술한다. |
| 직업군과 문화권 사례 | 마스터본에는 분량 제한을 두지 않고 밀도 있게 서술한다. 압축은 이후 LunaTalk 반영본에서 수행한다. |
| 학술 해석의 중심 | Windwatch와 Sunspire로 고정하지 않는다. 문화권, 지역권, 왕조 시기, 기관 목적에 따라 학술 해석이 달라질 수 있다. |
| 종족·문화군 처리 | 이번 Arion 장에서 최종 확정하지 않는다. 다만 여기서 정리한 감각·수명·생업 차이는 이후 종족 백과와 문화군 설정을 교정하고 확장하는 기준으로 쓴다. |
| Arion 달력과 징조표 | 일반 가정까지 보급되어 쓰이지만, 정확한 해석은 신전, 관청, 길드, 서기관에게 확인하는 경우가 많다. 같은 시간도 문화권과 지역권에 따라 다르게 해석된다. |
| 실패한 징조 해석 | 하나의 처리 방식으로 고정하지 않는다. 문화, 왕조 시기, 지역, 종족·문화군, 기관 이해관계에 따라 의례, 책임 전가, 기록 수정, 재해석, 침묵, 학파 논쟁이 달라진다. |

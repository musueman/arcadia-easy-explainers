# 비레스 루나톡 통합 DB 3구조 설계 제1판

비레스 루나톡 통합 DB는 `#세계관`, `#캐릭터`, `#시스템` 세 덩어리로 구성한다. 지금까지 작성한 마스터 객관정보, 기준시대 5083 객관정보, 도시·마을·종족·언어·달력 DB는 `#세계관`에 들어간다. 인물의 성격, 관계, 현재 위치, 행동 경향은 `#캐릭터`에 들어간다. 사용자가 작은 한 인물로 세계를 경험할 때 적용되는 진행 규칙은 `#시스템`에 들어간다.

## 1. 최상위 구조

### 1.1 세계관

`#세계관`은 비레스가 어떤 세계인지, 기준시대 5083년에 무엇이 존재하는지, 각 장소와 집단이 어떤 조건에서 굴러가는지를 담는다. 세계관 DB는 인물의 선택을 지시하지 않고, 인물이 움직일 수 있는 환경과 제약을 제공한다.

포함 범위는 다음과 같다.

| 분류 | 포함 내용 |
|---|---|
| 자연사 | 아리온 항성계, 비레스, 카엘룸, 움브라, 소천체권, 기후, 지형, 생물권 |
| 기준시대 | 에덴포르트 서력 5083년, 비레스 문명권의 정치·생활 표면 |
| 국가·권역 | 모든 국가와 주변 권역의 지리, 통치, 경제, 신앙, 법, 도시망 |
| 도시·마을 | 수도, 대표도시, 지역 도시, 외곽 소도시, 마을, 구조물, 가도, 항로, 국경 |
| 종족·집단 | 인간계, 페르브루니르, 실레니르, 메르세니르, 님소리르, 북방 복합 집단, 주변 전승 집단 |
| 언어·문자 | 공용서기어, 문화권별 언어, 종족어, 문해력, 기록 접근성 |
| 달력·절기 | 비레스 물리 시간, 문화권별 달력, 주기명, 절기, 장부일 |
| 법·신앙·전승 | 국가별 사법 표면, 신앙, 의례, 민간 전승, 장기 기억 |
| 역사 닻 | 광역 사건, 티리스 서부 사건, 그린할로우 함락, 뉴할로우 형성 |

티리스 서부 사건은 비레스 문명권 전체 시뮬레이션의 출발점에 놓인 큰 사건이다. 다만 세계관 DB 전체가 티리스 중심으로 기울지는 않는다. 티리스, 노르가르드, 레오니아, 린레네트, 벡도레트, 센할레트, 북방·외연권, 남방 복합권, 주변 대륙권은 모두 비슷한 밀도의 기본 정보를 가진다.

### 1.2 캐릭터

`#캐릭터`는 특정 인물이 세계 안에서 누구인지, 무엇을 알고 있고, 누구와 연결되어 있으며, 어떤 태도와 한계를 갖는지를 담는다. 캐릭터 DB는 세계 전체의 설명을 반복하지 않고, 각 인물이 실제로 접한 지식과 관계만 가진다.

포함 범위는 다음과 같다.

| 분류 | 포함 내용 |
|---|---|
| 기본 신원 | 이름, 나이대, 소속, 신분, 직업, 거주지, 현재 위치 |
| 지식 범위 | 인물이 직접 알고 있는 지역, 사건, 소문, 문서, 오해 |
| 관계 | 가족, 보호자, 후원자, 적대자, 동료, 거래처, 법적 보증인 |
| 태도 | 신앙, 법, 폭력, 돈, 종족, 외부자, 전쟁에 대한 경향 |
| 행동 표면 | 대화 방식, 거래 방식, 갈등 시 반응, 위험 감수 정도 |
| 사건 연결 | 티리스 서부 사건, 국가 사건, 도시 사건과의 관계 |

캐릭터는 세계관 DB의 모든 사실을 자동으로 알지 않는다. 예를 들어 뉴할로우 출신 인물은 티리스 서부 사건과 피난민 생활에는 밝지만, 님나레트 봉인 학술이나 드래곤스파이어 화산 항로에는 소문 수준으로만 닿을 수 있다.

### 1.3 시스템

`#시스템`은 사용자가 비레스 안의 작은 인물로 행동할 때 적용되는 진행 원칙이다. 시스템은 세계관 사실을 바꾸지 않고, 세계관과 캐릭터 DB를 사용해 장면을 굴린다.

포함 범위는 다음과 같다.

| 분류 | 포함 내용 |
|---|---|
| 시점 | 사용자는 전지적 관찰자가 아니라 한 인물로 행동한다. |
| 정보 접근 | 지역, 신분, 문해력, 소문, 문서 접근권에 따라 아는 정보가 달라진다. |
| 이동 | 거리, 가도, 항로, 국경, 검문, 계절, 비용, 동행자 조건을 반영한다. |
| 경제 | 돈, 물자, 세금, 부채, 장부, 보증, 길드, 항만세를 반영한다. |
| 법과 치안 | 성문, 검문, 억류, 재판, 관습법, 신전 중재, 보증인을 반영한다. |
| 갈등 | 사건은 고정된 결말이 아니라 발발 가능성과 해소 가능성을 가진다. |
| 불확실성 | 기록, 소문, 전승, 학술 해석은 서로 다를 수 있다. |
| 금지 표면 | 사용자의 작은 행동으로 왕국 전체가 즉시 움직이지 않는다. |

## 2. 세계관 DB 변환 기준

### 2.1 표의 서술형 변환

루나톡용 세계관 DB에서는 표를 그대로 넣지 않는다. 표의 한 행은 하나의 짧은 서술 카드로 바뀐다. 행의 정보량은 유지하되, AI가 문장 단서로 검색할 수 있게 고유명과 핵심 관계를 문장 안에 넣는다.

예시는 다음과 같다.

| 마스터 DB 형태 | 루나톡 세계관 DB 형태 |
|---|---|
| `티리스 / 농경·목축 군주국 / 온대 농경 영지 / 낮은 율례` | `[[티리스]]는 온대 농경 영지와 목축지, 숲 경계, 서부 접경을 가진 군주국이다. 티리스의 법정 질서는 왕실 법정, 영지 재판, 낮은 율례, 녹색 신앙과 연결된다.` |
| `노르가르드 / 해군·철강 팽창 왕국 / 군항 / 항만세` | `[[노르가르드]]는 북방 해안과 군항, 철강 부두를 가진 해군·철강 팽창 왕국이다. 항만세, 선박 징발, 해상 법원, 상인 길드가 국가 생활의 표면을 이룬다.` |

### 2.2 그림과 도식의 처리

그림과 도식 자체를 길게 설명하지 않는다. 도식이 담고 있는 관계만 짧은 세계관 단서로 바꾼다.

| 도식 정보 | 루나톡 단서 |
|---|---|
| 아리온 항성계 구조도 | `[[아리온 항성계]]는 중심 항성 [[아리온]]과 아홉 주요 행성, 내부 소행성대, 닉스 천체대 밀집권으로 이루어진다. [[비레스]]는 제3행성이며 문명권의 기준 행성이다.` |
| 비레스 쌍월 관계도 | `[[비레스]]에는 밝은 주 위성 [[카엘룸]]과 어두운 보조 위성 [[움브라]]가 있다. 두 위성은 해안, 항만, 밤길, 조석 전승에 영향을 준다.` |
| 5083년 국가·문화권 도식 | `5083년 [[비레스 문명권]]은 에덴포르트 중심권, 북방·외연권, 남방 복합권, 주변 대륙·전승권으로 나뉜다.` |

### 2.3 균일 밀도 원칙

세계관 DB의 국가·권역 항목은 특정 국가만 지나치게 커지지 않도록 같은 기본 필드를 가진다. 티리스 서부 사건은 시뮬레이션의 시작 사건으로 중요하지만, 티리스 자체가 전체 세계관의 유일한 중심은 아니다.

국가별 기본 필드는 다음과 같다.

| 필드 | 내용 |
|---|---|
| 위치와 자연환경 | 기후권, 지형, 주요 생활권 |
| 통치와 법 | 통치 구조, 법정, 검문, 사법 표면 |
| 경제와 물자 | 주요 생업, 세금, 물자, 교역 |
| 신앙과 의례 | 신앙, 달력, 공적 의례일 |
| 도시와 생활 표면 | 수도, 대표도시, 지역 도시, 공공시설 |
| 종족과 언어 | 주요 종족 분포, 공용어, 지역어, 기록층 |
| 주변국 관계 | 교역, 전쟁 압력, 외교, 소문 |
| 작은 인물의 접점 | 사용자가 그 지역에서 실제로 겪는 검문, 숙박, 장터, 소문, 비용 |

## 3. 루나톡 투입 분량 설계

### 3.1 전체 분량

루나톡 통합 DB는 `#세계관`, `#캐릭터`, `#시스템`을 한 캐릭터 위키 안에 넣는 구조를 기준으로 설계한다. 세계관만 20만 자를 채우지 않고, 캐릭터와 시스템이 들어갈 여유를 남긴다.

제1판의 보존 구조는 `#` 3개 아래에 `##` 대분류를 두고, 개별 항목은 `###` 카드로 배치한다. 다만 루나톡 위키 가이드는 `# 제목 / ## 소제목`마다 새 청크가 시작되고, 한 청크가 약 2,200자를 넘으면 단락 단위로 다시 쪼개진다고 설명한다. 따라서 실제 업로드 최적화본에서는 `##`를 너무 큰 대분류로만 쓰지 않고, 인물별·장소별·사건별 검색 단위가 `##`에 오도록 재분할하는 편이 검색 정확도에 유리하다.

| 구역 | 목표 분량 |
|---|---:|
| 세계관 | 60,000~85,000자 |
| 캐릭터 | 80,000~95,000자 |
| 시스템 | 8,000~15,000자 |
| 여유 | 5,000~20,000자 |
| 총합 | 150,000~180,000자 |

현재 제1판 산출물은 세계관 약 76,500자, 캐릭터 약 91,100자, 시스템 약 6,300자, 통합 약 173,900자다. 헤더 구조는 `H1 3개`, `H2 15개`, `H3 360개`이며, 캐릭터 ID는 `C001~C200` 200명이다. 캐릭터는 `019f362f-57c5-70a0-8b47-92d9eae3eb8d` 스레드에서 생성된 고정 캐릭터 200명 제2판 원본을 바탕으로 확장한다. 현재 통합본은 보존본으로는 적절하지만, 루나톡 실투입용으로는 `###` 카드 일부를 `##` 검색 단위로 승격한 별도 업로드본을 만드는 편이 좋다.

실투입 제1판은 보존본의 정보를 삭제하지 않고 헤더만 루나톡 검색 단위에 맞춰 재배치한다. `Arcadia_루나톡_통합DB_실투입_v1.md`는 `H1 3개`, `H2 360개`, `H3 0개`이며, 모든 개별 세계관·캐릭터·시스템 카드를 `##` 검색 단위로 둔다. 각 카드는 최대 약 800자 미만으로 유지되어 2,200자 초과에 따른 단락 재분할이 발생하지 않는다. 분리 업로드가 필요할 때는 `세계관DB_실투입`, `캐릭터DB_실투입`, `시스템DB_실투입` 3개 파일을 사용한다.

### 3.3 청크 크기

각 `## [[고유명]]` 단락은 하나의 검색 카드처럼 작동한다. 한 단락은 800~1,800자를 기본으로 잡고, 국가나 대형 사건은 2~4개 단락으로 나누어 균일한 밀도를 유지한다.

| 카드 유형 | 권장 크기 |
|---|---:|
| 항성계·행성 카드 | 1,000~1,800자 |
| 국가 카드 | 국가당 2,500~4,000자, 2~3개 단락으로 분할 |
| 도시 카드 | 도시당 600~1,200자 |
| 마을 카드 | 마을 유형당 500~900자 |
| 종족 카드 | 종족당 1,000~1,800자 |
| 언어·달력 카드 | 체계당 1,000~2,000자 |
| 사건 카드 | 사건당 1,200~2,500자 |

## 4. 추출 순서

### 4.1 첫 추출 대상

첫 루나톡용 추출은 `#세계관`부터 만들고, 이어서 `#캐릭터`, `#시스템`을 별도 파일로 만든 뒤 통합한다. 캐릭터는 별도 스레드의 고정 캐릭터 200명 산출물을 원본으로 삼고, 소규모 NPC 생성 기준은 캐릭터가 아니라 시스템에 둔다.

첫 추출 순서는 다음과 같다.

| 순서 | 대상 | 산출 |
|---:|---|---|
| 1 | 세계 기본 구조 | 아리온, 비레스, 카엘룸, 움브라, 자연권 |
| 2 | 5083년 세계 총람 | 비레스 문명권, 대권역, 지식층, 생활 표면 |
| 3 | 국가·권역 | 모든 국가와 주변 권역을 균일한 밀도로 서술 |
| 4 | 도시·마을 | 수도, 대표도시, 지역 도시, 마을 유형, 가도·항로 |
| 5 | 종족·집단 | 종족별 생활권, 사회 접점, 언어 |
| 6 | 언어·달력 | 공용서기어, 문화권별 언어, 달력 체계 |
| 7 | 법·신앙·생활 | 신앙, 법정, 경제, 의술, 이동, 치안 |

### 4.2 티리스 서부 사건의 위치

티리스 서부 사건은 비레스 문명권 전체 시뮬레이션의 시작지점에 놓인 큰 사건이다. 이 사건은 사용자가 처음 세계에 진입할 때 접하는 정치·피난·법정·군사·소문·물자 흐름의 강한 배경으로 작동한다.

다만 티리스 서부 사건은 세계관의 유일한 줄기가 아니다. 같은 시점에 노르가르드의 군항과 철강 경제, 레오니아의 궁정 외교, 린레네트의 기록·예술 소비, 벡도레트의 방어 체계, 센할레트의 재정착 지식, 북방권의 용병·저장고 질서, 남방권의 약초·관측·상업 네트워크도 독립적으로 움직인다.

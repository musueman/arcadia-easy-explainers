# Arcadia 문화권별 달력체계 설계초안 v1

## 목적

이 문서는 에덴포르트 서력 5083년 기준 Arcadian Sphere 안에서 병용되는 문화권별 달력 체계를 설계하기 위한 초안이다. 마스터본에 바로 넣는 정본이 아니라, 실제 역사 사례와 현재 세계관의 문화권을 맞추어 검토하기 위한 작업 문서다.

## 공통 기준

| 항목 | 기준 |
|---|---|
| 물리 기준 | Vireth의 1년은 660일, 1일은 26시간이다. |
| 공통 행정 기준 | 에덴포르트 서력은 대륙권 교역, 외교, 전쟁 기록의 기준 연호로 쓰인다. |
| 생활 주기 | 10일을 한 주기로 삼는 생활력은 티리스와 에덴포르트권에서 널리 쓰인다. |
| 사회시 | 하루를 22구간으로 나누는 Arcadian 조정시는 의례, 보초, 장터, 농경 절기에 쓰인다. |
| 문화권 차이 | 같은 날짜와 천문 현상도 국가, 신앙, 생업, 지리, 종족·문화군에 따라 다르게 해석된다. |
| LunaTalk 후속 원칙 | 마스터본에서는 객관 기준과 문화권별 해석을 구분하지만, LunaTalk 반영본에서는 인물의 문화권에서 통용되는 달력을 자연스러운 현실로 서술한다. |

Arcadia의 달력은 하나의 세계 표준으로 통합되지 않는다. 학술 문서와 외교 문서는 에덴포르트 서력을 쓰지만, 일반 가정은 지역 생활력과 신전 축일표를 함께 사용한다. 항해자, 상인, 군대, 신전, 농민, 유목민은 같은 660일을 서로 다른 방식으로 나누고 부른다.

| 장기 전사귀족 주기력 | 갈리아 Coligny 달력 같은 다년 태음태양 주기 | 귀족 의례, 전사 맹세, 축제일, 계절 조정을 장기 순환으로 묶음 |
| 산악 제국 의례력 | 잉카식 산악·태양·제국 의례력 | 산, 태양, 수도, 순례, 행정 동원을 하나의 질서로 묶음 |

## 문화권별 달력 설계

### 에덴포르트 공용 서력

| 항목 | 설정 |
|---|---|
| 달력명 | 에덴포르트 서력 |
| 유형 | 태양 행정력 |
| 실제 사례 대응 | 이집트 민간력, 율리우스력·그레고리력의 행정 표준화 |
| 기본 구조 | 660일 1년, 66개 10일 주기 |
| 사용 주체 | 왕실, 관청, 외교문서, 군사 기록, 대륙 교역 장부 |
| 사회 기능 | 공문서의 날짜 통일, 세금과 징병, 조약, 법정 출석일 정리 |
| 민간 차이 | 일반인은 서력을 알지만, 실제 생활에서는 지역 장날과 신전 축일을 함께 본다. |

에덴포르트 서력은 Arcadian Sphere 전체의 유일한 달력이 아니라, 교역과 외교를 위한 공통 환산 표준이다. 관청 문서에는 서력 날짜가 먼저 적히고, 그 아래에 지역력, 신전 축일, 군사 주기가 병기된다.

### 티리스 녹지절력

| 항목 | 설정 |
|---|---|
| 달력명 | 녹지절력 |
| 유형 | 농경 절기력, 10일 생활력, 3대 농경 계절력 |
| 실제 사례 대응 | 이집트 범람·생장·수확 3계절력, 중국 24절기, 중세 농업 축일력, 일본 달력 주석 |
| 기본 구조 | 66개 10일 주기를 3대 농경 계절과 8대 절기, 여러 소절기로 묶음 |
| 사용 주체 | 농민, 영지 관청, 녹색 여신 신전, 곡물 장부관 |
| 사회 기능 | 파종, 수확, 물대기, 양모 깎기, 곡물세, 공동 창고 개방일 |
| 민간 차이 | Greenhollow와 Newhollow는 같은 녹지절력을 쓰지만, 불탄 날과 피난일을 별도 기억일로 덧붙인다. |

티리스의 달력은 곡식과 목축, 공동체 의례에 맞추어 읽힌다. 신전은 절기를 여신의 숨결로 설명하고, 관청은 같은 절기를 곡물세와 창고 개방일로 쓴다. 농민은 정확한 천문 원리보다 “몇 번째 초록주기 뒤에 씨를 넣는가”를 더 중요하게 여긴다.

| 티리스 3대 계절 | 포함 절기 | 성격 |
|---|---|---|
| 흙깨어남 | 첫싹절, 물오름절 | 밭갈이, 씨앗 선별, 물길 정비, 공동 노동 배치 |
| 초록가득 | 잎그늘절, 흰빛절, 여문절 | 성장, 병충해 감시, Arion 강광기 해석, 감세·증세 논쟁 |
| 곡식잠김 | 거둠절, 뿌리절, 씨잠절 | 수확, 저장, 장례, 빚 정리, 다음 해 파종 운세 |

| 티리스 절기 | 대략적 위치 | 기능 |
|---|---:|---|
| 첫싹절 | 1~8주기 | 씨앗 선별, 봄 밭갈이, 가문 달력 갱신 |
| 물오름절 | 9~16주기 | 관개, 우물 정화, 목초지 개방 |

| 흰빛절 | 25~33주기 | Arion 강광기 해석, 외출 금기, 곡식 보호 의례 |
| 여문절 | 34~43주기 | 수확 예비, 세금 산정, 창고 수리 |

레오니아는 달력을 왕권의 질서로 본다. Caelum과 Umbra는 용의 양안으로 해석되고, 쌍위성 식은 왕이 결단해야 하는 날로 기록된다. 왕실 천문관의 계산은 학술 행위이면서 동시에 정치 행위다.

### 노르가드 조류력

| 항목 | 설정 |
|---|---|
| 달력명 | 조류력 |
| 유형 | 항해·상업 태음태양력, 달 위상 어로력 |
| 실제 사례 대응 | 바빌로니아 태음태양력, 이슬람 초승달 관측, 하와이 달 위상 어로력, 항해 알마낙 |
| 기본 구조 | Caelum과 Umbra의 위상, 조류, 어장, 등대 신호, 항구 장날을 함께 기록 |
| 사용 주체 | 해군, 상인 길드, 항구 신전, 해상 법원 |
| 사회 기능 | 출항일, 항로 금기, 선박 계약, 항만세, 해상 보험, 등대 점검 |
| 민간 차이 | 항구마다 초승달 목격과 안개 색에 따른 출항 금기가 다르다. |

노르가드 달력은 바다에 맞추어진다. 관청은 에덴포르트 서력으로 세금을 걷지만, 선장은 조류력으로 출항일을 고른다. 마레나 신전은 새 달이 보이지 않는 밤을 심해가 입을 닫은 날로 부르고, 상인 길드는 같은 날을 보험료가 오르는 날로 적는다.

| 조류력 표기 | 의미 | 사용 |
|---|---|---|
| 흰등 밤 | Caelum이 밝아 야간 항해가 쉬운 밤 | 연안 항해, 야간 어로, 등대 점검 |
| 검은종 밤 | Umbra가 짙고 해면이 어둡게 보이는 밤 | 출항 금기, 심해 의례, 선원 보호기도 |
| 두물갈림 | 두 위성의 위상과 조류 해석이 어긋나는 시기 | 보험료 인상, 항로 변경, 항구 소문 |
| 마레나의 닫힌 입 | 초승달 목격이 실패하거나 안개가 짙은 날 | 신전 해석, 선장 회의, 출항 연기 |

### 표기 규칙

| 항목 | 기준 |
|---|---|
| 날짜 표기 | `주기-일` 형식으로 적는다. 예: `01-01`은 1주기 1일, `66-10`은 66주기 10일이다. |
| 1년 구조 | 66주기, 각 주기 10일, 총 660일이다. |
| 휴일 여부 | 이 표는 공휴일을 지정하지 않는다. 명절, 의례일, 기억일, 금기일, 장터 기준일만 둔다. 실제 휴무는 국가, 영지, 길드, 신전, 가문 관습에 따라 달라진다. |
| 공용성 | 각 달력의 날짜는 해당 문화권 안에서 대체로 통용되는 기준이다. 지역별 이름과 세부 의례는 달라질 수 있다. |
| 병기 방식 | 외교문서와 장거리 교역 문서는 에덴포르트 서력 날짜를 병기한다. |

# Arcadia 기준시대 5083 공용어 생성체계 초안 v1

## 문서 역할

이 문서는 기준시대 5083에서 인간 중심 문화권이 사용하는 공용어를 먼저 제작하기 위한 생성 규칙을 정리한다. 목표는 특정 이름을 한 번에 고르는 것이 아니라, 의미에 맞는 철자와 발음을 반복적으로 생산할 수 있는 규칙을 만드는 것이다.

| 항목 | 기준 |
|---|---|
| 우선 대상 | 에덴포르트 인간 공용서기어 |
| 사용 층위 | 관청, 법정, 교역, 길드, 신전, 학술 기록, 대륙 간 외교 |
| 일상 사용 | 도시민과 교역층은 널리 사용하고, 농촌과 접경은 지역 방언과 병용한다. |
| 이종 사용 | 인간과 섞여 사는 이종은 공용어를 관청어와 교역어로 사용한다. |
| 종족어 처리 | 드워프계, 엘프계, 하플링계 등은 별도 종족어를 가지되, 공용어와 같은 의미 ID를 공유하고 각 언어별 음운·문자 규칙으로 다른 표면형을 만든다. |
| 문자 처리 | 실제 문자표 이미지는 후속 단계에서 정한다. 이번 문서는 로마자 전사, 발음, 어근, 접사 규칙을 우선한다. |

## 제작 원칙

| 원칙 | 적용 |
|---|---|
| 의미 우선 | 단어는 소리의 인상보다 의미 분해에서 출발한다. |
| 공용 의미망 | 인간, 이종, 문화권이 공유 가능한 핵심 의미를 먼저 만든다. |
| 외명과 자명 분리 | 공용어 이름은 외부 명칭일 수 있으며, 종족 내부 자명과 같을 필요가 없다. |
| 방언은 변형 규칙 | 방언은 별도 단어장이 아니라 발음, 축약, 선호 접사의 차이로 잡는다. |
| 문자와 언어 분리 | 같은 언어가 지역에 따라 다른 문자로 적힐 수 있다. |
| 생성 가능성 | 새 장소, 종족, 기관, 전승을 만들 때 같은 규칙으로 새 이름을 생산할 수 있어야 한다. |
| 한국어 글로스 비노출 | 한국어 단어는 작가용 입력 키로만 쓰고, 인월드 철자와 발음으로 직접 노출하지 않는다. |
| 실제 언어의 제한 차용 | 실제 언어와 고대 문자는 음운 질감, 문자 모양, 표기 습관의 참고로만 쓰고 단어를 대량 복제하지 않는다. |

## 공용서기어 전사와 발음

공용서기어의 작가용 전사는 로마자를 쓴다. 실제 인월드 문자표는 후속 단계에서 선택한다.

| 분류 | 규칙 |
|---|---|
| 기본 모음 | a, e, i, o, u |
| 이중모음 | ai, au, ei, oi |
| 기본 자음 | b, d, f, g, h, k, l, m, n, p, r, s, t, v, y, w, z |
| 보조 자음 | sh, ch, j |
| 쓰지 않는 글자 | q, x, th, 단독 c |
| 음절 구조 | (자음)(l/r/y/w)+모음+(n/r/l/s/k/t/m 중 하나) |
| 강세 | 뒤에서 두 번째 음절에 둔다. 두 음절 단어는 첫 음절에 둔다. |
| 묵음 | 없다. 적힌 모음은 모두 읽는다. |
| 장음 | 표기하지 않는다. 의례 낭독에서는 강세 음절을 길게 읽을 수 있다. |

### 발음 표

| 전사 | 기준 발음 | 한국어 근사 |
|---|---|---|
| a | /a/ | 아 |
| e | /e/ | 에 |
| i | /i/ | 이 |
| o | /o/ | 오 |

| sh | /sh/ | 쉬/슈 |

| j | /j/ | 지/자 계열 |

## 기능어와 최소 문장문법

기능어는 닫힌 목록으로 관리한다. 새 단어를 만들 때마다 기능어를 늘리지 않고, 의미 어근과 접사로 처리할 수 있는 것은 어근·접사 체계에 맡긴다. 공용서기어의 문장은 `주어 + 시제·양태 + 동사 + 목적어 + 보조구`를 기본으로 한다.

### 인칭과 지시

| 기능어 | 기능 | 사용 기준 | 예시 |
|---|---|---|---|
| mi | 1인칭 단수 | 말하는 사람, 서명자 | `mi reno`: 내가 기록한다 |
| tu | 2인칭 단수 | 듣는 사람, 명령 수신자 | `tu dato`: 네가 넘긴다 |
| se | 3인칭 단수 | 앞서 언급된 사람·대상 | `se yalo`: 그가 본다 |
| mir | 1인칭 복수 | 우리, 우리 관청, 우리 길드 | `mir varo`: 우리가 맹세한다 |
| tir | 2인칭 복수 | 너희, 수신 집단 | `tir hedo`: 너희가 계량한다 |
| ser | 3인칭 복수 | 그들, 해당 집단 | `ser woko`: 그들이 간다 |
| da | 가까운 이것 | 말하는 쪽에 가까운 대상 | `da renum`: 이 기록소 |
| du | 먼 저것 | 듣는 쪽 또는 먼 곳의 대상 | `du dorkar`: 저 돌 성채 |
| al | 공식적으로 특정된 것 | 법정·계약·장부에서 지정 대상 표시 | `al garhal`: 해당 곡식 회관 |

### 관계 기능어

관계 기능어는 명사구 앞에 둔다. 한국어 조사처럼 모든 의미를 촘촘히 나누지 않고, 기록문에 필요한 최소 관계만 표시한다.

| 기능어 | 기능 | 위치 | 예시 |
|---|---|---|---|
| ke | 향함, 수신자, 목적지 | 명사구 앞 | `dato ke renan`: 서기에게 넘긴다 |
| dal | 출처, 기원, 떠난 곳 | 명사구 앞 | `woko dal dorkar`: 돌 성채에서 떠난다 |
| lo | 장소, 안, 때 | 명사구 앞 | `reno lo garhal`: 곡식 회관에서 기록한다 |
| min | 함께, 동반, 도구 | 명사구 앞 | `seko min sekir`: 절단 도구로 자른다 |
| sha | 목적, 이유, 용도 | 명사구 앞 | `hedo gar sha var`: 법을 위해 곡식을 계량한다 |
| li | 병렬, 그리고 | 두 단위 사이 | `gar li fer`: 곡식과 쇠 |
| va | 선택, 또는 | 두 단위 사이 | `nav va kel`: 배 또는 길 |

### 수량과 시간 관계

수량 기능어는 세금, 재고, 병참, 증언 범위를 표시하기 위한 최소 장치다. 숫자 체계는 별도 회차에서 만들고, 여기서는 수량 범위만 둔다.

| 기능어 | 기능 | 위치 | 예시 |
|---|---|---|---|
| on | 하나, 단일 | 명사 앞 | `on sekir`: 자르는 도구 하나 |
| mor | 모두, 전체 | 명사 앞 | `mor gar`: 모든 곡식 |
| pel | 일부, 몫 | 명사 앞 | `pel fer`: 쇠 일부 |
| nul | 없음, 무량 | 명사 앞 또는 서술부 | `nul ren`: 기록 없음 |
| ek | 각각, 각 | 명사 앞 | `ek renan`: 각 서기 |
| ran | 전에, 앞서 | 시간 명사 앞 | `ran tikren`: 절차 기록 전에 |
| lun | 후에, 뒤이어 | 시간 명사 앞 | `lun sor`: 의례 후에 |
| tem | 동안, 때 | 시간 명사 앞 | `tem hes`: 서리 동안 |

### 시제·양태·부정·의문

시제와 양태는 동사 앞에 둔다. 명령문과 법정문은 양태어를 선호하고, 일상 발화는 양태어를 자주 생략한다.

| 기능어 | 기능 | 기준 | 예시 |
|---|---|---|---|
| ed | 완료, 과거 | 이미 끝난 행위 | `ed reno`: 기록했다 |
| nu | 진행, 현재 처리 중 | 지금 진행 중인 행위 | `nu hedo`: 계량 중이다 |
| vi | 예정, 앞으로 할 일 | 계획·예정·예고 | `vi woko`: 갈 것이다 |
| var | 의무, 법적 요구 | 해야 함, 명령, 판결 | `var dato`: 넘겨야 한다 |
| ken | 허가, 가능 | 할 수 있음, 허락됨 | `ken kelo`: 지나갈 수 있다 |
| na | 문장 부정 | 동사 앞, 문장 전체 부정 | `na reno`: 기록하지 않는다 |
| na- | 단어 부정 | 단어 앞, 성질·명사 부정 | `nareni`: 기록되지 않은 |
| ha | 의문 | 문장 끝 | `tu reno ha`: 네가 기록하는가 |

### 문장 골격

| 문장형 | 구조 | 예시 | 뜻 |
|---|---|---|---|
| 평서 | 주어 + 동사 + 목적어 | `mi reno garhal` | 나는 곡식 회관을 기록한다. |
| 완료 기록 | 주어 + `ed` + 동사 + 목적어 | `renan ed hedo gar` | 서기가 곡식을 계량했다. |
| 의무문 | 주어 + `var` + 동사 + 목적어 | `tir var dato hedren` | 너희는 계량 장부를 넘겨야 한다. |
| 장소문 | 주어 + 동사 + 목적어 + `lo` + 장소 | `ser puko fer lo dorkar` | 그들은 돌 성채에 쇠를 보관한다. |
| 방향문 | 주어 + 동사 + `ke` + 대상 | `navan woko ke marmir` | 선원이 해상 교역소로 간다. |
| 부정문 | 주어 + `na` + 동사 + 목적어 | `se na varo lamvar` | 그는 결속 서약을 맹세하지 않는다. |
| 의문문 | 평서문 + `ha` | `tu ken kelo ha` | 너는 지나갈 수 있는가. |
| 소유명사구 | 소유자 + `-a` + 명사 | `Tiris-a garhal` | 티리스의 곡식 회관 |
| 병렬명사구 | 명사 + `li` + 명사 | `gar li fer` | 곡식과 쇠 |

공용서기어는 길고 복잡한 종속절을 선호하지 않는다. 법정·계약·신전 기록에서는 짧은 문장을 이어 쓰고, 필요하면 `renum`, `varum`, `hedren` 같은 기관·장부 명사를 반복해 모호성을 줄인다.

### 기록 서식 패턴

법정·관청·길드·신전 문서는 일상문보다 서식화된 표현을 쓴다. 이 서식은 별도 문법 어미가 아니라 기존 어근과 기능어를 고정 순서로 쓰는 관습이다.

| 서식 기능 | 구조 | 예시 | 뜻 |
|---|---|---|---|
| 기록됨 | `renum: 문장` | `renum: renan ed hedo gar` | 기록소: 서기가 곡식을 계량했다. |
| 증언함 | `yalren: 증인 + 문장` | `yalren: se ed yalo dat ke renan` | 증언 기록: 그는 서기에게 넘긴 것을 보았다. |
| 명령함 | `radren: 명령자 + var + 동사` | `radren: raden var dato hedren` | 명령 기록: 명령권자가 계량 장부 제출을 명했다. |
| 봉납·납부 | `datren: 납부자 + dato + 대상` | `datren: tu ed dato gar ke garhal` | 납부 기록: 네가 곡식을 곡식 회관에 넘겼다. |
| 금지 | `na-var: 대상 + na/var + 동사` | `na-var: tir na ken kelo` | 금지문: 너희는 지나갈 수 없다. |

### 기능어 금지선

| 금지선 | 기준 |
|---|---|
| 한국어의 `은/는`, `이/가`, `을/를`, `에`, `에서`, `으로`를 기능어로 1:1 번역하지 않는다. | 공용서기어는 SVO 어순과 독립 기능어로 관계를 표시한다. |
| 명사 뒤에 긴 조사열을 붙이지 않는다. | 방향, 출처, 장소, 동반, 목적은 명사구 앞 기능어로 둔다. |
| 화제 표지를 기본 문법 범주로 만들지 않는다. | 필요한 강조는 어순, 반복 명사, 서식 제목으로 처리한다. |
| 높임법을 동사 어미 체계로 만들지 않는다. | 직함, 호칭, 서명 위치, 문서 서식으로 권위를 표시한다. |
| 법정·신전 서식을 일상 공용어 전체에 강제하지 않는다. | 서식 패턴은 기록문에서만 쓰고, 도시 공용어는 더 짧게 말한다. |

## 표준 예문 코퍼스

표준 예문 코퍼스는 공용서기어가 실제 기록문과 짧은 대화에서 작동하는지 확인하기 위한 시험 문장 묶음이다. 이 예문들은 정본 명칭 확정이 아니라 문법 검산용이며, 이후 방언·종족어·문자표 회차에서 같은 의미를 다른 표면형으로 변환하는 기준문으로 사용한다.

### 행정·세금 기록

| 번호 | 공용서기어 | 한국어 뜻 | 검산 항목 |
|---|---|---|---|
| ADM-01 | `renum: renan ed hedo mor gar lo Garhal` | 기록소: 서기가 Garhal에서 모든 곡식을 계량했다. | 서식 제목, 완료, 전체 수량, 장소 |
| ADM-02 | `radren: raden var dato hedren ke Varenum` | 명령 기록: 명령권자는 계량 장부를 Varenum에 넘겨야 한다고 명했다. | 의무, 수신처, 기관명 |
| ADM-03 | `ek renan var reno pel gar ran tikren` | 각 서기는 절차 기록 전에 곡식 일부를 기록해야 한다. | 각자, 의무, 시간 전치 |
| ADM-04 | `renan na yalo ren lo Garhal lun hes` | 서기는 서리 뒤 Garhal에서 기록을 보지 못했다. | 부정, 장소, 시간 후행 |

### 시장·교역 문장

## 의미 ID와 생성 절차

공용어 생성은 의미 ID에서 시작한다. 의미 ID는 언어 내부 어근이 아니라 작가용 관리값이다.

| ID 계열 | 대상 | 예시 |
|---|---|---|
| SEM-NAT-* | 자연, 지형, 물질 | SEM-NAT-WATER, SEM-NAT-IRON |
| SEM-SOC-* | 사회, 법, 기록, 제도 | SEM-SOC-LAW, SEM-SOC-RECORD |
| SEM-ACT-* | 행위, 과정 | SEM-ACT-GUARD, SEM-ACT-TRADE |
| SEM-REL-* | 관계, 혈연, 소유 | SEM-REL-KIN, SEM-REL-OATH |
| SEM-SPEC-* | 종족 외명 생성용 의미 | SEM-SPEC-FOREST-RECORD |
| SEM-LOC-* | 장소, 시설, 권역 | SEM-LOC-FORT, SEM-LOC-MARKET |

| 단계 | 산출물 | 기준 |
|---|---|---|
| 1 | 의미 ID | 만들려는 이름이나 단어의 핵심 의미를 고른다. |
| 2 | 표준 어근 | 의미 ID에 대응하는 공용어 어근을 고른다. |
| 3 | 품사·명명 접사 | 일반 단어인지 고유명인지에 따라 접사를 고른다. |
| 4 | 표준 철자 | 공용서기어 철자를 확정한다. |
| 5 | 발음 | IPA-lite와 한국어 근사를 병기한다. |
| 6 | 방언 필터 | 필요할 때만 지역 방언형을 산출한다. |
| 7 | 충돌 검산 | 같은 철자, 과도한 유사음, 위험 명칭과의 충돌을 확인한다. |

## 한국어 글로스 기반 생성 규칙

한국어 단어는 제작자가 의미를 찾기 쉽게 쓰는 작가용 글로스다. 글로스는 데이터베이스의 입력 키이며, 인월드 언어의 어원으로 취급하지 않는다. 따라서 `가위`, `물`, `철`, `왕`, `달` 같은 한국어 표제어는 의미 ID와 의미 분해를 여는 열쇠로만 쓰고, 실제 공용어·종족어·이종어 철자는 각 언어의 어근, 접사, 음운 규칙으로 산출한다.

| 단계 | 입력·산출 | 기준 |
|---|---|---|
| 1 | 한국어 글로스 | 제작자가 찾기 쉬운 표제어를 둔다. 예: `가위` |
| 2 | 의미 ID | 언어권 공통 관리값으로 바꾼다. 예: `SEM-TOOL-CUT-PAIRED` |
| 3 | 의미 분해 | 기능, 재료, 형태, 사용 맥락을 나눈다. 예: 자르다 + 쌍날 + 손도구 |
| 4 | 언어별 어근 선택 | 공용어, 종족어, 난소통 이종어가 같은 의미를 각자의 어근망으로 받는다. |
| 5 | 표면형 생성 | 각 언어의 음절 구조, 접사, 발음 금지선, 문자 체계에 맞춰 철자를 만든다. |
| 6 | 방언·문자 필터 | 지역 방언, 의례형, 목각형, 금속 각인형 등으로 다시 조정한다. |

### 직접 음운 치환 금지선

| 금지 방식 | 이유 | 허용 대안 |
|---|---|---|
| `가위`를 `gawi`, `kawi`, `ka-ui`처럼 옮김 | 한국어 음운이 그대로 남아 변환 암호처럼 보인다. | `자르다 + 쌍날 + 도구`의 의미 분해로 새 철자를 만든다. |
| 한글 자모를 1:1로 로마자나 룬 문자에 대응 | 언어가 아니라 문자 치환표가 된다. | 의미 ID를 먼저 만들고 언어별 음운 필터를 통과시킨다. |
| 모든 언어가 같은 글로스에서 같은 음절감을 공유 | 대륙권·종족권 언어 차이가 약해진다. | 공통 의미 ID만 공유하고 표면형은 언어별로 다르게 만든다. |
| 실제 고대어 단어를 대량 차용 | 특정 현실 문화권의 이름이 노골적으로 보일 수 있다. | 문자 모양, 음운 밀도, 접사 감각만 참고한다. |

### 단어 생성 등급

| 등급 | 대상 | 제작 방식 |
|---|---|---|
| A 핵심 어근 | 물, 불, 돌, 피, 법, 이름, 왕, 길처럼 반복 사용되는 의미 | 수동으로 어근을 확정하고 모든 언어권에 대응 어근을 둔다. |

| 공용서기어 | 자르다 계열 어근 + 도구 접사 | `Sekir` | `sek` + `-ir` 구조다. |
| 드워프계 내부어 | 금속·절단·장인 도구 계열 | `Ferkir` | 금속성과 제작자를 더 강하게 드러낸다. |
| 엘프계 내부어 | 섬유·가지치기·의례 도구 계열 | `Silkor` | 숲과 의례 용례가 강하면 다른 어근을 쓴다. |
| 난소통 이종어 전사 | 인간이 들은 소리를 공용어 문자로 근사 | `Kskir`, `Tsek` | 원음이 아니라 외부 전사다. |

## 지명 1차 생성장

지명 1차 생성장은 현재 정본 지명을 즉시 교체하기 위한 표가 아니다. 기존 지명을 보존한 상태에서 공용서기어 후보명, 지역 방언형, 문자 운용 포인터를 함께 관리하기 위한 후보장이다. 이 후보장 안의 1차 지명 후보 승격은 별도 명칭 회차에서 결정한다.

### 지명 생성 원칙

| 원칙 | 기준 |
|---|---|
| 기존명 보존 | 현재 문서에서 쓰이는 지명은 바로 교체하지 않고 후보명을 병기한다. |
| 의미 우선 | 영어식 표면 의미를 직접 번역하지 않고 장소의 현재 기능과 기억을 우선한다. |
| 국가명 보류 | 티리스, 레오니아, 노르가드, 엘리시움, 아르고스, 세레스는 국가명 회차에서 따로 다룬다. |
| 지역명·시설명 우선 | 영지, 폐허, 성채, 관측소, 학교, 창고처럼 기능이 분명한 장소를 먼저 만든다. |
| 다중 이름 허용 | 같은 장소가 행정명, 민간명, 의례명, 피난민명으로 다르게 불릴 수 있다. |
| 표준형 포인터 | 방언형·문자형에는 반드시 공용서기어 표준형 포인터를 둔다. |

### 국가명 1차 검토장

국가명은 지명보다 보수적으로 다룬다. 국가는 단순 장소가 아니라 자칭, 타칭, 외교 문서명, 왕조명, 고문서명, 민간 축약명이 함께 붙는 대상이기 때문이다. 따라서 현재 정본명은 바로 폐기하지 않고, 5083년 공용서기어에서 사용할 행정 병기명과 외부 호칭 후보를 따로 관리한다.

## 방언 변형

방언은 뜻을 바꾸지 않고 소리, 축약, 선호 접사, 기록 관습을 바꾼다. 표준 공용서기어는 외교·법정·상급 관청의 기준형이고, 방언형은 지역 장부, 민간 발화, 직업 집단의 약식 표기로 붙는다.

| 표준형 우선 | 조약, 상급 법정, 대륙 간 문서에는 표준형을 먼저 쓴다. |
| 의미 보존 | 방언형은 의미 ID와 문장 번호를 바꾸지 않는다. |
| 기능어 보존 | `ke`, `dal`, `lo`, `min`, `sha`, `li`, `va`는 되도록 유지한다. |
| 축약 제한 | 축약은 발화형과 지역 장부형에만 허용한다. |
| 표준형 포인터 | 지역 장부에는 방언형 옆에 표준형 포인터를 둘 수 있다. |
| 중요 정보 비축약 | 숫자, 인명, 지명, 물품명, 권한 표지는 행정·법정·항만 장부에서 축약하지 않는다. |
| 현실 방언 직접 차용 금지 | 실제 한국어 방언이나 현실 고대언어 억양을 권역 방언의 직접 모델로 삼지 않는다. |

### 방언 검산 기준

| 기준 | 적용 |
|---|---|
| 표준형 복원 가능 | 방언형만 보고도 표준형을 추적할 수 있어야 한다. |
| 기능어 과변형 금지 | 관계 기능어를 지역마다 새로 만들지 않는다. |
| 새 문법 금지 | 방언 변형은 새 어근·새 기능어·새 문장 구조를 만들지 않는다. |
| 지역성 과장 금지 | 한 권역의 모든 말이 같은 음운 장난처럼 보이면 조정한다. |
| 문화권 고정 금지 | 방언은 계층, 직업, 기록 매체에 따라 갈라질 수 있다. |
| 종족어와 혼동 금지 | 방언형은 인간 공용어 변형이며, 종족 내부어가 아니다. |
| 정보 위계 보존 | 상급 문서일수록 축약을 줄이고 표준형·직함·서명 위치를 보존한다. |

방언형은 표준형을 대체하지 않는다. 문서 기록에는 표준형을 두고, 민간 발화와 지역 장부에는 방언형을 붙인다.

## 언어군 확장 기준

공용어, 종족어, 난소통 이종어는 서로 다른 단어장을 무작정 늘리는 방식으로 만들지 않는다. 같은 의미 ID를 공유하되 언어군별 어근망, 음운 규칙, 문자 운용, 사회적 사용 범위를 분리해 관리한다.

| 언어군 | 생성 기준 | 실제 언어·고대 문자 참고 방향 | 산출물 |
|---|---|---|---|
| 인간 공용서기어 | 행정, 교역, 법, 학술에 맞는 안정적인 어근과 규칙적 접사 | 라틴계, 고대 이탈리아계, 그리스계의 문자 질서와 공문서 감각 | 표준 철자, 발음, 방언형 |
| 인간 지역 방언 | 공용어를 지역 음운과 직업어로 줄이거나 바꾼다. | 항만 피진, 상인 부호, 농촌 표식의 구조 | 방언형, 속칭, 약칭 |
| 인간과 공존하는 종족어 | 공용 의미 ID를 공유하되 내부 의례·기술·혈통 명칭에서 별도 어근을 쓴다. | 룬계, 고대 게르만 문자, 켈트·북방 각문, 숲·계보 문서 관습 | 자명, 의례명, 기술명, 공용어 외명 |
| 인간과 부분 교류하는 종족어 | 교역어와 외명은 공용어로 만들고 내부어는 제한적으로 설계한다. | 소그드계, 브라흐미계, 티베트계, 상형·음절 문자 관습 | 교역명, 경계명, 사절 번역명 |
| 소통이 어려운 이종어 | 의미 대응은 가능하지만 원음은 인간 음성으로 완전 재현하지 않는다. | 설형문자식 기록 습관, 기호문자, 비알파벳 문자 운용 | 공용어 번역명, 관찰 전사, 금기 표기 |

실제 문자와 언어는 분위기와 구조를 얻기 위한 참고 자료다. Arcadia의 인월드 언어는 현실 언어의 직계 후손이나 복제본으로 설정하지 않는다. 후속 문자 회차에서는 각 문자권에 대해 `사용 매체`, `획의 방향`, `기록 도구`, `공식 문서 적합성`, `뷰어 표시 가능성`을 따로 검토한다.

### 언어군 운용 금지선

| 금지선 | 이유 |
|---|---|
| 한 현실 언어를 특정 종족어의 직접 모델로 고정하지 않는다. | 현실 문화와 Arcadia 종족이 1:1로 대응되는 인상을 줄 수 있다. |
| 종족어를 종족 전체가 본능적으로 공유하는 단일 언어로 처리하지 않는다. | 지역, 계층, 교육, 혼혈, 이주에 따른 변이가 사라진다. |
| 공용어를 모든 인물이 완벽히 쓰는 언어로 만들지 않는다. | 행정체, 시장체, 군대체, 신전 문어, 외국인 억양이 필요하다. |
| 난소통 이종어를 처음부터 완전 문법으로 확장하지 않는다. | 공용어와 인간계 언어 체계가 잡히기 전에 복잡도가 폭증한다. |
| 생성된 단어를 설명 불가능한 소리 조합으로 남기지 않는다. | 어근 등급, 접사, 음운표, 문자 차용 규칙 중 하나로 추적 가능해야 한다. |

## 이종의 공용어 사용 기준

| 집단 | 공용어 사용 | 내부어 사용 | 공용어 외명 생성 |
|---|---|---|---|
| 드워프계 | 계약, 광물 거래, 병기 납품, 도시 거주에서 사용 | 광맥, 가문, 제련법, 장례, 장인 서약 | `fer`, `dor`, `brun`, `kin` 계열 |
| 엘프계 | 관청, 외교, 학술 교류, 도시 거주에서 사용 | 긴 기록, 숲 의례, 장수 계보, 금기 장소 | `sil`, `ren`, `sen`, `sor` 계열 |
| 하플링계 | 시장, 농촌 계약, 장인 조합, 세금 기록에서 사용 | 가문 잔치, 씨앗 보관, 민간 약속, 이동 상단 | `gar`, `mer`, `sen`, `hal` 계열 |
| 혼합 혈통 집단 | 공용어를 기본 생활어로 쓰는 경우가 많다. | 혈통·의례 정체성을 표시할 때 내부어를 쓴다. | 거주 권역의 인간 방언을 우선한다. |

완전히 다른 신체 구조나 소리 체계를 가진 집단의 언어는 이번 단계에서 다루지 않는다. 다만 공용어는 그들을 부를 외명과 교역 용어를 만들 수 있어야 한다.

| 명사구 | 수식어 + 핵심어 | `gar hal`: 곡식의 회관 |
| 소유 | 소유자 + `-a` | `Tiris-a garhal`: 티리스의 곡식 영지 |
| 동사 기본형 | 어근 뒤에 `-o`를 붙인다. | `reno`: 기록하다 |
| 부정 | 단어 앞에 `na-`를 붙인다. | `nareni`: 기록되지 않은 |
| 과거 | 동사 앞에 `ed`를 둔다. | `ed reno`: 기록했다 |
| 의무 | 동사 앞에 `var`를 둔다. | `var reno`: 기록해야 한다 |

## 문자 운용 후보

문자는 언어와 분리해 운용한다. 로마자 표준형은 작가용 전사와 내부 관리용이며, 인월드의 실제 문자는 문화권, 기록 매체, 문서 권위에 따라 달라진다. 이번 단계에서는 실제 문자표를 완전히 확정하지 않고, 표시 가능한 문자 계열과 운용 원칙을 정한다.

### 문자 운용 층위

| 층위 | 기능 | 노출 기준 |
|---|---|---|
| 작가용 로마자 전사 | 어근, 발음, 문법, 검색 키 관리 | 모든 생성 규칙의 기준 표기 |
| 표준 서기문자 | 에덴포르트 행정·외교·상급 법정 문서 | 위키 표와 정본 예시의 기본 인월드 문자 후보 |
| 지역 장부문자 | 목패, 항만 장부, 무기 각인, 공동 창고 표식 | 지역색을 보여줄 때 제한적으로 병기 |
| 의례·학술문자 | 왕실 의례, 신전 문서, 수도원 주석 | 권위·고어성·학술성을 보여줄 때 병기 |
| 관찰 전사 | 난소통 이종어를 인간 공용어로 옮긴 근사 표기 | 원음이 아니라 외부 관찰 기록으로만 사용 |

### 문자 계열 후보

| 사용층 | 후보 참고 문자 | Unicode 표시성 | 적용 방향 | 금지선 |
|---|---|---|---|---|
| 에덴포르트 공문서 | 라틴계, 고대 이탈리아계 | 높음 | 법정·서기 문서에 맞는 직선적 획, 단어 간격, 행 정렬 | 라틴어 단어를 그대로 차용하지 않는다. |
| 티리스 목패와 농경 표식 | 룬계, 목각 부호 | 중간 | 나무패, 창고 표식, 씨앗 장부의 짧은 각문 | 농촌 방언을 낮은 문자체로 취급하지 않는다. |
| 노르가드 항만·철강 기록 | 룬계, 상인 부호 | 중간 | 금속 각인, 선박 표식, 항로 장부, 물품 표식 | 모든 말을 거친 축약체로 만들지 않는다. |

| 발드라크 북방 각문 | 룬계, 돌·뼈 각문 | 중간 | 맹세, 무기, 장례 표식, 산악 부족 기록 | 북방 전사문화를 단일 룬 문자로 고정하지 않는다. |

| 난소통 이종어 관찰전사 | 설형문자계, 기호문자형 | 낮음~중간 | 인간 기록자가 들은 소리와 표식을 근사 기록 | 원문 재현처럼 말하지 않는다. |

| 규칙 | 기준 |
|---|---|
| 표준 전사 보존 | 모든 인월드 문자 표기에는 로마자 표준형을 내부 포인터로 둔다. |
| 문자와 음운 분리 | 같은 공용어 단어가 지역에 따라 다른 문자로 적힐 수 있다. |
| 로마자 정본 데이터 | 한국어 글로스 다음의 기준 데이터는 공용어 로마자 표준형과 발음값이다. 인월드 문자는 렌더링 층이다. |
| 문자표 확정 보류 | 실제 글자 대응표는 문자 회차에서 확정한다. 이번 문서는 후보와 운용층만 둔다. |

### 렌더링 데이터 필드

인월드 문자형은 정본 단어를 대체하지 않고 렌더링 레이어로만 붙인다. 이후 뷰어와 후속 반영본에서 문자 예시를 표시할 때는 아래 필드를 사용한다.

| 필드 | 내용 |
|---|---|
| meaning_key | 한국어 글로스 또는 의미 ID |
| standard_roman | 공용어 로마자 표준형 |
| pronunciation | 발음 근사 |
| script_family | 서기문자, 각문, 궁정문자, 수도원문자, 관찰전사 등 |
| region | 에덴포르트, 티리스, 노르가드, 레오니아, 발드라크, 미스테리아 등 |
| rendering_mode | roman_only, unicode_sample, image_glyph, mixed |
| inworld_sample | 실제 표시 예시. 확정 전에는 비워둘 수 있다. |
| fallback_roman | 표시 실패 시 반드시 보여줄 로마자 표준형 |

### 문자 운용 금지선

| 금지선 | 기준 |
|---|---|
| 실제 고대문자 글자를 단어 단위로 읽어 차용하지 않는다. | 문자 모양과 기록 습관만 참고한다. |
| 실제 고대어 낱말을 원형으로 끌어오지 않는다. | 라틴어, 그리스어, 산스크리트어, 소그드어, 티베트어, 수메르어 직접 차용을 피한다. |
| 특정 현실 문자권 하나를 특정 국가·종족의 직접 원본으로 고정하지 않는다. | 현실 문화와 Arcadia 문화권의 1:1 대응을 막는다. |

| 뷰어에서 깨지는 결합문자·방향 혼합 문자를 본문 핵심 표기로 쓰지 않는다. | 필요하면 이미지 글리프 또는 로마자 fallback을 둔다. |

## 현재 회차 결론

5083 기준 공용어 제작은 인간 문화권의 서기·관청·교역 공용어에서 시작한다. 이 언어는 모든 종족의 내부어를 대체하지 않으며, 서로 다른 집단을 행정과 교역에서 번역 가능하게 만드는 공통 의미망으로 작동한다. 새 명칭은 의미를 먼저 분해하고, 공용어 어근과 접사를 통해 철자와 발음을 만든 뒤, 지역 방언 규칙으로 변형한다. 첫 지명장은 기존 정본 지명을 즉시 교체하지 않고, `Gardel`, `Kordor`, `Zelvar`, `Yentor`, `Artor` 같은 병기 후보를 관리하는 방식으로 둔다. `Rendel`은 단순 병기 후보가 아니라 Newhollow 생존자 내부 자칭으로 별도 관리하고, `Rendel Pukum`은 공동 창고와 이름패 보관소 시설명으로 제한한다. 국가명은 더 보수적으로 다루며, `Tiris`, `Leonia`, `Norgard`는 정본명을 유지한 채 `Garvaret`, `Draradet`, `Mernavet` 같은 공용서기어 행정 병기명을 문서층별로 병기한다. `Elysium`, `Argos`, `Ceres`는 현실 고전명 연상이 강하므로 5083 기준시대 객관정보에서는 `Linrenet`, `Vekdoret`, `Senhalet`을 정본 표면명으로 전환하고, 이전 명칭은 브리지 라벨로 보존한다. `Valdrak`, `Mysteria`는 단일 국가명이 아니라 `Hesferet`, `Silnimet` 외부 분류 정본으로 전환하며, 세부 국가와 문화권 언어를 나눌 때 다시 검산한다.

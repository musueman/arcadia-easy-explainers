# Arcadia 마스터본 단락별 확장 소플랜

## 목적

마스터 세계관을 한 번에 크게 고치지 않고, 단락별로 함께 검토하며 정본 문체로 확장한다. 마스터본에는 결론만 남기고, 수정 이력, 비교 기록, 작업 메모, 보류 질문은 별도 문서에서 관리한다.

## 작업 단위 규칙

| H3가 없는 경우 | H2 단락 1개 |

| 마스터 제외 기준 | 역사 장면화, 인물관계, 구버전 비교, 작업 과정 기록 |
| 확장 형식 | 표, 짧은 정본 설명, 필요한 경우 하위 표 |

## 회차 진행 방식

1. 해당 단락 원문을 읽고 핵심 질문 3~5개를 뽑는다.
2. 확정값과 보류값을 분리한다.
3. 확정값만 마스터본에 반영한다.
4. 반영 후 같은 단락 안에서 용어, 수치, 법, 신앙, 지리 충돌을 확인한다.
5. 다음 회차로 넘길 미확정 질문은 회차 노트에 기록한다.

# Arcadia 마스터본 단락별 확장 회차 노트

## 1회차: 기준 범위, 5083년 기준 세계 상태

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-06-24 |
| 대상 단락 | `기준 범위`, `5083년 기준 세계 상태` |
| 마스터 반영 | 기준 층위, 중심 무대, 현재 긴장 구조, 서부 접경 상태 |
| 마스터 제외 | 인물관계, 상세 사건 경과, 구버전 비교, 작업 과정 |

### 핵심 질문

1. 기준 범위의 중심 무대를 `에덴포르트 서부 접경`으로 계속 둘 것인가, 아니면 `에덴포르트 전체`를 같은 비중으로 둘 것인가.
2. 전승 항목은 세계 내부의 믿음과 정치 언어로만 둘 것인가, 일부를 실제 초자연 사실로 승격할 것인가.
3. 5083년 현재의 대국 압력은 레오니아와 노르가드를 같은 비중으로 둘 것인가, 노르가드를 서부 접경의 직접 압력으로 더 강하게 둘 것인가.
4. Newhollow의 지위를 피난민 공동체, 노동력, 기억 보관소 중 어떤 축으로 가장 강하게 둘 것인가.
5. LunaTalk용 응답 규칙은 마스터본 내부에 두지 않고 별도 추출본에서 관리할 것인가.

### 현재 적용 기본값

| 질문 | 적용 기본값 |
|---|---|
| 중심 무대 | 에덴포르트 서부 접경을 중심으로 둔다. |
| 전승 지위 | 세계 내부의 믿음과 정치적 언어로 둔다. |
| 대국 압력 | 노르가드는 서부 접경의 직접 압력, 레오니아는 대륙 질서의 배경 압력으로 둔다. |
| Newhollow 지위 | 피난민 공동체, 노동력, 기억 보관소를 함께 둔다. |
| LunaTalk 규칙 | 마스터본이 아니라 파생 추출본에서 관리한다. |

## 2회차: Vireth, Arcadia, Arcadian Sphere

| 항목 | 내용 |
|---|---|
| 날짜 | 2026-06-25 |
| 대상 단락 | `Vireth`, `Arcadia`, `Arcadian Sphere` |
| 마스터 반영 | 물리 행성명, 문화적 세계명, 북반구 문명권명의 삼분법 |
| 마스터 제외 | 구버전 명칭 비교, 인물 중심 용례, 상세 역사 장면 |

### 핵심 질문

1. Vireth를 학술·천문 용어로 고정하고, 일상어에서는 대륙명·국가명·영지명을 우선하게 둘 것인가.
2. Arcadia를 행성명이 아니라 문화적 세계명으로 고정하되, 세계 내부 인물이 세계 전체처럼 부르는 용례를 허용할 것인가.
3. Arcadian Sphere를 단일 제국이 아니라 문화권으로 두고, 정치 결속보다 교역·혼인·용병·절기·신앙 결속을 강조할 것인가.
4. Sylvania, Dragonspire, Fenrir's Eye를 중심 대륙이 아니라 주변 권역으로 계속 둘 것인가.
5. Greenhollow 사건을 티리스 지방 사건이면서 Arcadian Sphere 전체의 해석 대상이 되는 사건으로 둘 것인가.

### 현재 적용 기본값

| 질문 | 적용 기본값 |
|---|---|
| Vireth 용례 | 물리 행성명과 학술·천문 용어로 둔다. |
| Arcadia 용례 | 문화적 세계명으로 두며, 행성명으로 쓰지 않는다. |
| Arcadian Sphere 성격 | 단일 국가가 아닌 북반구 문화권으로 둔다. |
| 주변 권역 | Sylvania, Dragonspire, Fenrir's Eye는 주변 권역으로 둔다. |
| Greenhollow 사건 범위 | 티리스 사건이자 대륙권 해석 대상인 사건으로 둔다. |

### 조사 결론

Arion 인식은 하나의 믿음 체계로 쓰지 않는다. 기준시대의 민간인은 색, 밝기, 안개, 꿈, 병, 수확, 출산, 전쟁 소문을 통해 Arion을 읽고, 직업군은 자기 생업의 위험을 중심으로 별도 징조 목록을 만든다. 학술기관은 같은 현상을 관측표, 절기표, 질병 장부, 가격 장부, 왕실 보고서로 정리하지만 현대 과학에 도달하지 못한다. 따라서 학술 인식은 민간 인식과 단절된 과학이 아니라 더 문서화되고 권위화된 전근대적 오해 체계다.

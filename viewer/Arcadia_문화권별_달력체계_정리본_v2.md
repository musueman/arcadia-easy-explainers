# Arcadia 문화권별 달력체계 정리본 v2

## 1. 공통 기준

이 문서는 에덴포르트 서력 5083년 기준 Arcadian Sphere 안에서 실제로 쓰이는 문화권별 달력 체계를 정리한다. 달력은 하나의 세계 표준으로 통일되어 있지 않으며, 관청·신전·길드·가문·직업군이 서로 다른 달력판과 주석을 병용한다.

| 항목 | 기준 |
|---|---|
| 물리 기준 | Vireth의 1년은 660일, 1일은 26시간이다. |
| 기본 생활 단위 | 10일을 한 주기로 삼으며, 1년은 66주기다. |
| 날짜 표기 | 이 문서에서는 `주기-일` 형식을 쓴다. 예: `01-01`, `66-10`. |
| 공용 환산 | 대륙 간 외교·무역·군사 문서는 에덴포르트 서력을 병기한다. |
| 휴일 원칙 | 공휴일은 지정하지 않는다. 각 날짜는 명절, 의례일, 기억일, 금기일, 장터 기준일로만 둔다. |
| 지역 차이 | 실제 휴무와 의례 강도는 국가, 영지, 길드, 신전, 가문 관습에 따라 달라진다. |

일반 가정은 간단한 생활 달력을 쓰고, 정확한 해석은 신전·관청·길드·서기관에게 확인한다. 같은 날짜와 천문 현상도 티리스 농민, 노르가드 선장, 레오니아 기사, 미스테리아 수도사가 서로 다르게 말한다.

### 10일 주기

Arcadian Sphere의 기본 생활 주기는 10일이다. 이 주기는 근현대적 주말 제도와 다르다. 모든 문화권이 같은 날에 쉬지 않으며, 휴식·장터·재판·의례·훈련은 국가와 직업군에 따라 다르게 배치된다. 다만 관청과 장거리 교역에서는 10일 안의 위치를 맞추기 위해 공통 행정명을 사용한다.

| 일차 | 공통 행정명 | 기본 기능 | 민간 체감 |
|---:|---|---|---|
| 1일 | 첫날 | 주기 개시, 장부 기입, 새 지시 전달 | 새 일을 시작하는 날로 여긴다. |
| 2일 | 둘날 | 준비, 도구 점검, 길드 소집 | 전날 받은 지시를 실제 일로 옮긴다. |
| 3일 | 셋날 | 작은 장터, 마을 회의, 단거리 거래 | 티리스 일부 지역에서는 장터가 선다. |
| 4일 | 넷날 | 공방, 수리, 관개, 선박 손질 | 장인과 농민의 실무일 성격이 강하다. |
| 5일 | 가운데날 | 검열, 중간 보고, 성벽·창고 점검 | 군사 영지와 관청이 중시한다. |
| 6일 | 여섯날 | 이동, 운송, 전갈 발송 | 상인과 사절이 길을 잡기 좋은 날로 본다. |
| 7일 | 일곱날 | 재판 예비, 신전 상담, 길흉 확인 | 신관과 서기관에게 묻는 날이 되기 쉽다. |
| 8일 | 여덟날 | 큰 장터, 세금·계약, 공개 의례 | 티리스 장터와 길드 거래가 자주 붙는다. |
| 9일 | 아홉날 | 정리, 귀환, 채무 확인, 장례 준비 | 묵은 일을 닫기 시작하는 날이다. |
| 10일 | 끝날 | 봉인, 보고 마감, 의례 마감 | 한 주기의 결산일이며 금기와 기억일이 자주 붙는다. |

티리스 생활권에서는 셋날과 여덟날의 장터 관습이 널리 알려져 있고, Ravenstone 같은 군사 영지는 가운데날마다 성벽 점검과 훈련 검열을 붙인다. 노르가드 항구는 여섯날과 여덟날을 출항·계약에 자주 쓰고, 레오니아 왕실은 일곱날과 끝날을 법정·의례 주석에 자주 묶는다.

## 3. 에덴포르트권 달력

### 에덴포르트 공용 서력

#### 개요

에덴포르트 공용 서력은 Arcadian Sphere 안에서 외교와 장거리 교역을 위해 가장 널리 병기되는 환산 달력이다. 민간 명절을 규정하기보다 관청 날짜, 조약, 군사 기록, 세금 문서의 기준을 제공한다.

| 항목 | 내용 |
|---|---|
| 유형 | 태양 행정력 |
| 사용 주체 | 왕실, 관청, 외교문서관, 군사 기록관, 대륙 상인 |
| 실제 판형 | 장식이 적은 관청판, 장부 삽입용 얇은 표 |
| 기능 | 날짜 환산, 세금·군역·조약·공문서 기준 |

### 티리스 녹지절력

#### 개요

티리스 녹지절력은 농경과 목축, 녹색 여신 신앙, 공동 창고 운영을 묶는 생활 달력이다. Greenhollow와 Newhollow는 공식 절기 외에 상실과 피난의 기억일을 덧붙인다.

| 항목 | 내용 |
|---|---|
| 유형 | 농경 절기력, 10일 생활력, 3대 농경 계절력 |
| 사용 주체 | 농민, 목동, 영지 관청, 녹색 여신 신전, 곡물 장부관 |
| 실제 판형 | 나무판, 천 달력, 공동 창고 벽걸이 |
| 기능 | 파종, 수확, 물대기, 양모 깎기, 곡물세, 공동 창고 개방 |

| 흙깨어남 | 첫싹절, 물오름절 | 밭갈이, 씨앗 선별, 물길 정비, 공동 노동 배치 |

## 7. 달력 충돌과 병기 방식

| 사건 | 티리스 | 노르가드 | 레오니아 | 엘리시움 | 미스테리아 |
|---|---|---|---|---|---|
| Arion의 붉은 하늘 | 녹색 여신의 침묵, 병충해 경고 | 바다가 길을 바꾸는 출항 경고 | 왕권 결단을 요구하는 용의 눈 | 비극 상연과 기록의 날 | 숲과 산의 기운 불균형 |
| Greenhollow 함락일 | 불탄 고향의 기억일 | 서부 국경 안정 작전일 | 대륙 균형을 흔든 흉일 | 비극 제작의 기념일 | 외부 전쟁이 자연 질서를 찢은 날 |
| 쌍위성 식 | 여신의 등불과 씨앗 그림자 | 흰 등대와 검은 종의 교차 | 용의 양안이 겹친 날 | 특별 공연과 논쟁의 날 | 하늘·숲·강의 징조가 겹친 날 |
| 흉작 | 공동 창고 개방과 감세 청원 | 가격 상승과 수송 계약 | 관료 책임 조사 | 구호 공연과 후원 경쟁 | 땅·물·정령의 불균형 |

외교문서에는 `에덴포르트 서력 날짜 / 지역력 날짜 / 의례 주석`을 병기한다. 예를 들어 티리스 영지문서는 `에덴포르트 서력 5068년 48-10, 티리스 녹지절력 곡식문 열림 뒤 셋째 주기`처럼 적을 수 있다. LunaTalk 반영본에서는 캐릭터가 자기 문화권의 달력을 자연스럽게 우선하고, 필요한 경우에만 에덴포르트 서력으로 환산한다.

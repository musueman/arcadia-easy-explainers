# Arcadia 문화권별 달력체계 정리본 v3

## 1. 기준 원칙

Vireth의 물리적 1년은 660일이다. 그러나 5083년의 Arcadian Sphere 사람들이 이 660일을 모두 같은 방식으로 나누는 것은 아니다. 에덴포르트 서력은 외교와 행정의 환산 기준이지만, 각 문화권의 실제 달력판은 대륙, 신앙, 생업, 종족 감각, 관청 체계에 따라 서로 다른 주기를 쓴다.

| 항목 | 기준 |
|---|---|
| 물리년 | Vireth 1년 660일 |
| 물리일 | 26시간 |
| 공통 환산 | 에덴포르트 서력 날짜와 연중일을 병기한다. |
| 지역 표기 | 각 문화권은 자기 주기명과 날짜명을 쓴다. |
| 휴일 원칙 | 공휴일은 지정하지 않는다. 명절, 의례일, 기억일, 금기일, 장터 기준일만 둔다. |
| 판형 원칙 | 달력판에는 `지역 주기-지역 일명`이 먼저 보이고, 관청 문서에는 에덴포르트 서력 환산일이 덧붙는다. |

### 환산 방식

| 표기 | 의미 |
|---|---|
| 연중일 | 1년 660일 중 몇 번째 날인지 표시하는 설정집 기준값 |
| 지역 주기 | 해당 문화권이 실제 생활에서 쓰는 반복 단위 |
| 지역 일명 | 그 주기 안의 특정 날짜명 |
| 에덴포르트 병기 | 장거리 문서에서 쓰는 `서력 주기-일` 환산 |

예를 들어 연중일 480일은 에덴포르트 10일력으로는 `48-10`이다. 그러나 발키리아 12일 명예력으로는 `40주기 12일, 칼집날`이 되고, 센린국 20일 숲숨력으로는 `24주기 20일, 마지막숨`이 된다. 따라서 같은 날이라도 문화권별 달력판에서는 서로 다른 위치와 이름을 가진다.

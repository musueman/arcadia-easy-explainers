# 비레스 공개 안내 UX 정제 실행 계획

1. 공개 사이트 검증 스크립트에 첫 진입, 짧은 권역 카드, 고유명사 검색, 금칙 문장을 추가한다.
2. 검증 실패를 확인한다.
3. 구형 `#regions` 진입을 첫 화면으로 복구한다.
4. 권역 카드를 수도와 핵심어 중심으로 축약한다.
5. 정적 문구와 권역·세계 읽기 본문을 서술형 다체로 고친다.
6. 중요한 명칭과 수치를 굵게 표시한다.
7. 고유명사 검색 페이지와 공개 내비게이션을 추가한다.
8. PowerShell 검증, 브라우저 기능 검사, 모바일·데스크톱 스크린샷 검사를 실행한다.
9. 변경 파일만 커밋하고 GitHub Pages에 배포한다.

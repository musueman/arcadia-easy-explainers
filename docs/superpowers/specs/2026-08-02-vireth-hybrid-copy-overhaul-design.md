# 비레스 공개 안내 혼합형 문체 개편 설계

## 목표

비레스 공개 홈페이지를 내부 설정을 풀어놓은 자료실이 아니라, 처음 온 사용자가 세계의 분위기를 느끼면서도 필요한 사실을 빠르게 찾을 수 있는 여행 안내서로 다듬는다.

문체는 혼합형으로 고정한다.

- 제목과 단락 도입은 판타지 여행기의 분위기를 가진다.
- 사실 설명은 현대 생활어와 짧은 서술형 다체로 쓴다.
- 버튼과 조작 문구는 짧은 행동형으로 쓴다.
- 설정의 고유명사, 수치, 환산값, 도시와 시설명은 축약하지 않는다.

## 조사 근거

- W3C는 쉬운 단어, 짧은 문장, 단순한 시제, 짧은 글 덩어리와 명확한 이미지가 이해를 돕는다고 설명한다.
- Nielsen Norman Group은 사용자가 웹 문서를 처음부터 끝까지 읽기보다 제목과 강조어를 훑는 경향이 강하므로, 의미가 분명한 제목과 앞부분에 놓인 결론이 필요하다고 설명한다.
- Microsoft Writing Style Guide는 자연스럽고 따뜻하되 핵심을 먼저 제시하는 문체를 권한다.
- Apple 온보딩 지침은 필요한 정보를 실제 행동과 가까운 지점에서 보여주고, 처음부터 모든 설명을 늘어놓지 않는 방식을 권한다.

참고:

- https://www.w3.org/WAI/WCAG2/supplemental/objectives/o3-clear-content/
- https://www.w3.org/WAI/tips/writing/
- https://www.nngroup.com/articles/be-succinct-writing-for-the-web/
- https://learn.microsoft.com/en-us/style-guide/top-10-tips-style-voice
- https://developer.apple.com/design/human-interface-guidelines/onboarding

## 현재 문제

### 문체

- 공개 페이지는 이미 대부분 서술형 다체다. 문제는 종결형이 아니라 추상어와 동일 문형의 반복이다.
- `중요하다`, `힘을 가진다`, `길을 연다`, `사람을 가른다`가 실제 제도와 결과를 대신한다.
- 도시 설명 100개 이상이 `수도 또는 중심 거점이다`, `주요 도시 또는 지역 거점이다`로 끝나 장소별 차이가 사라진다.
- 역사 설명이 `남았다`, `이어진다`로 끝나 사건의 시기, 결과, 현재 흔적을 전달하지 못한다.

### 정보 배치

- 권역 카드와 상세 패널에서 비슷한 문장이 반복된다.
- 세계 읽기 단락의 제목과 본문이 떨어져 있어 한 단락만 펼쳐서는 정보가 완결되지 않는 곳이 있다.
- 종족 설명 중 일부는 외형, 거주지, 생업보다 기록 출처가 먼저 나온다.
- 갤러리와 시작 장면에 제작 상태나 사용 방법을 설명하는 문장이 남아 있다.

### 고유명사 사전

- 최신 통합본에서 만든 상세 항목보다 HTML 내부의 짧은 수동 항목이 먼저 적용된다.
- 그 결과 여러 수도와 도시가 같은 일반 설명으로 표시된다.
- 사전은 이름을 찾는 기능은 갖췄지만, 처음 본 사용자가 장소의 성격을 구별하기 어려운 항목이 많다.

## 문체 체계

### 1. 제목

제목은 감각적인 장면이나 사용자의 선택을 드러낸다. 멋을 위한 은유만 남기지 않고, 제목만 읽어도 단락 주제를 짐작할 수 있어야 한다.

예시:

- `비레스에서 어디로 갈까요?` → `비레스의 어느 길로 들어설까`
- `스무 권역, 서로 다른 첫 장면` → `스무 권역이 스무 가지 삶을 품는다`
- `길 위에서 먼저 마주치는 것들` → `길을 나서기 전에 알아둘 것`

### 2. 도입

도입은 두세 문장으로 제한한다.

1. 첫 문장은 장소나 생활의 감각을 보여준다.
2. 둘째 문장은 사용자가 이 단락에서 무엇을 알게 되는지 말한다.
3. 필요한 경우에만 셋째 문장에서 다음 행동을 안내한다.

### 3. 사실 설명

- 한 문장에는 한 가지 사실만 둔다.
- 시설명이나 제도명을 나열한 뒤 추상어로 끝내지 않는다.
- `무엇이 존재하는가`, `누가 이용하는가`, `없으면 어떤 일이 생기는가` 중 최소 두 가지를 적는다.
- 수치와 환산 관계는 생활 예시와 함께 둔다.

예시:

기존:

> 추천장과 문장 반지가 힘을 가진다.

변경:

> 레오니아 궁정은 추천장에 적힌 보증인과 봉인을 대조한 뒤 출입을 허가한다. 문장 반지는 신분과 소속 가문을 확인하는 표식이다.

### 4. 역사 설명

역사 항목은 다음 네 요소 중 최소 두 가지를 포함한다.

- 시기
- 장소
- 사건의 결과
- 5083년에 남은 흔적

객관 사실과 지역에 유통되는 기억이 다른 경우 둘을 분리해 적는다.

예시:

> 그린할로우는 5068년에 상실되었다. 피난민 일부는 이듬해 레이븐스톤 외곽에 뉴할로우를 세웠다. 티리스 서부에서는 지금도 농지 소유권과 귀향 자격을 두고 분쟁이 이어진다.

### 5. 종족 설명

종족 항목은 다음 순서로 쓴다.

1. 식별 가능한 외형 또는 신체 특징
2. 주 거주권
3. 주요 생업과 사회적 역할
4. 다른 종족이나 국가와의 관계
5. 기록과 전승의 차이가 필요한 경우 마지막에 덧붙인다.

### 6. 조작 문구

- 버튼은 행동형으로 쓴다.
- `여행지 고르기`, `장면 읽기`, `지도 열기`, `이름 찾기`처럼 사용자가 누른 뒤 일어날 일을 직접 말한다.
- 사용자에게 필요한 오류나 상태 안내에만 존댓말을 허용한다.

## 섹션별 정보 구조

### 첫 화면

- 분위기를 전달하는 제목 한 줄
- 비레스의 생활 차이를 보여주는 두세 문장
- `여행지 고르기`, `세계 알아보기`, `시작 장면` 세 행동
- 렌과 듀란은 세계를 대신 설명하는 화자가 아니라 시각 안내자로만 둔다.

### 권역 카드

각 카드에는 다음 정보만 노출한다.

- 권역명과 문장
- 수도 또는 중심도시
- 보이는 풍경 한 문장
- 여행자가 바로 겪는 생활 조건 한 문장

`중요하다` 대신 통행, 거래, 숙박, 배급, 허가에 미치는 실제 결과를 적는다.

### 권역 상세

모든 권역은 같은 순서로 읽힌다.

1. 어떤 땅인가
2. 수도와 주요 도시
3. 사람과 종족
4. 돈과 장터
5. 달력과 계절
6. 역사와 현재 문제
7. 여행자가 시작하기 좋은 곳

20개 권역은 같은 정보 밀도를 유지한다.

### 세계 알아보기

여섯 장을 유지하되, 각 장은 그 자리에서 내용이 완결된다.

- 나라와 권역
- 종족과 문화
- 도시와 마을
- 돈과 물건
- 달력과 계절
- 역사와 소문

단락 도입에는 분위기를 허용하고, 표와 본문에는 고유명사와 수치를 우선한다.

### 시작 장면

- 현재형 장면 묘사
- 눈, 귀, 냄새, 온도 가운데 두 가지 이상의 감각 단서
- 즉시 가능한 선택 세 가지
- 이미지가 없는 항목에도 제작 상태 문구를 노출하지 않는다.

### 갤러리

- `자료`, `보여주기 위한`, `감을 잡게 한다` 같은 제작자 시점 문구를 제거한다.
- 이미지 속 장소와 사용자가 확인할 대상을 직접 적는다.
- 도시, 마을, 지도의 차이는 제목과 캡션만으로 알 수 있어야 한다.

### 고유명사 사전

각 항목은 다음 순서로 표시한다.

- 이름
- 분류
- 위치 또는 관련 권역
- 구체적인 기능이나 사건
- 식별 특징 또는 현재 영향

최신 통합본에서 생성한 설명을 우선하고, HTML 내부의 일반 설명은 상세 설명이 없을 때만 보조값으로 사용한다.

## 금칙 표현

다음 표현은 구체적인 사실로 대체한다.

- 중요하다
- 힘을 가진다
- 길을 연다
- 사람을 가른다
- 주요 도시 또는 지역 거점이다
- 수도 또는 중심 거점이다
- 삶과 가까운 장면이 열린다
- 웹툰이 더해지기 전까지
- 자료를 모았다
- 감을 잡게 한다

단, 문맥상 실제 의미가 분명하고 다른 표현보다 정확한 경우에는 검토 후 사용할 수 있다.

## 정보 손실 방지

- 20개 국가·권역을 모두 유지한다.
- 각 권역의 수도, 대표도시, 종족, 화폐, 달력, 역사 기억을 삭제하지 않는다.
- 화폐 환산, 거리·무게·부피 단위, 품삯과 대표 물가는 수치를 보존한다.
- 객관정보와 공개 정보가 다른 경우 공개 정보에서 단정하지 않고, 지역 기록이나 구전의 범위를 함께 적는다.
- 티리스와 레오니아만 높은 밀도로 확장하지 않는다.

## 검증 기준

- 공개 페이지의 `거점이다` 일반 설명은 0개다.
- 금칙 추상 표현은 문맥 검토 없이 남아 있지 않는다.
- 20개 권역 모두 권역 카드와 상세 본문을 가진다.
- 여섯 개 세계 안내 장은 펼친 단락 안에서 내용이 완결된다.
- 고유명사 사전은 최신 통합본의 상세 설명을 우선한다.
- 공개 화면에 제작 상태와 내부 작업 용어가 노출되지 않는다.
- 모바일 390px, 태블릿 768px, 데스크톱 1280px에서 제목과 본문이 읽기 좋은 길이로 표시된다.

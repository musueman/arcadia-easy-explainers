# 비레스 공개 안내 UX 정제 설계

## 목표

공개 안내 페이지의 첫 진입, 문체, 정보 밀도, 검색성을 함께 개선한다. 첫 화면은 항상 비레스 소개에서 시작하고, 사용자는 권역을 짧게 훑은 뒤 상세 정보를 읽거나 고유명사를 직접 검색할 수 있다.

## 진입

- 루트 주소와 과거 공유 주소 `#regions`는 첫 화면으로 열린다.
- 현재 페이지에서 사용자가 누른 `여행지 고르기` 링크는 계속 권역 선택으로 이동한다.
- `#start-situations` 같은 의도적인 세부 링크는 유지한다.

## 문체

- 공개 설명은 해요체보다 서술형 다체를 사용한다.
- 명령형 버튼 문구는 짧게 유지한다.
- 제도와 사물에 사람처럼 행동을 부여하는 모호한 문장을 피한다.
- 한 문장에는 한 가지 사실만 둔다.

## 권역 선택

- 한 줄 가로 탐색 구조는 유지한다.
- 카드에는 문장, 권역명, 수도, 핵심어 세 개만 노출한다.
- 생활·역사·경제 설명은 선택 뒤 상세 화면에서 제공한다.
- 카드의 핵심어는 권역 간 차이를 비교할 수 있는 명사형 표현으로 통일한다.

## 세계 읽기

- 여섯 장의 접기·펼치기 구조는 유지한다.
- 닫힌 상태에는 제목과 한 줄 요약만 보인다.
- 열린 본문은 짧은 문단, 굵은 핵심어, 표와 목록을 함께 사용한다.
- 나라, 종족, 화폐, 달력, 역사 명칭은 본문에서 바로 확인할 수 있다.

## 고유명사

- `glossary.html`을 별도 페이지로 만든다.
- 검색과 범주 필터를 제공한다.
- 권역, 도시, 종족, 화폐·단위, 달력·시간, 역사, 기관·장소를 다룬다.
- 각 항목은 이름, 범주, 한 문장 정의, 관련 권역을 가진다.

## 접근성

- 검색 입력과 필터는 키보드로 조작할 수 있다.
- 결과 수를 실시간으로 알린다.
- 모바일 390px에서도 가로 스크롤이나 글자 단위 줄바꿈이 없어야 한다.

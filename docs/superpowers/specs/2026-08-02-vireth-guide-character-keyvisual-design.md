# 비레스 여행 안내 캐릭터 키 비주얼 디자인

- 작성일: 2026-08-02
- 대상: 비레스 공개 여행 안내 홈페이지
- 상태: 사용자 승인

## 목표

첫 화면의 렌과 듀란을 사각 이미지 두 장이 아니라 비레스 세계를 먼저 보여 주는 시각 안내자로 배치한다. 두 인물의 상반신, 양어깨, 허리와 손이 임의로 잘리지 않아야 하며, 이름과 한 줄 소개가 이미지와 한 덩어리로 읽혀야 한다.

## 선택한 접근

두 인물을 함께 보여 주는 비대칭 2인 키 비주얼을 사용한다.

- 렌은 청록색, 듀란은 적색을 인물별 식별색으로 사용한다.
- 인물 원본의 밝은 배경을 제거하고 투명 누끼만 사용한다.
- 데스크톱에서는 렌과 듀란의 몸통과 손이 모두 보이는 구도를 유지한다.
- 모바일에서는 같은 자산의 표시 크기만 줄이고 얼굴이나 몸을 임의로 자르지 않는다.
- 인물은 기록의 저자나 사건 당사자가 아니라 방문자의 시각적 안내자다.

## 첫 화면 구조

1. 왼쪽에는 `비레스에서 어디로 갈까요?`와 세계 소개, 주요 이동 버튼을 둔다.
2. 오른쪽에는 배경 프레임이 없는 렌과 듀란 누끼를 겹쳐 배치한다.
3. 각 인물 옆에는 영문 이름, 한글 이름, 한 줄 소개를 둔다.
4. 렌과 듀란의 색을 얇은 세로선과 이름 강조에만 사용하고 큰 색면 카드를 만들지 않는다.
5. 도시 배경과 인물 사이에는 얕은 광도 차와 그림자만 사용한다.

## 인물 소개

- 렌: `비레스를 먼저 걸으며 낯선 길과 사람의 기색을 읽어 온 여행자.`
- 듀란: `붉은 망토를 두르고, 무너진 길에서도 사람을 지키려는 기사.`

## 페이지 전반

- 권역 선택은 기존 수도 풍경 카드와 문장 체계를 유지하되 선택 상태에 청록·적색·금색을 분리한다.
- 세계 읽기의 여섯 묶음은 인물 키 비주얼과 같은 얇은 색선, 명확한 아이콘, 평평한 정보 구조를 사용한다.
- 시작상황은 인물 소개보다 강하게 보이지 않도록 배경 밝기와 제목 크기를 조정한다.
- 자료관의 도식은 서브컬처 키 비주얼 영역과 분리된 정보 자료로 유지한다.
- 사각형 안에 사각형을 중첩하거나, 모든 구역을 캐릭터 카드처럼 꾸미지 않는다.

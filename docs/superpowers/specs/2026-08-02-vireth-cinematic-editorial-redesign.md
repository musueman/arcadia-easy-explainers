# 비레스 공개 안내서 시네마틱 잡지형 개편 명세

## 목표

현재 공개 페이지의 반복 카드와 중첩 테두리를 줄이고, 비레스의 장소와 이야기가 먼저 기억되는 시네마틱 잡지형 화면으로 전환한다. 사용자는 20개 권역의 정보를 잃지 않으면서도 설정 관리 화면이 아니라 판타지 여행 잡지를 읽는 느낌을 받아야 한다.

## 확정 방향

- 비교 시안의 C안인 `시네마틱 잡지형`을 사용한다.
- 큰 이미지, 큰 제목, 짧은 도입, 이미지와 본문의 교차 배치를 기본 리듬으로 삼는다.
- 독립적으로 선택하거나 펼치는 요소에만 테두리와 배경을 사용한다.
- 카드 안에 카드가 들어가는 중첩 구조는 제거한다.
- 기존 데이터와 이미지 자산을 유지하며 콘텐츠를 삭제하지 않는다.

## 화면 구조

### 첫 화면

- 현재 렌·듀란 키 비주얼과 세 개의 주요 진입 버튼을 유지한다.
- 인물 소개는 별도 밝은 카드가 아니라 이미지 위의 짧은 캡션으로 남긴다.

### 권역 탐색

- 20개 권역 선택지는 작은 풍경 카드 격자 대신 `권역 색인`으로 바꾼다.
- 색인은 작은 문장, 권역명, 수도명으로 구성하며 선택된 항목은 색선과 굵은 글자로 표시한다.
- 선택된 권역은 색인 옆의 작은 상세 카드가 아니라 색인 아래의 전폭 기사로 연다.
- 기사의 첫 화면은 수도·중심도시 이미지를 전폭으로 사용하고 권역명, 한 문장 소개, 수도명을 이미지 위에 표시한다.
- 도시, 종족, 돈, 달력, 역사, 시작 장소는 이미지와 본문이 교차하는 전폭 단락으로 배치한다.
- 작은 정보는 박스 대신 구분선과 2열 또는 3열 정보 행으로 정리한다.

### 세계 읽기

- 여섯 주제는 한 줄짜리 장 제목 형태의 아코디언으로 유지한다.
- 닫힌 상태에는 아이콘, 제목, 한 문장 요약만 보인다.
- 열린 본문에서는 이미지와 설명을 테두리 없는 2열 구성으로 배치한다.
- 강조 문장은 배경 박스 대신 세로 색선 또는 넓은 인용문으로 표현한다.
- 표처럼 비교가 필요한 정보만 실제 표를 유지한다.

### 플레이 시작점

- 네 가지 플레이 유형은 배경 카드 없이 아이콘, 제목, 짧은 설명으로 구성한다.
- 여섯 시작상황은 이미지가 깔린 전폭 배너로 유지한다.
- 펼친 뒤의 태그, 첫 선택, 웹툰은 하나의 연속된 기사처럼 보이게 하며 각각을 별도 카드로 감싸지 않는다.

### 풍경과 자료관

- 설정화는 기존의 한 장 슬라이드와 확대 모달을 유지한다.
- 슬라이드 바깥의 큰 프레임과 반복 테두리는 제거한다.
- 도식은 `지도와 자료관` 안에 남기되 본문과 시각적으로 분리한다.

## 시각 규칙

- 섹션 전체를 감싸는 흰색 둥근 카드, 그림자, 겹테두리를 제거한다.
- 섹션 구분은 배경색이 다른 전폭 밴드, 충분한 위아래 여백, 얇은 구분선을 사용한다.
- 모서리 반경은 이미지와 실제 상호작용 요소에만 제한적으로 사용한다.
- 렌의 청록, 듀란의 적색, 세계관의 금색을 장별 보조색으로 사용한다.
- 큰 제목은 이미지와 가까이 두고, 설명 문단은 한 줄이 지나치게 길어지지 않도록 폭을 제한한다.
- 장식용 오브젝트, 중첩 카드, 둥근 상자 반복은 추가하지 않는다.

## 반응형

- 데스크톱에서는 권역 색인과 선택된 기사 사이에 충분한 폭 차이를 둔다.
- 태블릿에서는 권역 색인을 2열로 줄이고 기사는 전폭으로 내린다.
- 모바일에서는 권역 색인을 가로 스크롤 가능한 한 줄 또는 2열 목록으로 바꾸고, 기사는 이미지 다음 본문 순서로 쌓는다.
- 모바일에서도 제목, 버튼, 인물 캡션이 한 글자 단위로 끊어지지 않아야 한다.

## 유지되는 기능

- 20개 권역 선택 및 같은 데이터 원천 사용
- 세계 읽기 아코디언
- 시작상황 접기·펼치기
- 이미지 슬라이드, 키보드 이동, 확대·축소 모달
- 지연 로딩과 기존 GitHub Pages 배포 구조

## 완료 기준

- 바깥 섹션 카드와 중첩 카드가 제거되어 한 화면에 보이는 사각 프레임 수가 절반 이하로 줄어든다.
- 20개 권역과 여섯 세계 읽기 주제, 여섯 시작상황이 모두 유지된다.
- 권역 상세 첫 화면에서 대표 이미지, 권역명, 수도, 핵심 소개가 즉시 보인다.
- 데스크톱, 태블릿, 모바일에서 가로 넘침과 글자 단위 줄바꿈이 없다.
- 클릭, 터치, 키보드로 기존 상호작용이 모두 작동한다.
- 공개 페이지에서 깨진 이미지와 콘솔 오류가 없다.
